## 快速开始

### 环境准备

```bash
pip install openpyxl
```

### 生成课表

```bash
python3 scripts/timetable.py \
  --input 课程列表.xlsx \
  --output 课表.xlsx \
  --school "XX小学"
```

### 使用示例数据测试

```bash
python3 scripts/timetable.py \
  --input examples/示例课程列表.xlsx \
  --output 测试课表.xlsx \
  --school "示范小学"
```

## 输入文件格式

Excel文件需包含一个工作表（名称含"课程"关键字或使用第一个工作表），结构如下：

| 列 | 字段名 | 类型 | 必填 | 说明 |
|----|--------|------|------|------|
| A | 课程ID | 文本/数字 | 否 | 课程唯一标识 |
| B | 课程名称 | 文本 | 是 | 课程显示名称 |
| C | 科目 | 文本 | 是 | 科目分类（语文/数学/英语/体育等） |
| D | 年级 | 文本 | 是 | 年级名称（一年级~六年级） |
| E | 班级 | 文本 | 是 | 班级全称（如"一年级（1）班"） |
| F | 授课教师 | 文本 | 是 | 教师姓名 |
| G | 规定周课时 | 整数 | 是 | 每周课时数（1~6） |

### 支持的科目

| 类别 | 科目 |
|------|------|
| 主科 | 语文、数学、英语 |
| 体育类 | 体育、体活 |
| 艺术类 | 音乐、美术 |
| 其他 | 科学、道法、班会、写作、劳动、健康、信息、故事会 |

### 注意事项

- 每个班级的总周课时不应超过30节（6节×5天）
- 班会课的教师不能同时担任两个班的班会（因为都固定在周一第5节）
- 班主任自动识别：每个班级的语文教师即为班主任
- 每个班级至少有一门语文课程

## 约束规则详解

### 1. 教师冲突（硬约束）
同一教师在同一时间段只能在一个班级授课。系统通过`teacher_occ`字典实时跟踪教师占用情况。

### 2. 延时课不排课（硬约束）
所有课程安排在第1-6节正课时段。第7、8节（延时课）不安排任何课程。

### 3. 周一第一节班主任课程（硬约束）
每周一第一节课必须安排班主任（即该班语文教师）的课程。系统在预分配阶段优先处理此约束。

### 4. 班会固定时段（硬约束）
班会课固定在周一第5节。系统在初始化阶段首先放置所有班会课程。

### 5. 非主科同天限制（硬约束）
除语文、英语、数学外，其余科目在同一天同一班级最多安排1节。例如，一个班级同一天不能上2节音乐课。

### 6. 体育/体活统一管理（硬约束）
体育与体活被视为同一科目进行管理。每个班级每天最多安排1节体育或体活课程。

### 7. 音美合并排课（硬约束）
3-6年级的音乐和美术合并排课，每天每班最多安排1节音乐或美术课程。

### 8. 前两节科目限制（硬约束）
非主科课程（体育除外）不安排在第1、2节。主科（语文、数学、英语）可以安排在任意时段。

### 9. 教师每日覆盖（软约束）
所有教师在周一至周五每天都应有课程安排。系统通过后处理优化`_balance_teacher_days`函数尝试修复空天问题。由于课程总量和教师分配的限制，此约束可能无法完全满足。

### 10. P1分布优化（软约束）
避免同一班级的同一科目多次出现在每天的第一节。系统通过评分函数对此进行惩罚。

### 11. 科目分散（软约束）
同一科目的课程尽量分散到不同的天数，避免集中安排。

### 12. 主科优先（软约束）
主科（语文、数学、英语）优先安排在前几节课时段。

### 13. 课程全部安排（目标约束）
确保所有课程都被安排到课表中。系统通过随机重启和冲突解决机制尽力实现此目标。

## 输出文件说明

### 年级总课程表
按年级分组的完整课表，每个班级显示5天×8节的课程安排。每个时间段显示科目名称和授课教师，科目用不同颜色标识。

### 教师周课时统计
统计每位教师的承担学科和总正课课时数。

### 教师个人课表
每位教师的个人周课表，显示该教师在各时间段的授课安排（班级+科目）。

### 约束检查报告
自动检查13类约束的满足情况，显示通过/未通过状态及具体问题。

### 班主任信息
列出每个班级的班主任（语文教师）识别结果。

## 算法原理

### 四阶段求解策略

#### 阶段1：P1预分配
- 周一第一节：优先安排班主任的主科课程
- 其他天第一节：优先安排主科课程

#### 阶段2：特殊课程预分配
- 体育/体活：按天预分配，确保每天一节
- 特殊教室课程（信息/科学）：按天分散预分配

#### 阶段3：贪心排课
- 按难度排序：主科优先、可选位置少的优先
- 评分函数：综合考虑位置偏好、科目分散、教师覆盖等因素
- 选择评分最低（最优）的位置放置课程

#### 阶段4：后处理优化
- 冲突解决：尝试通过移动已有课程来解决未放置的任务
- 教师空天修复：多轮迭代，将课程移动到教师的空天

### 随机重启
系统支持随机重启（默认30次），在每次重启中使用不同的随机种子打乱课程顺序，选择未安排课程数最少的结果作为最终输出。

## 常见问题

### Q: 部分课程未安排怎么办？
A: 检查约束检查报告中的"课程全部安排"项。常见原因：
1. 班级总课时超过30节（6节×5天）
2. 班会教师冲突（同一教师教授多个班的班会）
3. 教师课程过于集中，无法找到无冲突的时间段

### Q: 教师每日覆盖未通过怎么办？
A: 这是软约束，系统会尽力优化但无法保证100%满足。常见原因：
1. 教师课程较少（如仅2-3节/周），难以覆盖5天
2. 教师同时教授多个班级的同一科目，时间冲突

### Q: 如何调整排课结果？
A: 修改`--seed`参数使用不同的随机种子，或增加`--restarts`次数以获得更好的结果。

### Q: 如何添加自定义约束？
A: 在`scripts/timetable.py`的`_can_place`方法中添加新的检查逻辑，并在`_write_constraint_report`函数中添加对应的检查项。

### Q: 支持哪些年级和班级格式？
A: 年级支持"一年级"至"六年级"格式。班级名称需包含年级信息，如"一年级（1）班"。

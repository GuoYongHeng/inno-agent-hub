# 学校课表自动排课系统

## Overview

基于约束满足(CSP) + 贪心回溯算法的学校课表自动生成工具。从Excel课程列表读取数据，自动生成满足20类约束的完整课表，输出格式化的Excel文件。

## 使用方法

### 基本用法

```bash
python3 scripts/timetable.py \
  --input 课程列表.xlsx \
  --output 课表.xlsx
```

### 指定随机重启次数

```bash
python3 scripts/timetable.py \
  --input 课程列表.xlsx \
  --output 课表.xlsx \
  --restarts 50
```

### 参数说明

| 参数 | 必需 | 说明 |
|------|------|------|
| `--input` | 是 | 课程列表Excel文件路径（含"课程列表"工作表） |
| `--output` | 否 | 输出路径，默认为脚本同目录下的 `排课结果.xlsx` |
| `--restarts` | 否 | 随机重启次数，默认30 |
| `--seed` | 否 | 随机种子，默认2026 |
| `--school` | 否 | 学校名称（用于表头），默认为"学校" |

### 班主任自动识别

系统会自动从课程列表中识别班主任：每个班级的语文教师即为该班班主任。班会课自动由班主任授课，固定在周一第5节。无需单独提供班级列表文件。

## 输入文件格式

Excel文件需包含名为"课程列表"的工作表（或第一个包含"课程"关键字的工作表），列结构如下：

| 列 | 字段 | 说明 |
|----|------|------|
| A | 课程ID | 课程编号（可为空） |
| B | 课程名称 | 课程名称 |
| C | 科目 | 科目分类 |
| D | 年级 | 年级名称（如"一年级"） |
| E | 班级 | 班级名称（如"一年级（1）班"） |
| F | 授课教师 | 教师姓名 |
| G | 规定周课时 | 每周课时数 |

示例文件参见 `examples/示例课程列表.xlsx`。

## 约束规则

系统支持以下20类约束：

### 基础约束

1. **教师冲突**：同一教师同一时间只能在一个班级授课
2. **延时课不排课**：所有课程安排在第1-6节正课时段
3. **周一第一节班主任课程**：所有年级每周一第一节课必须安排班主任（语文教师）所带课程，该规则不得变更
4. **班会固定时段**：班会课固定在周一第5节
5. **非主科同天限制**：除语文、英语、数学外，其余课程同一天同一班级最多安排1节
6. **体育/体活统一管理**：体育与体活视为同一科目，每天每班最多1节
7. **音美合并排课**：3-6年级音乐和美术合并排课，每天每班最多1节
8. **前两节科目限制**：非主科（体育除外）不安排在前两节
9. **教师每日覆盖**：所有教师周一至周五每天都有课程安排（软约束，尽力满足）
10. **课程全部安排**：确保所有课程都被安排到课表中

### P1分布规则

11. **P1分布规则**：每周五天第一节课按年级分配科目：
    - 1-2年级：语文2节 + 数学3节（周一固定语文/班主任）
    - 3-6年级：语文2节 + 数学2节 + 英语1节（周一固定语文/班主任）

12. **P1科目限制**：第一节课只能安排语文、数学、英语（班会除外）

13. **P1连续避让**：禁止同一班级连续两天第一节安排同一课程

### 连续课程规则

14. **同天连续同课禁止**：禁止同一班级同一天连续两节课安排同一课程（班会除外）

### 时段分布规则

15. **语数早上优先**：全年级语文、数学每天在早上（第1-3节）至少安排1节课
16. **最后一节禁主科**：严禁在每天最后一节课（第6节）安排语文、数学和英语
17. **数学每天分布**：数学课尽量每天安排至少1节（软约束）

### 科目分散规则

18. **科目分散**：同一科目尽量分散到不同天
19. **主科优先**：主科（语文、数学、英语）优先安排在前几节
20. **单双周限制**：
    - 1-2年级：所有课程不允许出现单双周差异
    - 3-6年级：仅音乐和美术允许区分单双周，其余课程不允许

## 输出文件

输出Excel包含5个工作表：

| 工作表 | 说明 |
|--------|------|
| 年级总课程表 | 按年级分组的完整课表，含科目和教师 |
| 教师周课时统计 | 每位教师的承担学科和总课时 |
| 教师个人课表 | 每位教师的个人周课表 |
| 约束检查报告 | 20类约束的通过/未通过状态及详情 |
| 班主任信息 | 各班级班主任识别结果 |

## 算法说明

系统采用五阶段求解策略：

1. **P1分布预分配**：按年级P1分布规则分配第一节课，周一固定班主任课程，其余天按科目配额分配并避免连续相同
2. **特殊课程预分配**：体育/体活、特殊教室课程（信息/科学）预分配
3. **贪心排课**：按难度排序，使用评分函数选择最优位置（含P1连续避让、语数早上优先、数学每天分布等评分）
4. **教师空天修复**：后处理修复教师空天问题
5. **规则后处理**：迭代修复所有新增规则违规（同天连续同课、最后一节主科、早上无语数、P1连续等）

支持随机重启，在多次尝试中选择最优结果。

### 评分函数

评分函数综合考虑以下因素（分值越低越优先）：
- 主科优先安排在前三节（-5分）
- 非主科优先安排在后面（-3分）
- 同科目分散到不同天（+10分惩罚同天）
- 教师空天填充（-15分强烈鼓励）
- P1分布避让（+8分惩罚重复P1科目）
- P1连续避让（+15分惩罚连续两天P1相同）
- 语数早上优先（-20分强烈鼓励填入无语数的早上时段）
- 数学每天分布（-12分鼓励填入无数学的天）

### 后处理修复

后处理按优先级迭代修复以下违规：
1. 同天连续同课（通过跨天交换修复）
2. 最后一节主科（与非主科交换）
3. 早上无语数（下午语数与早上非主科交换）
4. P1连续（P1-P1交换保持分布不变）

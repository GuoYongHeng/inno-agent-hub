# 课件 HTML 生成技能（innoslides）

一键产出符合规范模板与字体样式的单文件 `.bento.html` 课件（离线可用、双击浏览器直开），并可用配套脚本转成可编辑 PPTX。**封面/内页底图已内置在 `assets/themes/`，七套主题可选，无需用户提供。**

使用时输入课题与主讲人即可。**生成前必须完成「大纲确认 + 风格选择」两步用户确认（见下节）**；`--theme` 用于指定用户选定的背景主题：

| 脚本 | 作用 |
|---|---|
| `scripts/build_deck.py` | **正式出课件用这个**：读 JSON 页面规格 → 生成真实内容的课件，写盘后自动去品牌字样；`--dry-run` 只打印大纲与预检供用户确认（不写盘） |
| `scripts/generate_themes.py` | 生成/重新生成主题底图（每套含封面 + 内页），可扩展新配色 |
| `scripts/create_skeleton_deck.py` | 生成**占位骨架**课件（封面 + N 页假内容页），只用于核对背景图与坐标 |
| `scripts/scrub_bento.py` | 去掉课件里可见的品牌字样（幂等，自动 .bak） |
| `scripts/set_transition.py` | 批量修补已生成课件的放映切换为 none |
| `scripts/verify_bento.cjs` | Edge/Chrome headless 逐页截图自检 |
| `scripts/bento_to_pptx.py` | 转可编辑 PPTX（文字为原生文本框，图片为原生图片） |

## ⛳ 生成前必做：① 确认大纲 → ② 选择风格（强制）

**未完成下面两步用户确认，不得写盘生成。** 顺序固定：先大纲、后风格；用户可一次性回复两项，但**用户未见过大纲与风格选项之前，不得生成，也不得替用户默认选择主题**。

**① 大纲确认。** 根据课题拟出**课件大纲**发给用户逐项确认（增/删/改页都在这一步完成，避免出片后返工）：

- 课题、年级学科、主讲人/学校（未提供则用「待填写 / XX学校」占位）、预计总页数（封面＋内容页＋结束页）；
- 各一级环节（汉字编号，≤6 个）及页数；每页给出 `heading` 与一行要点摘要；
- 每页尽量配 1 行高亮提示（tip）；单页 ≤8 行、单行 ≤28 字（脚本自动预检）。

```
【课件大纲 · 待确认】
课题：《水的三态》　八年级·物理　预计 12 页（封面＋10 内容页＋结束页）

一、情境导入（1 页）
　P2　水的三种模样：江河雨雪云雾，都是水
二、水的三种状态（2 页）
　P3　三态实例：冰、水、水蒸气
　P4　三态特征对比与辨析
三、水的物态变化（3 页）
　……
```

**② 风格选择。** 把下文「主题背景」七套主题按「主题 / 风格 / 适用场景」列给用户（可直接引用那张表），并根据学科给出**推荐项**（如物理→`science`、语文故事→`storybook`、古诗词→`chinese`），等用户选定后再生成。

**③ 确认后生成。** 把大纲写入 `pages.json`，先干跑核对，再正式生成：

```bash
python "<skill_dir>/scripts/build_deck.py" --json pages.json --theme <用户选定主题> --dry-run   # 只打印大纲与预检，不写盘
python "<skill_dir>/scripts/build_deck.py" --json pages.json --theme <用户选定主题> -o "<课题>.html"  # 确认无误后正式生成
```

## 快速开始

**① 写内容规格 JSON**（`pages.json`）——⚠️ 前置：大纲与风格已按上节完成确认；一级环节用汉字编号（`一、`）最多 6 个，二级标题用阿拉伯数字（`1.` `2.`）：

```json
{
  "theme": "storybook",                        // 可省略：默认温暖绘本（storybook/blue/blackboard/minimal/cartoon/science/chinese）
  "meta": {
    "title": "维护生态安全", "lesson": "",
    "grade": "八年级", "subject": "生物学（人教版）",
    "teacher": "待填写", "school": "XX学校",
    "accent": "#2E7D32"                          // 可选，高亮提示行强调色；缺省取主题色
  },
  "pages": [
    { "heading": "一、情境导入",
      "lines": ["20 世纪以来，人类活动对地球的影响越来越大。", "地球仿佛寄来一封求助信。"],
      "tip": "〔情境〕今天这节课，我们学习怎样守护共同的家园。" }
  ]
}
```

**② 生成课件**（前置确认完成后；正文纯文字满宽 896px；末页默认追加致谢结束页）：

```bash
python "<skill_dir>/scripts/build_deck.py" --json pages.json --theme storybook -o "维护生态安全.html"
```

可选参数：`--theme storybook|blue|blackboard|minimal|cartoon|science|chinese`（背景主题，meta.theme 亦可指定）、
`--cover` / `--bg`（覆盖主题底图，一般不需要）、`--size 36`（强制正文字号）、
`--no-brand`（不加末页结束页）、`--strict`（有告警即退出码 2）、`--dry-run`（只打印大纲与预检、不写盘）。
`lesson` 留空则封面标题不带括号；全文每个内容页都 ≤5 行时自动把正文放大到 36px 更舒展。

### 🎨 主题背景：七套内置主题，坐标契约一致

封面与内页底图**已随技能内置**（1280×720，与画布 1:1），每套主题一张封面 + 一张内页：

| 主题 | key | 主色 | 风格描述 | 适用场景 |
|---|---|---|---|---|
| 温暖绘本（默认） | `storybook` | `#D4A373` | 暖米底 + 手绘波浪边框 + 四角小花 + 驼色细线 | 语文故事/绘本阅读/品德 |
| 深蓝商务 | `blue` | `#1F4E79` | 深海蓝 + 六边形网格底纹 + 冰蓝科技角标 + 层叠边框 | 理科/沉稳汇报 |
| 黑板经典 | `blackboard` | `#2E7D32` | 官方木质黑板封面 + 同色系绿色内页（深色条） | 传统课堂/板书风格 |
| 极简留白 | `minimal` | `#34495E` | 大面积留白 + 细竖线/横线装饰 + 圆点阵列 + 极细边框 | 现代简约/设计课 |
| 卡通风 | `cartoon` | `#5B9BD5` | 天蓝底 + 白云/星星 + 暖黄圆角块 + 底部波浪线 | 小学低段/幼儿/美术 |
| 理化生实验 | `science` | `#0F4C5C` | 深青黑底 + 六边形分子网格 + 荧光绿角标 + 数据条装饰 | 物理/化学/生物实验课 |
| 国风素雅 | `chinese` | `#4A6741` | 米白底 + 淡墨竹影 + 赭石印章圆 + 竹青细线边框 | 语文古诗词/书法/历史 |

- **封面文字色按主题自动适配（coverTextColor）**：浅色封面主题使用深色文字——温暖绘本/极简留白/卡通风 `#1F2937`、国风素雅 `#33452C`；深色封面主题保持白字。JSON 里 `meta.coverTextColor` 可覆盖。**新增主题必须同时配置 `headingColor` 与 `coverTextColor`**。
- 前七套底图（除黑板经典外）由 `scripts/generate_themes.py` 程序化生成，存于 `assets/themes/<key>/cover.jpg` 与 `bg.jpg`（若存在同源 `*.jpg.b64.txt` 亦可回退读取）。
- `blackboard` 主题封面使用官方木质黑板底图、内页复用绿色主题底图（**不含任何「基础教育精品课」字样**）。**七套主题的封面均不绘制左上角标签文字**（不再出现「课件生成」字样）。
- **所有主题共用同一套坐标契约**：内页色条边界 y=89/661；**内页小标题置于上方色条内**（y=8、h=74、垂直居中，颜色按主题取 `headingColor`：深色条白字、浅色条深字）；白色区安全区 x∈[96,1184]、y∈[96,656]；封面文字坐标（标题 96,205 / 元信息 150,380 与 658,456）不变。因此**换主题不需要重标任何坐标**。
- `theme` / `--theme` / `--cover` / `--bg` 留空、路径不存在 → 自动回退默认主题底图，只打一行提示，不报错。
- **自定义底图请谨慎**：脚本会打「自定义底图」告警。封面文字坐标与安全区是按主题底图标定的，换任何别的图都会文字错位、文字压色条。确要换图：保持 1280×720，并同步核对上述坐标。
- 要新增配色：在 `generate_themes.py` 的 `THEMES` 里加一组颜色并重跑，然后在 `build_deck.py` / `create_skeleton_deck.py` 的 `THEMES` 里登记同名 key，并给它配好 `headingColor`（色条深→`#FFFFFF`，色条浅→`#1F2937`）。

**③ 骨架模式**（只需确认背景图与坐标时）：

```bash
python "<skill_dir>/scripts/create_skeleton_deck.py" \
  --title "爬山虎的脚" --lesson "第一课时" --grade "四年级" \
  --subject "语文（统编版）" --teacher "待填写" --school "XX学校" \
  --slides 5 -o "爬山虎的脚.html"
```

（`--theme` / `--cover` / `--bg` 可省略，省略即用默认主题底图。）

**④ 页面规格字段**：`heading` 页标题、`lines` 正文行数组（每行一段）、`tip` 可选高亮提示行、
`img` 可选右侧配图路径（仅限用户提供的现成素材）、`size`/`headingSize` 可选字号覆盖、`notes` 放映备注。

- 产物命名自动归一为 `<课题>（第X课时）.html`，文件名不含 bento。
- 写盘后自动调用 `scrub_bento.py` 清洗可见品牌字样，生成结束会自检字数/行数/切换并打印警告。
- 旧课件批量补洗：`python scrub_bento.py --dir <目录>`（幂等）。

## 硬性规范

1. **放映切换恒为 `transition:"none"`**：每一页（含封面）都必须写。fade/morph/slide/zoom 在内嵌 reveal.js 的黑色容器底上翻页会闪黑（实测核实，勿再尝试）。已生成课件用 `set_transition.py` 批量修补。也不要给元素加 `fx` 入场动画。
2. **不得出现可见品牌字样**：标签页标题/加载屏/顶栏 logo/界面文案全部为「课件生成」等中文文案。`scrub_bento.py` 只动可见文案，功能性标识符（bento-doc/bento-rt/CSS 类名/MIT 注释）必须保留；`#bento-doc` 里 `"format":"bento/slides"` 与运行时校验串必须成对替换，只改一边会静默回退到演示 deck。**每次 scrub 完必须用 `verify_bento.cjs` 截图确认加载的是真课件。**
3. **版面**（画布 1280×720）：内页小标题按模板置于上方色条内（y=8、h=74、垂直居中；深色主题白字、浅色主题深字）；除此之外，上下色条（y 0~89、661~720）不放任何元素，内容 `y ≥ 96` 且 `y+h ≤ 656`，`x ≥ 96` 且 `x+w ≤ 1184`。不要额外绘制标题栏/页脚（背景图已含）。封面不绘制左上角标签。
4. **背景图 base64 嵌入**：第 1 页用 `asset:jingpinke-cover`（主题封面），第 2 页起用 `asset:jingpinke-bg`（主题内页），每页全幅 image 置底、各用不同 id（bg-s1/bg-s2…）。
5. **文字写入 `#bento-doc` 时所有 `<` 转义为 `\u003c`**；`html` 字段支持 `<br>` 换行、`<b>` 加粗，缩进用全角空格。

## 字体与字数（中文课件）

| 元素 | 字体 | 字号(pt) | px |
|---|---|---|---|
| 封面主标题 | 微软雅黑加粗 | 54 | 72 |
| 封面元信息（无标签） | 华文楷体 | 21 | 28 |
| 小标题 | 黑体（SimHei/Heiti SC） | 30 | 40 |
| 正文 | 华文楷体（STKaiti/KaiTi） | ≥24，字少可放大 | ≥32，可到 37 |

- 单行 ≤28 汉字（正文框宽 896px 自然换行）；单页 ≤8 行。小标题渲染在内页上方色条内（深色主题白字、浅色主题深字）。
- 🚨 **正文框高度按实际行数算：`body_h = len(lines) * int(字号 × 1.5)`**（36px 版式每行 54px；正文起点 y=160），不要封顶 6 行。**高亮提示行与正文底部保持 40px 间距（TIP_GAP）**，避免贴叠。有提示行时 36px 版式正文最多 7 行，8 行须拆页。
- 一级环节 ≤6 个（汉字编号一、二、…，**按编号去重计数**），二级标题用阿拉伯数字（1. 2.），层级只有两级；页数不限，多页可属同一环节——**同环节首页用汉字编号标题，后续页用阿拉伯数字二级标题**（如「三、文言基础过关」→「1. 通假字…」）。
- 封面实测坐标：主标题 `x=96,y=205,w=1088,h=130,72px`；元信息左列 `x=150`、右列 `x=658`，两行 `y=380/456`，28px；封面不含左上角标签。

## 英语课件字体规范（`--lang en`）

`create_skeleton_deck.py` **与 `build_deck.py`** 均支持 `--lang zh|en|auto`（默认 auto：按 `--subject` / `meta.subject` 含「英语/English」自动判为 en）。中文课件不受影响。
build_deck 英语模式要点：封面大标题 48px、内页小标题 48px、正文 32px，单行 ≤15 词；不套用中文「字少自动放大字号」规则。

| 元素 | 字体 | 字号(pt) |
|---|---|---|
| 封面大标题 | Times New Roman | 32—36（默认 36，`--cover-title-size` 可调） |
| 内页标题 | TNR 为主，可搭配 Arial | 32—36，强调 40 |
| 正文 | TNR 为主，可搭配 Arial | 24—28，强调 32 |

- 英文每行 ≤15 单词（自动校验）；单页 ≤8 行；英文标题用阿拉伯数字编号。
- 英文模式**不要**套用中文「字少自动放大字号」规则，字号按上表固定。封面元信息/结束页保持中文字体。

## 末页结束页（可选）

`create_skeleton_deck.py` 默认在末页追加结束页：内页背景 + 「感谢观看！」致谢行（安全区居中，`transition:"none"`，华文楷体 32px）。文案在脚本顶部 `BRAND_PAGE_TEXT` 常量；`--no-brand` 可关。旧课件补结束页：向 `#bento-doc` 追加同结构 slide（id 用 `brand-sN`，幂等判断 notes 含「结束页」）。

## 转可编辑 PPTX

```bash
python "<skill_dir>/scripts/bento_to_pptx.py" "秋天的雨（第一课时）.html"   # 输出同名 .pptx
```

文字是真正可编辑的 PPT 文本框，背景/配图为原生图片；页面备注（`notes`）同步写入演讲者备注；px→pt ×0.75；中文字体写入 latin+eastAsia 双设置防回退；**行距按固定值（字号×lineHeight）写入**，与网页版式一致——PPT 的「倍数行距」按字体自然行高计算会偏高约 20%，导致多行正文下坠压到下方提示行（已修复）。依赖 python-pptx，纯离线。

## 配图页规范（仅限用户提供的现成素材）

默认纯文字、正文满宽 896px。`build_deck.py` 支持页面规格里的 `"img"` 字段（用户提供素材时）：
Pillow 统一处理为 800×800 JPEG 后 base64 嵌入 `doc.assets`（未装 Pillow 则回退原图直嵌并提示）；
配图放右侧 `x=824, y=160, w=360, h=360`，正文框收窄 `w=672`（每行 ≤20 字）；
高亮提示保持整行 `x=96, w=1088`，`y = max(正文底, 图片底) + 40`。文字密集页（清单/作业类）不配图。

## 自检

- 逐页截图：`node "<skill_dir>/scripts/verify_bento.cjs" "<课件>.html" "<输出目录>" 20`（路径用**绝对路径**；浏览器自动探测不到时用环境变量 `CHROME` 指定，macOS 如 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`）。截图含编辑器外壳属正常，只看中间画布；核对无叠字、无越界、加载的是真课件。
- 模板壳 `assets/Bento_Slides.bento.html` + **主题底图 `assets/themes/`** 随技能离线分发，所有脚本无网络请求、无外链跳转。
- 重新生成/扩展主题底图：`python scripts/generate_themes.py [--theme blue]`（依赖 Pillow）。

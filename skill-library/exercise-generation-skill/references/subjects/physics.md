# 物理 · 命题要点（physics）

学科是物理（初中八、九年级，高中必修与选择性必修）时必读。小学科学里的"力、光、电"读 `science.md`。

---

## 1. 课标锚点

### 1.1 核心素养（写 `objective` 时用）

初中、高中名称相同：**物理观念、科学思维、科学探究、科学态度与责任**。要素（两版课标一致，已核对原文）：
- 科学思维：模型建构、科学推理、科学论证、质疑创新
- 科学探究：问题、证据、解释、交流
- 科学态度与责任：科学本质（观）、科学态度、社会责任

`objective` 写"知识点 + 素养要素"，例如"漂浮条件与阿基米德原理的联用（科学思维·科学推理）""探究电流与电阻关系中的变量控制（科学探究·证据）"。只写"科学思维"等于没写。

### 1.2 课标对作业和命题的要求（原文摘要）

**2022 版义务教育物理课标**
- 作业："设计层次分明、类型多样的作业，兼顾基础性作业和探究性、实践性作业"；"合理调控作业量，避免机械训练、简单重复"。
- 难度结构："从课程内容、试题情境、知识应用等不同角度设置试题难度"，"题量与考试时间相匹配，阅读量适中"。
- 试题命制：要"清楚每道题目所考查的物理内容及其对应的认知水平"；"要设计能展示学生思维过程的问题"。
- 情境："试题情境要客观真实，准确可靠"，"服务于考试目标，信息量要适当"，"应为大多数学生所熟悉，对不同群体学生作答的公平性无影响"。
- 评分："对可能出现的各种合理答案进行分类并划分出相应的水平"；参考答案"无知识性错误，无学术性争议"。
- 学业质量（节选）：能"分析和解决熟悉情境下的简单物理问题"；能"运用控制变量法等制订比较合理的科学探究方案"；能"从物理学视角对生活中不合理的说法进行质疑并说出理由"。

**普通高中物理课标（2017 年版，已核对；2020 修订版此处未核实是否改动）**
- 学业质量按"问题情境的复杂程度、知识和技能的结构化程度、思维方式或价值观念的综合程度"划分为 **5 级**；"学业质量水平 2 是高中毕业生应达到的合格要求，是学业水平合格性考试的命题依据；学业质量水平 4 是……等级性考试的命题依据"。
- 难度："可根据物理学科核心素养的水平层次、试题情境的复杂性或新颖性、知识要求的深度或广度等多方面来设计试题的难度，保证合理的梯度"。
- 选择题："错误选项要具有较强的干扰性，能反映学生的典型错误"；"各个选项的结构、长度要大体一致"。

### 1.3 分层锚点

- **初中**：课标给的三个难度角度正好对应画像维度：课程内容（`k`、`s`）、试题情境（`r`、`c`）、知识应用（`g`、`o`）。A 层 ≈ 学业质量里"熟悉情境下的简单物理问题"；B 层把条件变隐含或加一个知识点；C 层到"设计方案、质疑说法、陌生情境建模"。
- **高中**：A ≈ 水平 2（合格考：熟悉情境、常见模型、简单直接的证据），B ≈ 水平 3（熟悉情境中**选用**恰当模型），C ≈ 水平 4（把实际对象和过程**转换**成物理模型，综合分析，用证据证明结论）。水平 5 超出课后作业需要，不作目标。注意：理科水平编号与数学不同（数学三级，物理五级），不要照搬 `layering.md` 里"A≈水平一"的数学说法。
- **学生必做实验**（义务教育课标列出测量类 9 个、探究类 12 个，已核对）：测量类含天平测质量、测密度、温度计、刻度尺和停表、测速度、弹簧测力计、电流表、电压表、伏安法测电阻；探究类含水沸腾、滑动摩擦力、液体压强、浮力、杠杆平衡、光的反射、平面镜成像、凸透镜成像、通电螺线管磁场、电磁感应条件、串并联电流电压特点、电流与电压电阻关系。**实验探究题优先围绕这些实验命题**。

## 2. 物理出卷老师的组卷方法

1. **母题 = 一个物理模型 + 一个过程。** 先定模型（漂浮的物体、串联电路、杠杆、匀变速直线运动），再定过程（一个状态、两个状态对比、连续变化）。题组围绕同一模型展开，比每层换一个新模型更像分层。
2. **升级路线**（物理最常用）：
   - **改条件给法**：直接给数 → 铭牌、图像、表格、电路图 → 隐含条件（"匀速""漂浮""正常发光""光滑""轻质""缓慢"）。
   - **改状态**：一个状态 → 前后两个状态比较（开关闭合前后、浸入前后）→ 动态变化（滑片移动、逐渐浸入）。
   - **改问法**：求量 → 比较大小、判断变化 → 由结果反求条件 → 解释现象 → 设计方案或评价方案。
   - **加知识**：力 + 压强、浮力 + 密度、热 + 电（电热效率）、运动 + 功率。
   - **由算到说**："小明认为……你同意吗？说明理由"；判断估测值是否合理。
   - **由做到设计**：给器材设计实验、指出方案缺陷、分析误差来源。
3. **反向设计数据**：先选物理上合理、计算上规整的答案（如浮力 1.2 N、电流 0.5 A），再倒推条件，然后**逐个核对第 5 节的量级**。规整与真实冲突时，优先真实，允许结果保留一位小数并在题干写明精度。
4. **不靠运算量升级**：把 2 V 换成 2.37 V、多套一次科学记数法，不是升级。
5. **初中 `g` 的约定**：教材中 g = 9.8 N/kg，粗略计算可取 10 N/kg。作业里取哪个值，**都要在题干写明**（如"g 取 10 N/kg"）。

### 2.1 难度画像在物理里的含义

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| `k` | 一个规律（v=s/t） | 两个（ρ=m/V 与 G=mg；欧姆定律与串联分压） | 三个及以上或跨章（力、压强、浮力连用；电热效率） |
| `c` | 物理量直接给出，单位已统一 | 需换算单位、读铭牌/图像/表格/电路图、把文字转成物理量（"满载""额定"） | **需自己从情境中识别**：受力情况和平衡状态（"匀速""静止""缓慢"→二力平衡），理想化条件（"光滑"→无摩擦，"轻质"→不计质量），状态条件（"漂浮"→F浮=G，"正常发光"→U=U额，"标准大气压下烧开"→100 ℃），临界条件（"恰好"），或题中有干扰数据 |
| `r` | 标准物理模型（"水平面上的木块""如图电路"） | 熟悉生活情境，需自己抽出模型（电热水壶、自行车刹车、提水桶） | 陌生或综合情境（新科技装置、跨学科任务、科普阅读材料） |
| `o` | 唯一答案 | 需解释现象、说理，或可多法 | 设计实验或方案、开放评价 |
| `g` | 识记、识别（单位、现象名称、读数） | 套用规律计算或判断 | 受力分析、动态电路分析、图像分析、多过程推理 |

`g=3`：评价实验方案、设计新方案、对不合理说法给出有依据的反驳。
`s` 按解析里必要环节数：识别状态 → 选规律 → 换算 → 代入 → 求中间量 → 求所问量，各算一步。

## 3. 题型与命题规范

| 题型 | 规范 |
|---|---|
| 选择题 | 初中、高中单选四选一。新高考物理有多选题（全对满分、漏选得部分分、错选 0 分，按当地规则写进题干），只在高中出。干扰项各对应一个错因：**用错状态**（漂浮当悬浮）、**单位未换算**、**量与量混淆**（质量与重力、功与功率、电能与电功率）、**方向弄反**。数值选项按大小排列 |
| 填空题 | 物理量要写明单位要求（"___ N"）；数值题写明精度；现象类填空答案唯一（"___（选填'变大''变小'或'不变'）"） |
| 作图题 | 见 3.1 |
| 实验探究题 | 见 3.2 |
| 计算题 | 见 3.3 |
| 估测题 | 只用于判断"量级是否合理"，选项之间相差一个数量级以上，避免"0.75 m 与 0.8 m"之争 |
| 说理题 / 简答题 | 给出要判断的说法或现象；评分要点写"用到的规律 + 推理链 + 结论"三段 |
| 科普阅读题 | 材料 300 字以内（初中），信息真实或标"（材料为虚构）"；问题要求从材料中提取物理量或规律，不是考阅读理解 |

### 3.1 作图规范（题干和答案都要符合）

- **力的示意图**：带箭头的线段，起点（或终点）在作用点；同一物体受多个力时作用点都画在重心；标力的符号，题目给出大小时标数值；平衡力线段等长。
- **杠杆**：力臂是支点到力的**作用线**的垂线段，用虚线或大括号标 `l`；"最小动力"题要先找最长力臂。
- **光路图**：光线用实线加箭头；法线、反向延长线、虚像用虚线；平面镜成像要画出对称的虚像点；凸透镜三条特殊光线。
- **电路图**：用规范元件符号；导线横平竖直；交叉相连处画实心点；元件不画在拐角；实物连线不交叉、电表"正进负出"。
- **磁感线**：在磁体外部从 N 极出发回到 S 极，用虚线或实线加箭头。
- 作图题 `figure` 要把已有图形描述完整（物体、支点、光源位置、元件位置），答案写成"正确图的要点"，`check.method` 用 `blind`。

### 3.2 实验探究题规范

- **变量控制**：题干要让学生能识别自变量、因变量、控制变量。问"控制变量"时，答案写到具体的量（"保持导体两端电压不变"），不接受"控制其他条件相同"。
- **数据处理**：给表格时数据要**自洽**（用程序生成并验算，见第 6 节），有意设置的"异常数据"要在教师版说明；作图像要求描点、连线（直线或平滑曲线）。
- **多次测量的目的**要分清：测量类实验（测密度、测电阻）是"求平均值减小误差"；探究类实验（探究规律）是"使结论具有普遍性"。这是高频错因，B 层常考。
- **误差与错误**：误差不可避免、只能减小；错误（读数视线、量程选错）可以避免。
- **读数**：刻度尺要估读到分度值的下一位；其他仪表的估读要求各地不一（经验做法：初中电流表、电压表、弹簧测力计一般读到分度值），题干给出分度值或图示要清楚，答案写可接受范围。
- 实验题不设计危险操作（见 5.3）。

### 3.3 计算题书写规范

- 题干写"写出必要的文字说明、公式和重要演算步骤，只写出最后答案的不能得分"（经验做法，与多数地区中考说明一致）。
- 解析按**公式 → 代入（带单位）→ 结果（带单位）**写；每个所求量先写公式再代入；单位统一用国际单位制，换算单独写一步。
- 下标区分同类量（F浮、G木、U1、U2）；不同状态的同一物理量用上标或文字区分（"闭合 S1 时 I1"）。
- **有效数字与精度**（经验做法）：初中一般在题干写"结果保留一位小数"或数据设计成能整除；高中计算结果通常与已知数据的有效数字位数一致（2–3 位），题干给出要求。不能整除又没写精度的题，是病题。
- 答案写明"答：……"不是必需，但物理量必须有单位，结果为向量时（高中）说明方向。

## 4. 题型谱（按学段）

### 4.1 初中

| 单元 | 常考题型 | 典型错因（可观察行为） |
|---|---|---|
| 机械运动 | 刻度尺读数、参照物判断、v=s/t 计算、s-t/v-t 图像 | 读数不估读或漏单位；把"相对于地面"与"相对于车"混用；全程平均速度用"速度的平均值" |
| 声现象 | 声音三特性辨析、声速计算（回声） | 音调与响度混淆；回声计算忘记除以 2 |
| 光现象 | 反射/折射/直线传播辨析、平面镜成像作图、光路作图 | 认为"人走近平面镜像变大"；折射光路角度画反；虚像画成实线 |
| 透镜及其应用 | 凸透镜成像规律表、成像位置判断、近视远视矫正 | 把物距与像距对应关系记反；u=2f 处判断错误；近视用凸透镜 |
| 物态变化 | 物态变化名称判断、吸放热、熔化/沸腾图像 | "白气"认作水蒸气；把"升华"与"汽化"混淆；晶体熔化时温度"上升" |
| 质量与密度 | 天平使用、测密度实验、ρ=m/V 计算、密度图像 | 游码读右边缘；先测体积后测质量导致偏差方向判断错；g/cm³ 与 kg/m³ 换算错 |
| 力、运动和力 | 重力、弹力、摩擦力辨析，二力平衡，惯性 | 把"惯性"说成"受到惯性作用"；认为运动需要力维持；平衡力与相互作用力混淆 |
| 压强 | p=F/S、液体压强 p=ρgh、大气压现象 | 受力面积取错（取物体底面积而非接触面积）；h 取成离容器底的高度；液体对容器底压力当成液体重力 |
| 浮力 | 阿基米德原理、浮沉条件、称重法、综合计算 | 漂浮时仍用 V物 算 V排；把物体密度当液体密度代入；悬浮与漂浮混淆 |
| 功和机械能 | W=Fs、P=W/t、动能势能影响因素、机械能转化 | 力与距离不对应（水平推力×竖直高度）；"物体做功"与"力做功"混淆；忽略摩擦时仍说机械能减少 |
| 简单机械 | 杠杆平衡条件、力臂作图、滑轮组 n 的判断、机械效率 | 力臂画成支点到作用点的连线；滑轮组 n 数错；有用功与总功颠倒 |
| 内能与热机 | Q=cmΔt、热值、比热容应用解释、冲程判断 | Δt 用末温代替温差；"升高到"与"升高了"不分；热值单位 J/kg 与 J/m³ 混用 |
| 电流和电路 | 串并联识别、电路连接、电表接法 | 电流表并联在用电器两端；短路与断路分不清 |
| 电压、电阻、欧姆定律 | 串并联电流电压规律、I=U/R 计算、动态电路、伏安法 | 不同状态的量混用（"张冠李戴"）；滑片移动后电表示数变化方向判断错；认为 R 与 U 成正比 |
| 电功率 | 铭牌计算、实际功率、电能表读数、焦耳定律 | 用额定电压算实际功率；kW·h 与 J 换算错；电能表读数忘记最后一位是小数 |
| 电与磁 | 磁感线、安培定则、电磁感应条件、电动机与发电机原理 | 安培定则握法错；把电动机原理说成电磁感应；导体平行磁感线运动也判为产生电流 |
| 家庭电路与安全用电 | 电路连接作图、故障判断、安全用电判断 | 开关接零线；三孔插座接法错；把"保险丝熔断"都归因为短路 |

### 4.2 高中（按人教版 2019 必修/选必章节简列；章名凭记忆，以所用教材为准）

| 模块 | 核心章节 | 常考题型 | 典型错因 |

## 6. 正确性验证

`verify_items.py` 已执行 `from sympy import *`。计算题都写 `check.code`，只用题干条件重新算。

**运行环境提醒**：sympy 已占用一些常见名字（`I` 虚数单位、`E`、`N`、`S`、`Q`、`product`）。在 code 里把 `I` 当电流用会覆盖虚数单位，问题不大，但不要在 `expect` 里用这些名字；要用 itertools 的 `product`，就在 code 里先写 `from itertools import product`。

```python
# 单位换算：sympy.physics.units
from sympy.physics.units import km, hour, meter, second, convert_to
v = convert_to(72*km/hour, meter/second)      # 题干：72 km/h
ans = v / (meter/second)                       # expect "20"

# 热学计算：题干 1.5 kg 水从 20 ℃ 在 1 标准大气压下烧开，电热水壶 1500 W，效率 84%
c = Rational(42, 10)*10**3; m = Rational(15, 10); dt = 100 - 20
P, eta = 1500, Rational(84, 100)
Q = c*m*dt; t = Q/(eta*P)
ans = [Q, t]                                   # expect "[504000, 400]"

# 有精度要求：铭牌 220 V 1500 W，求正常工作电流（保留一位小数）并与插座 5 A 比较
I = Rational(1500, 220)
ans = [round(float(I), 1), I > 5]              # expect "[6.8, True]"

# 选择题：先算正确值，再把每个干扰项按错因算一遍（门禁 C）
rho_w, g = 1000, 10                            # g 取 10 N/kg（题干）
V = Rational(200, 10**6); V_sub = Rational(3, 5)*V   # 体积 200 cm³ 的木块漂浮，3/5 浸入水中
F = rho_w*g*V_sub
opts = {'A': 2, 'B': Rational(6, 5), 'C': Rational(4, 5), 'D': 1200}
assert opts['A'] == rho_w*g*V                  # 错因：用全部体积
assert opts['C'] == rho_w*g*(V - V_sub)        # 错因：用露出部分
assert opts['D'] == rho_w*g*Rational(3, 5)*200/1000   # 错因：把 1 cm³ 当成 10⁻³ m³
ans = [k for k, v in opts.items() if v == F][0]       # expect "'B'"

# 高中：刹车陷阱。108 km/h 的汽车以 5 m/s² 刹车，求 8 s 内位移
v0 = Rational(108*1000, 3600); a = -5
t_stop = -v0/a                                 # 6 s 已停下
tt = Min(8, t_stop)
ans = v0*tt + Rational(1, 2)*a*tt**2           # expect "90"（直接代 8 s 会得 80）
```

## 7. 常见病题（审卷时重点查）

- **条件缺失产生第二答案**：没写"不计绳重和摩擦"，滑轮组拉力有两种算法；没说"灯丝电阻不变"，实际功率无法唯一确定；没说"1 标准大气压"，沸点不确定。
- **数据不自洽**：漂浮物体的 V排 大于 V物；密度大于水的物体"漂浮"；实验表格里 U/I 应恒定却随手写了数；机械效率超过 100%。
- **量级失真**：教室高 30 m、电视机功率 2000 W、人步行 10 m/s。见 5.1。
- **状态不清**："开关闭合后"没说哪个开关；"一段时间后"没说是否达到平衡或停止。
- **图文不一致**：图中滑片在 a 端，文字说在 b 端；电路图与实物图元件顺序不同。
- **概念性错误表述**："受到惯性的作用""温度高的物体含有的热量多""电流通过导体消耗了电流"。题干和答案里都不能出现。
- **精度未说明**：结果为循环小数却没要求保留位数。
- **选项中同时出现两个可辩护的答案**：如"减小误差"和"使结论具有普遍性"在一个探究实验里都选得过去时，要在题干点明实验类型。

## 8. 三层微型示例（八年级下·浮力：物体的浮沉条件）

课时目标：学生能综合运用阿基米德原理和漂浮条件，求浮力、排开液体体积或液体密度。

**A1（基础巩固，计算题）** 一个体积为 200 cm³ 的木块漂浮在水面上，浸入水中的体积为 120 cm³。g 取 10 N/kg，ρ水 = 1.0×10³ kg/m³。求木块受到的浮力。
- 答案：F浮 = ρ水gV排 = 1.0×10³ kg/m³ × 10 N/kg × 1.2×10⁻⁴ m³ = 1.2 N。
- 画像：k0 s3 c1（cm³→m³ 换算）r0 o0 g1。支架（可选）："先把浸入体积换算成 m³。"

**B1（能力提升，计算 + 说理）** 一个质量为 120 g、体积为 200 cm³ 的木块放入水中，静止后有一部分露出水面。(1) 说明木块静止时受到的浮力为什么等于它的重力；(2) 求露出水面的体积。g 取 10 N/kg。
- 答案：(1) 木块静止，处于平衡状态，竖直方向只受重力和浮力，二力平衡；(2) F浮 = G = 1.2 N，V排 = F浮/(ρ水g) = 1.2×10⁻⁴ m³ = 120 cm³，露出 200 − 120 = 80 cm³。
- 画像：k1 s5 c2 r0 o1 g2。
- upgrade：from A1，dims [c, g, o]，"浸入体积不再直接给出，要从'静止、部分露出'中识别漂浮状态，由 F浮=G 逆求 V排，并说明平衡理由"。

**C1（拓展挑战，探究 + 评价）** 把 B1 中的木块分别放入水和某液体中，静止时浸入的体积分别是 120 cm³ 和 150 cm³。(1) 求该液体的密度；(2) 木块是长方体，竖直漂浮。小明想在木块侧面标刻度，做成一个能直接读液体密度的"密度计"，他认为"刻度应该等间距"。你同意吗？用式子说明理由。
- 答案：(1) 两次都漂浮，浮力都等于重力，ρ水V1 = ρ液V2，ρ液 = 1.0×10³ × 120/150 = 0.8×10³ kg/m³；(2) 不同意。ρ液 = G/(gV排)，V排 = S·h浸，h浸 与 ρ液 成反比而不是一次函数关系，所以刻度不均匀（密度越大，刻度越密）。
- 画像：k2 s6 c2 r1 o1 g3。
- upgrade：from B1，dims [k, r, g]，"从一种液体推广到两种液体的比较，建立 ρ液 与 V排 的反比关系，并用它评价一个设计方案"。
- check.code（第 1 小问）：`rho_w = 1000; ans = rho_w*Rational(120, 150)`，expect `"800"`。木块密度 0.6 g/cm³、液体密度 0.8 g/cm³ 均在真实范围内。

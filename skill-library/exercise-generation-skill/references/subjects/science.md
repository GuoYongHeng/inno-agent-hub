# 小学科学 · 命题要点（science）

学科是小学科学（一至六年级）时必读。初中物理、化学、生物分别读 `physics.md`、`chemistry.md`、`biology.md`。

## 1. 课标锚点（2022 版义务教育科学课标，已核对原文）

### 1.1 核心素养与课程内容

- 核心素养：**科学观念、科学思维、探究实践、态度责任**。
  - 科学思维"主要包括模型建构、推理论证、创新思维等"。
  - 探究实践包括科学探究能力、技术与工程实践能力和自主学习能力。
  - 态度责任包括科学态度与社会责任。
- 课程内容：**13 个学科核心概念**（物质的结构与性质；物质的变化与化学反应；物质的运动与相互作用；能的转化与能量守恒；生命系统的构成层次；生物体的稳态与调节；生物与环境的相互关系；生命的延续与进化；宇宙中的地球；地球系统；人类活动与环境；技术、工程与社会；工程设计与物化）和 **4 个跨学科概念**（物质与能量、结构与功能、系统与模型、稳定与变化）。
- 学段：1–2 年级、3–4 年级、5–6 年级三段，内容要求和学业要求螺旋上升。

`objective` 写"知识点 + 素养表现"，例如"搅拌对溶解快慢的影响（探究实践·对比实验）""用影子长短变化解释一天中太阳位置的变化（科学思维·推理论证）"。

### 1.2 课标对作业和命题的要求（原文摘要）

- **作业分层**："作业难度要体现适切性。根据题目所要求的认知水平，可以将作业分成理解性、应用性、综合性、探究性和创新性等不同的层次"；"针对不同学生的发展水平和学习的不同阶段，设计不同层次的作业。强调在注重理解和应用的基础上，增加综合性、探究性和创新性作业"。
- **作业形式**："书面作业，如知识内容的巩固练习、单元练习等；动手操作类作业，如实验设计和探究、科学设计与制作等；主题学习的考察类作业，如参观科普场馆……调查类作业"。
- **单元评价**：重点考查学生"理解了什么"和"会做什么"；"要考虑用合适的时间和题量（或测试任务）来考评学生"。
- **期末评价**："测评题的材料尽可能来自生产生活实际，但情境要为学生所常见"。
- **命题规划**："避免机械记忆试题，减少客观性试题比例，提高探究性、开放性、综合性、表现性试题的比例"。
- **命题流程**："明确测评指标—预估试题的难度水平—确定测评题目的题型—确定试题情境和任务—确定测评题目的评分标准"。
- **认知水平三级**（原文）："低级水平，运用一个步骤的认知过程，如回忆事实、术语、概念或原理，或者从图表中读取某一个信息。中级水平：运用概念描述或解释现象，在需要两个或两个以上步骤的认知过程中制订适宜的程序，组织并展示数据，解释或运用数据及图表等。高级水平：分析复杂的信息或数据，整合或评价证据，确定各种不同信息资源的合理性，制订解决问题的计划或规划，以及方法、步骤、程序等。"

### 1.3 分层锚点

| 层 | 课标作业层次 | 认知水平 | 典型任务 |
|---|---|---|---|
| A 基础巩固 | 理解性、应用性 | 低级为主，至少一道中级 | 说出现象、读出记录单里的一个信息、用学过的概念解释一个熟悉现象 |
| B 能力提升 | 应用性、综合性 | 中级 | 比较两组实验得出结论、判断实验是否公平、整理数据画简单图表、解释一个新现象 |
| C 拓展挑战 | 探究性、创新性 | 中级到高级 | 设计对比实验、评价别人的方案、设计制作并改进、长周期观察 |

学段适配（与 `layering.md` 一致）：
- **1–2 年级不布置书面家庭作业。** 用户要的是课堂练习或实践活动时才出：以"看一看、摸一摸、说一说、画一画"为主，题量少，文字极短。
- **3–4 年级**：学业质量要求"能利用控制变量的方法设计简单的实验"，B 层开始出"公平不公平"的判断题，C 层出简单的对比实验设计。
- **5–6 年级**：学业质量要求"设计控制变量的实验方案""建立证据与观点之间的联系"，C 层可以要求完整的方案、预测和反思。

## 2. 科学出卷老师的组卷方法

1. **母题 = 一个可观察的现象 + 一个探究活动。** 例如"溶解"：观察食盐在水中消失 → 比较不同条件下溶解的快慢 → 设计对比实验。三层共用一个现象最自然。
2. **升级路线**（小学科学最常用）：
   - **观察 → 描述 → 比较 → 分类**：说出一个特征 → 用科学词汇描述 → 比较两个物体 → 按自定标准分类并说明标准。
   - **解释 → 预测**：用学过的概念解释看到的现象 → 预测换个条件会怎样。
   - **判断公平 → 设计实验**：判断一组实验是否只改变了一个条件 → 自己设计改变一个条件、保持其他条件不变的实验。
   - **读记录 → 整理数据 → 得出结论 → 质疑结论**：从记录表读一个数 → 求几次测量的平均 → 由数据得出结论 → 指出"只做一次不够可靠"。
   - **使用 → 设计 → 改进**（技术与工程）：说出工具的作用 → 按要求设计一个简单装置 → 根据测试结果提出改进。
3. **实践作业单独成项。** 种植、养殖、观察月相、记录天气这类长周期任务，写成"实践作业"，不计入一次作业的时长；一次作业里最多一项。
4. **不考死记硬背。** 课标明确要"避免机械记忆试题"。识记类题只放在 A 层第一、二题，而且要配一道"解释"题。

### 2.1 难度画像在小学科学里的含义

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| `k` | 一个概念 | 两个（溶解 + 对比实验方法） | 跨核心概念（物质 + 能量；生物 + 环境） |
| `c` | 信息直接给出 | 需读记录表、简单图表或图画描述 | 需自己发现：实验里不公平的地方、记录中不合理的数据、现象背后没说出的条件 |
| `r` | 课堂上做过的实验或观察 | 生活中常见的现象，需要联系课堂所学 | 陌生现象或工程任务（设计、制作、改进） |
| `o` | 唯一答案 | 说理由、多种合理答案 | 设计方案、开放探究 |
| `g` | 低级：回忆、读取一个信息 | 中级：描述、解释、整理数据 | 中高级：分析证据、评价方案 |

`g=3`：制订探究计划、设计并改进作品、评价不同方案。`s` 在小学一般是 1–4。

## 3. 题型与命题规范

| 题型 | 规范 |
|---|---|
| 选择题、判断题 | 题干短句；判断题不出"一定""所有"这类绝对化陷阱（小学生会在语言而不是科学上失分），除非考的就是"结论不能过度推广" |
| 填空、连线 | 科学词汇要与教材一致；连线题两侧数量不同，避免排除法 |
| 观察记录题 | 给出记录单格式（表格、画图框），要求"如实记录"；评分看记录是否具体（"叶子边缘有锯齿"而不是"叶子很好看"） |
| 画图表达 | 低中年级常用：画出观察到的现象、画电路连接、画影子位置。`figure` 写清给出的底图，答案写成"正确图的要点" |
| 实验探究题 | 用学生能懂的说法："改变的条件""不改变的条件""怎样知道结果"。3–4 年级可以说"对比实验""只改变一个条件"，5–6 年级可以用"控制变量" |
| 解释说理题 | 给出现象，问"为什么"；评分要点写"用到的科学概念 + 与现象的联系" |
| 设计制作题 | 写清任务目标、可用材料、限制条件（尺寸、时间、成本）、怎样测试效果 |
| 实践作业 | 写清任务、周期、记录方式、安全提示（见 5.2）、要交什么、评价要点 |

语言：按 `situation.md` 控制句长（中高段每句约 20 字以内）；不提前使用初中术语（小学说"物体""材料"，不说"物质的密度"；说"热传递"可以，但不出比热容计算）。

## 4. 题型谱（按学段与领域）

单元编排各版本不同（如教科版、苏教版），下表按课标领域列，课题名称为常见说法。

| 领域 | 学段 | 常见课题 | 常考题型 | 典型错因（可观察行为） |
|---|---|---|---|---|
| 物质 | 3–4 | 水的三态、空气、溶解、常见材料 | 现象解释、溶解快慢对比实验、材料性能比较 | 把"溶解"说成"消失了""融化了"；认为水结冰后质量变小；比较材料时一次改变两个条件 |

| 运动与能量 | 3–4 | 物体的运动、声音、简单电路、磁铁 | 电路连接判断、声音高低与振动、磁极相互作用 | 电路只连一端也认为灯会亮；把"声音大小"和"声音高低"混为一谈；认为所有金属都能被磁铁吸引 |
| 运动与能量 | 5–6 | 光、力与运动、简单机械、能量转换 | 影子方向判断、摆的快慢、杠杆省力判断 | 认为摆锤越重摆得越快；影子方向与光源方向画在同侧 |
| 生命 | 1–4 | 植物与动物的特征、植物的生长、动物的一生、人体（呼吸消化） | 观察记录、生命周期排序、结构与功能对应 | 把蚕的一生写成三个阶段（漏了"蛹"）；认为植物只需要阳光就能生长 |
| 生命 | 5–6 | 生物与环境、微小世界、生物的多样性 | 食物链、对比实验（光照对植物）、显微镜观察 | 食物链箭头方向画反；对比实验没有对照组 |
| 地球与宇宙 | 3–4 | 天气、太阳与影子、月相、岩石与土壤 | 天气记录、影子长短与方向、月相顺序 | 认为中午影子最长；月相变化顺序排错 |

| 技术与工程 | 全学段 | 工具使用、设计制作（小船、小车、保温杯、桥） | 设计方案、测试与改进 | 只写"做一个"不写测试办法；改进时同时改动多处，说不清是哪处起了作用 |

## 5. 情境与数据规则（重点）

### 5.1 现象和数据要真实

- **现象必须是学生真能观察到的。** 不设计"观察到糖在水中变成了小颗粒"这类实际看不到的现象。实验结果要与真实规律一致：搅拌、用温水、把颗粒弄小都会使溶解变快；摆的快慢主要与摆长有关，与摆锤轻重基本无关；中午前后影子最短；月相大约一个月（约 29.5 天）循环一次；蚕的一生经过卵、幼虫、蛹、成虫四个阶段。
- **数据要合理**（经验值）：通常情况下水约 0 ℃ 结冰、约 100 ℃ 沸腾；人体正常体温约 37 ℃；当地气温要符合季节；记录表中的数据要有正常的小波动，不要几次测量一模一样。题中数据如果是编的，写"（数据为虚构）"。
- **结论不能超出证据。** 只用一种材料、做一次实验得出的结论，不能写成"所有……都……"。
- **不编造动植物和天文事实。** 不确定就换成教材里的对象。

### 5.2 安全与材料（小学必须严格）

- **材料易得**：家庭实践作业只用家里常见、安全的东西：水、食盐、白糖、塑料杯、勺子、吸管、纸、橡皮泥、干电池（1.5 V）、小灯泡、种子、塑料瓶。课堂专用器材（酒精灯、显微镜、温度计）只出现在课堂练习里。
- **禁止出现在家庭作业里的操作**：使用明火、开水或酒精灯（溶解实验在家用温水，不用开水）；接触 220 V 家庭电路或插座；用导线直接连接电池两极（短路发热）；直视太阳或用放大镜对着太阳聚光；品尝、闻不明物质；触摸或捕捉野生动物、采摘不认识的植物；独自去水边、野外观察。
- **低年级注意误吞**：不让一、二年级学生在家使用纽扣电池、小磁珠、小颗粒材料。
- 需要家长配合的任务写明"请在家长陪同下完成"，但不要把作业变成家长的作业。
- 避免依赖家庭经济条件的任务（"去科技馆参观""网购材料"），给出替代方案。

### 5.3 情境闸门补充

科学题的情境常常就是实验或现象本身，这时不需要再套故事。"周末小明和妈妈去公园，看到……"如果删掉后不影响作答，就删掉。课标样题（湿毛巾拧瓶盖与"小心地滑"）是好例子：两个生活现象形成真实的矛盾，学生需要提出问题、设计实验，情境承担了认知任务。

## 6. 正确性验证

小学科学多数题用 `blind`：`blind_answer` 写答案要点，开放题写评分层次（写出 1 个合理条件得几分，写出完整方案得几分）。能计算的（几次测量的平均值、温度变化、简单统计）写 `check.code`：

```python
# 三次测得摆摆动 10 次所用时间（s）：15.2、14.8、15.0，求平均值和摆动 1 次的时间
times = [Rational(152, 10), Rational(148, 10), Rational(150, 10)]
avg = sum(times)/len(times)
ans = [avg, avg/10]                    # expect "[15, Rational(3,2)]"
```

注意：sympy 已占用一些常见名字（`I` 虚数单位、`E`、`N`、`S`、`Q`、`product`）。不要用它们作变量名或写在 `expect` 里；要用 itertools 的 `product`，就在 code 里先写 `from itertools import product`。

非计算题重点查两件事：
- **实验题**：对照的两组是不是只差一个条件；按题目给的现象，是不是只能得出一个结论。
- **观察、画图题**：只看 `figure` 的文字描述，学生能不能明白要观察或画什么。

## 7. 常见病题（审卷时重点查）

- **实验本身不公平**：示例或题干里的"正确实验"同时改变了两个条件（除非就是要学生找出来）。
- **现象不真实**：编出来的观察结果与实际不符（摆锤越重摆得越快、冬天中午影子最短）。
- **结论过度推广**：一次实验得出"所有……"。
- **超学段术语**：三年级题目里出现"控制变量""物理变化""比热容"。
- **只能看图作答**：`figure` 没写清，学生看不到图就无从下手。
- **不安全或不可得**：家庭作业要求用酒精灯、开水、插座，或用家里没有的材料。
- **1–2 年级出了书面家庭作业**。
- **评分标准缺失**：开放题和设计题没有分层次的评分要点。

## 8. 三层微型示例（三至四年级·溶解：影响溶解快慢的因素）

课时目标：学生能用对比实验（只改变一个条件）判断搅拌是否影响食盐溶解的快慢。（对应课标 3–4 年级活动建议"取等量的食盐，分别放入两个装有等量水的杯中，探究是否搅拌或温度高低对溶解快慢的影响"。各版本所在册次不同。）

**A1（基础巩固，选择题）** 想知道"搅拌能不能让食盐溶解得更快"，下面哪组实验是公平的？（　　）
A. 两杯水一样多，各放一小勺食盐，一杯搅拌，一杯不搅拌
B. 两杯水一样多，一杯放一小勺食盐并搅拌，一杯放两小勺食盐不搅拌
C. 一杯温水、一杯冷水，各放一小勺食盐，温水那杯搅拌
D. 一杯多、一杯少的水，各放一小勺食盐，都搅拌
- 答案：A。干扰项：B 对应"同时改变了食盐的多少"；C 对应"同时改变了水温"；D 对应"没有改变要研究的条件（都搅拌），却改变了水量"。
- 画像：k0 s2 c1 r0 o0 g1。

**B1（能力提升，分析说理）** 小红按 A 的方法做实验，记录如下（数据为虚构）：搅拌的一杯约 1 分钟全部溶解，不搅拌的一杯 5 分钟后杯底还有食盐。(1) 你能得出什么结论？(2) 小明说："我用温水搅拌、冷水不搅拌，也发现搅拌的溶解得快，所以搅拌能加快溶解。"他的说法有道理吗？为什么？
- 答案：(1) 搅拌能使食盐溶解得更快；(2) 没有道理。他的两杯水温度不同，又一杯搅拌一杯不搅拌，改变了两个条件，不知道是哪个条件让溶解变快的。
- 画像：k1 s4 c2 r0 o1 g2。

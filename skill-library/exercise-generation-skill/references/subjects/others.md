# 其他学科：信息科技、艺术、体育与健康、劳动、综合实践活动

学科是上面这些之一时必读。这些学科的书面作业很少，作业的主体是**实践性任务**：制作、调查、练习打卡、作品创作、编程。分层的思路和 `layering.md` 一致，即同一目标逐层进阶，但难度画像、任务单写法、评价和安全要另外处理。

## 1. 课标锚点

### 1.1 核心素养（原文摘要）

|---|---|---|

### 1.2 课标里现成的工具，直接借用

- **劳动任务单**（劳动课标示例）的栏目：劳动任务名称、要解决的问题、所需材料、工具与设备、方法与步骤、团队成员、完成时间、劳动计划或设计方案、劳动过程记录、劳动成果、劳动体会。**所有实践作业的任务单都可以按这个格式写。**
- **家庭劳动清单**（劳动课标三年级示例）：按项目列出，从"劳动参与"（偶尔参与、经常参与）和"劳动技能"（基本掌握、熟练掌握）两个维度打勾，再加劳动体会和家长评价。
- 课标里按学段给出的记录方式：1–2 年级用劳动绘本、劳动日志、星级自评、贴小红花；3–6 年级用劳动叙事、作品展示；7–9 年级可用劳动测试、评语评价等。
- 综合实践各方式的"关键要素"，可以直接当作任务步骤。以考察探究为例："发现并提出问题；提出假设，选择方法，研制工具；获取证据；提出解释或观念；交流、评价探究成果；反思和改进"。

## 2. 实践性作业怎么分层

三层仍然服务于**同一个课时目标**。学生版层名可以用"基础任务、拓展任务、创意任务"。

| 层 | 任务形态 | 学生的自主程度 |
|---|---|---|
| A 基础任务 | 按给定步骤完成一个标准任务：整理一个抽屉、练一组动作、临摹一幅作品、运行并读懂一段程序 | 给步骤、给材料、给示范 |
| B 拓展任务 | 同一技能换一个对象或条件，或者把两个技能组合起来；要记录过程并说明为什么这样做 | 给目标和约束，方法自选 |
| C 创意任务 | 自己发现问题、设计方案、创作作品，或者为他人服务；包含反思和改进 | 只给主题，问题和方案都自定 |

升级的维度（动结构，不只是"做更多"）：
- **自主程度**：照做 → 自选方法 → 自定问题
- **复杂度**：单一技能 → 技能组合 → 完整项目
- **情境**：课内模拟 → 家庭或校园中的真实情境 → 社区、为他人服务
- **表达**：交成品 → 说明设计理由 → 反思并改进（第二版）
- **持续性**（体育、劳动特有）：做一次 → 坚持一周并记录 → 养成习惯，再带动家人

**同一层次内不要用"做更多遍"来升级。**做 3 次和做 5 次是同层的平行任务。

### 2.1 难度画像在实践作业中的含义

| 键 | 含义 |
|---|---|
| `k` | 用到的技能或知识数：0 一项；1 两项组合；2 三项及以上，或跨学科 |
| `s` | 任务的主要环节数（准备、操作、记录、反思……），与任务单的步骤数大致一致 |
| `c` | 0 给出步骤和材料；1 只给目标和约束，要自己选材料、选方法；2 要自己发现问题或约束条件（如"先观察家里哪里最需要整理"） |
| `r` | 0 课内或模拟情境；1 家庭或校园中的真实情境；2 社区、陌生对象、为他人服务 |
| `o` | 0 有标准成品；1 方法可以不同；2 作品或方案开放 |
| `g` | 0 模仿；1 独立应用；2 分析、调整（找出问题并改进）；3 设计、创作、评价 |

## 3. 任务单写法（`type: "实践作业"`）

`stem` 里写全以下各项，学生拿到就能做，不用再问：

1. **任务**：一句话说明要完成什么、为了什么。
2. **材料与工具**：只列家里常见的东西，并给出替代方案（"没有量杯可以用矿泉水瓶盖代替"）。
3. **步骤或要求**：A 层写具体步骤；B、C 层写要求和约束。
4. **时长**：写清单次时长和持续天数，如"每天 10 分钟，连续 5 天"。
5. **安全提示**：见第 5 节，有风险就必须写。
6. **成果形式**：记录表、照片（写明拍什么，不拍人脸）、作品、不超过 1 分钟的视频、代码文件、口头汇报提纲，任选其一，并写清楚提交方式。
7. **自评标准**：把第 4 节量规里学生看得懂的部分写进去，让学生知道"做到什么样算好"。

教师版：`answer_points` 写量规；`solution` 写任务的关键环节和示范做法；`teacher_note` 写批改关注点和可能出现的问题；`check` 写 `blind`，`blind_answer` 记录你"走一遍任务"的结论（见第 7 节）。

## 4. 评价量规：分维度、分等级

每个实践作业都配一张 3–4 维 × 3 级的量规。维度从下面挑，不要超过 4 个：

| 维度 | 3 级（优秀） | 2 级（达标） | 1 级（待改进） |
|---|---|---|---|
| 完成度 | 按要求完成全部环节，成果完整 | 完成主要环节，有个别遗漏 | 只完成部分环节 |
| 技能规范 | 操作规范、熟练，没有安全问题 | 操作基本规范，偶有失误 | 操作不规范，需要指导 |
| 创意或设计 | 有自己的想法，并能说明理由 | 在示例基础上做了调整 | 照搬示例 |
| 反思与改进 | 能指出问题并提出（或做出）改进 | 能说出做得好和不好的地方 | 没有反思 |
| 坚持性（体育、劳动） | 按计划完成全部天数并如实记录 | 完成大部分天数 | 完成少于一半 |

- **体育**以"和自己比的进步"为主要标准，不用统一的成绩线给学生定等级。体质差异大，统一标准会让一部分学生永远拿不到高分。
- **艺术**评价过程和成品并重；"好看不好看"不能作为唯一标准，要看是否用到了本课的表现手法、能否说明自己的创作意图。
- **劳动**按课标的侧重点评价：日常生活劳动侧重卫生习惯和生活能力，生产劳动侧重工具使用、技能和质量意识，服务性劳动侧重服务意识和社会责任感。可以让家长参与评价。
- 量规里每一级都要能观察到，不写"态度认真"这种没法判断的话。

## 5. 安全与可行性（布置前逐项检查）

- **安全**：刀具、明火、热油、热水、电器、高处、化学品（消毒液配比）、户外水域，涉及哪一项，就写明"在家长陪同下完成"，并给出具体的防护做法。小学低段不布置用刀、用火的任务。体育作业写清楚热身和运动强度，提醒"身体不适立即停止"，不布置有危险的动作。
- **材料易得、零成本或低成本**：不要求购买专门的材料，不比谁的材料更贵。
- **家庭条件差异**：不假设每个家庭都有电脑、打印机、网络、宽敞的空间或会陪伴的家长。信息科技的家庭作业要提供**不用设备的版本**（纸笔模拟算法、手工编码）；需要家长参与的，也要提供学生能独立完成的替代方案。
- **时长**：实践作业的时长要计入当天作业总量（见 `layering.md` 3.1），按学生的速度估算，包括准备和收拾的时间。
- **隐私**：照片和视频不拍人脸，不拍家庭内部的隐私；采访要先征得对方同意，记录中的人名用化名。
- **防止家长代劳**：任务要设计成学生能独立完成的规模。评价时看过程记录，不只看成品。

## 6. 各学科要点

- **信息科技**
  - 书面题：概念辨析，数据与编码（如二进制、编码规则），读流程图写结果，信息安全与隐私情境判断（参照 `politics.md` 的辨析题写法）。
  - 编程题：分层路线是读程序写结果（A）→ 补全或修改程序（B）→ 独立编写、调试，并说明算法思路（C）。题干写清输入、输出格式，并给一组样例。课标没有指定编程语言；经验做法是小学多用图形化编程，初中多用 Python。用户没说时按 Python 出，写进 `assumptions`。
  - 验算：编程题、读程序题写 `check.method: "python"`，在 `code` 里运行参考程序，算出 `ans`（见下例）。
- **艺术**
  - 欣赏评述按"描述 → 分析 → 解释 → 评价"四步设问。
  - 涉及具体作品时，作品名、作者、年代、流派必须准确，没把握就不点名，或者改用"一幅山水画（描述如下）"。
  - 不要求学生下载付费音乐或视频。
  - 创作任务写清用到本课哪一种表现手法。
- **体育与健康**
  - 练习打卡写清动作、组数、次数或时长、休息时间。
  - 健康知识题可以有书面题，但不要编造医学数据。
  - 课标要求"每天校内锻炼 1 小时、校外锻炼 1 小时"，体育家庭作业是这 1 小时的一部分，不另加负担。
- **劳动**
  - 按任务群选项目，如清洁与卫生、整理与收纳、烹饪与营养。
  - 体现持续性：用一周的劳动清单记录。
  - C 层多为服务他人，如为家人做一顿早餐，为社区做一次志愿服务。
- **综合实践活动**
  - 按考察探究、社会服务、设计制作、职业体验来设计，步骤直接用 1.2 节里的"关键要素"。
  - 一般是长作业（一周到一个月），给出阶段节点。

```python
# 信息科技：读程序写结果 / 编程题的验算——运行参考程序，结果赋给 ans
def f(n):                      # 题中的程序：求 1 到 n 中能被 3 整除的数之和
    s = 0
    for i in range(1, n + 1):
        if i % 3 == 0:
            s += i
    return s
ans = [f(10), f(20)]           # 题中两组样例输入的输出，expect "[18, 63]"
```

## 7. 正确性与可行性验证

- 书面题、编程题按 `verification.md` 处理。编程题还要用至少一组**边界输入**跑一遍参考程序，比如 0、1、最大值、空输入，确认题目对这些输入有明确的要求。
- 实践作业写 `blind`。试做的方式是**在纸面上"走一遍任务"**，在 `blind_answer` 里记录：
  1. 材料在一般家庭里能找齐吗？没有时有替代吗？
  2. 按学生的速度，实际要多久？是否超出预算？
  3. 每一步有什么安全风险？提示写了吗？
  4. 成果能按量规评价吗？量规每一级都能观察到吗？
  5. 学生能独立完成吗？
- 有一项不过，就改任务单。

## 8. 三层微型示例（三年级劳动·整理与收纳）

课时目标：学生能按"分类—定位—标识"的方法整理自己的学习用品，并保持整洁。

- **A1 基础任务**：按"先倒空、再分类（书本、文具、杂物）、最后放回固定位置"三步，整理自己的书包或书桌抽屉；拍一张整理后的照片（不拍人脸），在劳动清单上打勾。时长 15 分钟。画像 k0 s3 c0 r1 o0 g1。
- **B1 拓展任务**：连续 5 天，每天放学后用 3 分钟检查书桌，记录"有没有乱、乱在哪里"；第 5 天写一句话：最容易乱的是什么，为什么，你打算怎么改。升级：相对 A1，从"按步骤整理一次"变为"持续观察，并找出原因"（`dims: s, c, g`）。画像 k1 s4 c1 r1 o1 g2。
- **C1 创意任务**：针对 B1 发现的问题，用家里的废旧纸盒等材料，给书桌做一个分格收纳或标签方案，用一周后说说效果，以及还要怎么改。升级：相对 B1，从"找出问题"变为"设计并检验解决办法"（`dims: o, g, k`）。画像 k2 s5 c2 r1 o2 g3。安全提示：用剪刀时请家长在旁边。
- 量规：完成度、技能规范、坚持性（B1）、创意与改进（C1），各分 3 级，见第 4 节。

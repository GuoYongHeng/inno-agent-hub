# 化学 · 命题要点（chemistry）

学科是化学（初中九年级，高中必修与选择性必修）时必读。小学科学里的"物质的变化"读 `science.md`。

---

## 1. 课标锚点

### 1.1 核心素养（写 `objective` 时用学段对应的说法）

| 学段 | 核心素养 |
|---|---|
| 初中（2022 版义务教育课标） | 化学观念、科学思维、科学探究与实践、科学态度与责任 |
| 高中（2017 年版课标，已核对；2020 修订版未核实） | 宏观辨识与微观探析、变化观念与平衡思想、证据推理与模型认知、科学探究与创新意识、科学态度与社会责任 |

`objective` 写"知识点 + 素养表现"，例如"用质量守恒定律解释反应前后质量变化（化学观念·元素守恒）""由离子反应现象推断溶液成分（证据推理与模型认知）"。初中不要用高中五条的说法。

初中课程内容分 5 个学习主题（原文）："科学探究与化学实验""物质的性质与应用""物质的组成与结构""物质的化学变化""化学与社会·跨学科实践"。

**初中学生必做实验（课标附录 4，原文 8 个）**：粗盐中难溶性杂质的去除；氧气的实验室制取与性质；二氧化碳的实验室制取与性质；常见金属的物理性质和化学性质；常见酸、碱的化学性质；一定溶质质量分数的氯化钠溶液的配制；水的组成及变化的探究；燃烧条件的探究。**实验题优先围绕这 8 个实验命题。**

### 1.2 课标对作业和命题的要求（原文摘要）

**2022 版义务教育化学课标**
- 作业："保证基础性作业，增加实践性作业、弹性作业和跨学科作业"；单元作业"体现整体性、多样性、选择性和进阶性"；"合理规划课时作业和单元练习的任务水平及比例，适当增加迁移创新水平的任务"；可增加"科普阅读、动手实践、实验探究等综合实践型作业"。
- 教学与评价："注意设计真实情境下不同陌生度和复杂度的问题解决活动"；"针对同一核心内容的评价目标及要求需具有进阶性，体现不同的能力层级水平"。
- 情境素材：关注"真实性、适用性和包容性，确保信息的权威性，杜绝政治性和科学性错误"；"根据题目的预设难度调整素材的陌生度和复杂度，与问题（任务）类型相匹配"。
- 任务类型：设计考查"辨识记忆、概括关联、分析解释、推论预测、简单设计、综合问题解决等多种任务类型的试题"；"设计连线、作图等多种试题作答形式，适当增大试题的开放度"。
- 学业质量（节选）：能"用相对原子质量、相对分子质量进行物质组成的简单计算"；能"依据质量守恒定律，用化学方程式表征简单的化学反应，结合真实情境中物质的转化进行简单计算"；能"依据物质类别及变化特征、元素守恒、金属活动性顺序等，预测、判断与分析常见物质的性质和物质转化的产物"。

**普通高中化学课标（2017 年版，已核对原文；2020 修订版此处未核实是否改动）**
- "化学学业质量水平划分为 4 级"；"学业质量水平 2 是高中毕业生在本学科应该达到的合格要求，是化学学业水平合格性考试的命题依据；学业质量水平 4 则是化学学业水平等级性考试的命题依据"。
- 命题原则：以真实情境为测试载体，形成"具有不同陌生度"的测试载体；以实际问题为测试任务，形成"具有不同复杂程度和结构合理的测试任务"；"在同一个测试目标下，可以创设不同的真实情境，提出不同复杂程度和结构合理的实际问题，形成不同难度的测试任务"。这正是分层作业"同一目标、三层进阶"的依据。

### 1.3 分层锚点

化学课标把难度拆成两个旋钮：**素材的陌生度**和**问题的复杂度**。对应到画像：陌生度 → `r`；复杂度 → `k`、`s`、`c`。六种任务类型对应认知要求：

| 课标任务类型 | `g` | 典型问法 |
|---|---|---|
| 辨识记忆 | 0 | 写出化学式、判断物质类别、说出现象 |
| 概括关联 | 1 | 归纳同类物质的共性、把性质和用途对应 |
| 分析解释 | 1–2 | 用微粒观点解释现象、说明实验操作的原因 |
| 推论预测 | 2 | 根据金属活动性、复分解条件预测反应能否发生和产物 |
| 简单设计 | 2–3 | 设计检验、除杂、鉴别方案 |
| 综合问题解决 | 3 | 流程分析、方案评价、陌生情境中的定量与定性综合 |

- 初中：A 层 = 熟悉素材 + 辨识记忆、概括关联；B 层 = 熟悉素材 + 分析解释、推论预测；C 层 = 较陌生素材 + 简单设计或综合问题解决。
- 高中：A ≈ 水平 2（合格考），B ≈ 水平 3，C ≈ 水平 3–4（等级考）。化学只有 4 级，不要照搬数学"水平一/二/三"的说法。

## 2. 化学出卷老师的组卷方法

1. **母题 = 一个反应（或一类物质）+ 一个实验。** 例如"实验室制二氧化碳"可以串起药品选择、装置、检验、计算和误差分析。三层围绕同一个反应展开。
2. **化学特有的升级路线**：
   - **三重表征递进**：宏观现象 → 微观解释（分子、原子、离子）→ 符号表征（化学式、方程式）→ 三者互译（看微观示意图写方程式）。
   - **正向 → 逆向**：给反应物写产物和现象 → 由现象推断物质（推断题）→ 由结论反推实验设计。
   - **纯净物 → 混合物**：纯净物计算 → 含杂质样品计算 → 溶液中的反应（溶质质量分数）→ 用质量差、图像、表格数据计算。
   - **理想 → 真实**：先在"杂质不反应、忽略挥发"的理想条件下算，再分析真实实验中误差的来源和方向。
   - **熟悉物质 → 陌生物质**：先考教材中的反应，再给"资料卡"让学生类比迁移（已知 CO₂ 与澄清石灰水的反应，类比 SO₂）。这是提高 `r` 的主要办法。
   - **定性 → 定量**：判断能否反应 → 计算生成多少 → 判断反应后溶液中溶质成分（"是否过量"需要讨论）。
   - **会做 → 会评**：评价方案的优劣（安全、环保、成本、操作简便），指出实验设计缺陷。
3. **反向设计数据**：先定一个规整的答案（生成 4.4 g CO₂、质量分数 90%），按教材常用相对原子质量倒推已知量，再用第 6 节的代码验算。
4. **不靠运算量升级**：把样品质量从 10 g 改成 12.37 g 不算升级。
5. **题干必须给出"可能用到的相对原子质量"**，只列本题要用到的元素。

### 2.1 难度画像在化学里的含义

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| `k` | 一个知识点（写化学式） | 两个（化学方程式 + 溶质质量分数） | 三个及以上（推断 + 方程式 + 计算 + 实验评价） |
| `c` | 反应物、条件、数据直接给出 | 需读溶解度曲线、pH 曲线、标签、表格、装置图、微观示意图，或把文字转成物质 | **隐含**：要自己发现"恰好完全反应""质量减少的是逸出的气体""杂质不参与反应""过量的是哪种"，或从现象推出物质，或题中有干扰信息 |
| `r` | 教材经典反应和实验 | 熟悉的生活或生产情境，需要自己找出其中的化学反应（除水垢、自热食品、铁生锈） | 陌生物质或陌生工艺（资料卡、工艺流程、新材料、科研情境） |
| `o` | 唯一答案 | 需解释原因、说明理由，或有多种合理方案 | 开放设计（检验、除杂方案）、方案评价 |
| `g` | 辨识记忆 | 概括关联、简单应用 | 分析解释、推论预测 |

`g=3`：简单设计、综合问题解决、评价方案。`s` 按解析的必要环节数：写方程式、找比例关系、换算、列式、求解、判断，各算一步。

## 3. 题型与命题规范

| 题型 | 规范 |
|---|---|
| 选择题 | 四选一。干扰项各对应一个错因：**现象与结论混淆**（"铁丝燃烧生成四氧化三铁"当现象）、**价态错误**（铁与盐酸生成 FeCl₃）、**条件忽略**（不加催化剂、不点燃）、**守恒误用**（把"质量守恒"用于物理变化）、**微粒混淆**（分子、原子、离子、元素）。"下列说法**不正确**的是"要加着重号 |
| 化学用语填空 | 元素符号首字母大写；离子符号数字在前、正负号在后（Fe³⁺、SO₄²⁻）；化合价标在元素符号正上方，正负号在前（+3）；"2H"与"H₂"区分清楚。学生版用 Unicode 上下标（H₂O、CO₃²⁻），`check.code` 里用 ASCII（"H2O"） |
| 化学方程式 | 见 3.1 |
| 计算题 | 见 3.2 |
| 实验探究题 | 按"提出问题 → 猜想 → 设计方案 → 现象 → 结论 → 反思"组织。要求学生写"现象"时，答案只写看得见的变化，不写产物名称；"结论"写物质或规律。对照实验要说明对照组 |
| 推断题 | 突破口（颜色、沉淀、气体、特殊反应条件）要唯一；做完后**把推出的物质代回每一步**检查是否全部吻合（门禁 B）。初中推断题物质限定在课标要求的常见物质内 |
| 流程题 | 每一步的物质和操作都要真实可行；问题指向"这一步加入什么、发生什么反应、操作名称、某物质的作用"；不考陌生的工业参数 |
| 图像题 | 溶解度曲线、反应进程曲线（质量、pH、温度随时间或加入量变化）。曲线起点、拐点、终点要与化学事实一致（如向酸中加碱，pH 从小于 7 开始） |
| 科普阅读题 | 材料来自真实资料或标"（材料为虚构）"；问题指向从材料中提取化学信息并用所学知识解释 |

### 3.1 化学方程式书写规范

- 四个要件：化学式正确、配平、**反应条件**（点燃、加热用"△"、高温、通电、催化剂写在等号上方）、**状态符号**。
- ↑：反应物中没有气体而生成气体时标；↓：溶液中的反应生成沉淀时标。反应物中有气体时，生成的气体不标↑。
- 初中用"＝"；高中可逆反应用"⇌"，有机反应常用"→"，离子方程式要满足原子守恒和电荷守恒。
- 不出现教材没有、也没在题干资料中给出的反应。配平和守恒用第 6 节的代码检查。

### 3.2 计算题书写规范（初中人教版格式，经验做法）

- **设—写—找—列—求—答**：设未知量（"设生成二氧化碳的质量为 x"，x 不带单位）；写出化学方程式；在相关物质的化学式下方写出"相对分子质量×化学计量数"和已知量、未知量（已知量带单位）；列比例式；求解（结果带单位）；简明作答。
- 代入方程式的必须是**纯净物的质量**。含杂质样品、溶液要先换算成纯物质质量，这是最高频错因。
- 溶液计算：溶质质量分数 = 溶质质量/溶液质量 × 100%；反应后溶液质量 = 反应前总质量 − 气体质量 − 沉淀质量 − 不溶杂质质量。
- 高中计算以物质的量为中心（n = m/M = V/Vm = cV），气体体积要写明"标准状况"，结果按题给有效数字要求。

## 4. 题型谱（按学段）

### 4.1 初中（按主题列，单元编号各版本不同，不写）

| 主题 | 常考题型 | 典型错因（可观察行为） |
|---|---|---|
| 化学实验基本操作 | 操作图辨析、仪器名称、错误操作的后果 | 胶头滴管伸入试管；加热固体时试管口向上；量筒仰视俯视读数偏差方向判断反 |
| 空气和氧气 | 空气成分、测定氧气含量实验误差、氧气性质与制取、装置选择 | 测氧气含量时用木炭或硫代替红磷；把"排水法收集"与"向上排空气法"的选择依据弄反；铁丝燃烧现象写成"产生火焰" |
| 水 | 电解水、水的净化、硬水软水 | 电解水正负极气体及体积比记反；认为过滤能把硬水软化；把"吸附"说成化学变化 |
| 物质构成的奥秘 | 分子原子离子、原子结构示意图、元素周期表信息 | 认为"分子大，原子小"；元素与原子混用（"水由两个氢元素组成"）；相对原子质量带单位 g |
| 化学式与化合价 | 化学式意义、化合价计算、相对分子质量和元素质量分数 | 化合价代数和不为零；把"2O"读成"两个氧分子"；质量分数忘记乘原子个数 |
| 质量守恒定律与化学方程式 | 微观示意图、守恒解释、方程式书写配平、简单计算 | 用质量守恒解释物理变化；有气体参与或生成的敞口实验说"不守恒"；把混合物质量代入方程式 |
| 碳和碳的氧化物 | 单质碳的性质、CO 与 CO₂ 性质对比、CO₂ 制取与检验 | 用燃着的木条检验 CO₂（只能验满）；CO 还原氧化铁先加热后通气；用稀硫酸和大理石制 CO₂ |
| 燃料与燃烧 | 燃烧条件探究、灭火原理、能源 | 把"降低温度到着火点以下"写成"降低着火点"；控制变量时同时改变两个条件 |
| 金属和金属材料 | 金属活动性顺序、置换反应、金属与盐溶液反应后滤渣滤液成分、锈蚀条件 | 铁与酸生成 FeCl₃；认为铜能置换出酸中的氢；滤渣滤液成分不按"先后顺序"分析 |
| 溶液 | 溶解度曲线、饱和与不饱和转化、溶质质量分数计算、配制溶液 | 不指明温度比较溶解度；稀释时溶质质量不变用错；配制时把量取的水当成溶液质量 |
| 常见的酸和碱 | 酸碱通性、指示剂、中和反应、pH 曲线 | 认为"生成盐和水的反应都是中和反应"；pH 曲线起点判断错；把"酚酞不变色"当成"溶液呈中性"（也可能呈酸性） |
| 盐和化肥 | 复分解反应条件、离子共存、物质鉴别与除杂、化肥 | 只看生成物不看反应物是否可溶；除杂引入新杂质；铵态氮肥与碱性物质混用 |
| 化学与社会 | 营养物质、材料分类、环境保护 | 把合金归为合成材料；把"甲醛浸泡食品"之类的错误做法判为可行 |

## 5. 情境与数据规则（重点）

### 5.1 化学事实必须真实

- **不编造反应。** 只用教材中出现过的反应，或题干"资料卡"中给出的真实反应。不确定的反应（能否发生、产物是什么、条件是什么），有搜索工具就核对，没有就不用。常见编造：铜与稀盐酸或稀硫酸反应；铁与盐酸生成 FeCl₃；铁在氧气中燃烧生成 Fe₂O₃；硝酸钾、硝酸钠在初中复分解中"参加反应生成沉淀"；碳酸钙与稀硫酸持续反应制 CO₂。
- **反应条件要对。** 点燃（燃烧）、加热（KMnO₄、KClO₃ 分解）、高温（CaCO₃ 分解、C 还原 CuO）、通电（电解水）、催化剂（H₂O₂ 分解用 MnO₂）。
- **现象要真实且规范描述**（经验做法，按人教版教材常见表述）：

| 实验 | 规范现象 |
|---|---|
| 木炭在氧气中燃烧 | 发出白光，放热，生成能使澄清石灰水变浑浊的气体 |
| 硫燃烧 | 在空气中发出淡蓝色火焰，在氧气中发出蓝紫色火焰，生成有刺激性气味的气体 |
| 红磷燃烧 | 产生大量白烟，放热 |
| 铁丝在氧气中燃烧 | 剧烈燃烧，火星四射，放热，生成黑色固体（**没有火焰**） |
| 镁条燃烧 | 发出耀眼的白光，生成白色固体 |
| 铁钉放入硫酸铜溶液 | 铁钉表面有红色固体析出，溶液由蓝色逐渐变为浅绿色 |
| 酸碱指示剂 | 紫色石蕊遇酸变红、遇碱变蓝；无色酚酞遇碱变红、遇酸和中性溶液不变色 |
| 铁锈与稀盐酸 | 铁锈逐渐消失，溶液由无色变为黄色 |
| 常见沉淀颜色 | Cu(OH)₂ 蓝色；Fe(OH)₃ 红褐色；CaCO₃、BaSO₄、AgCl 白色（后两者不溶于稀硝酸） |

- **物质性质要真实**：颜色、状态、气味、溶解性、毒性（CO 有毒、甲醛有毒）以教材为准。不要写"某金属呈绿色"之类的设定，除非是资料卡给出的真实物质。
- **相对原子质量**用教材附表的常用值，并写进题干（以题目给出为准）：H 1，C 12，N 14，O 16，Na 23，Mg 24，Al 27，S 32，Cl 35.5，K 39，Ca 40，Mn 55，Fe 56，Cu 64，Zn 65，Ag 108，Ba 137。
- **溶液浓度要真实**：题中的"稀盐酸"质量分数一般在 20% 以下（常用 7.3%、10%、14.6%），浓盐酸约 36%–38%；稀硫酸常用 9.8%、19.6%；过氧化氢溶液常用 3%–10%。数据倒推出来的浓度超出这些范围，就要调整题中用量。
- **用到非本课的方程式时，题干要给出**：不是本课新学、学生也未必记得的反应（比如本课学利用方程式计算，题目却用了碳酸钙与盐酸的反应），就在题干里给出化学方程式，避免考查目标被"会不会写这个方程式"干扰。
- **数据自洽**：样品中某成分的质量分数不能超过 100%；生成气体质量不能超过理论最大值；溶液质量分数不能超过该温度下饱和溶液的质量分数；天然样品的组成要大致合理（鸡蛋壳、石灰石中 CaCO₃ 一般在 80% 以上，写成 30% 就失真）。

### 5.2 安全规范（不设计危险实验）

- 实验题的操作要符合规范：稀释浓硫酸是"酸入水、沿器壁、慢慢倒、不断搅"；点燃可燃性气体前要验纯；加热固体时试管口略向下倾斜；CO 实验有尾气处理。题目里出现错误操作时，只能作为"找错""判断后果"的对象。
- **家庭小实验、实践作业**只用家中常见且安全的材料：食醋、小苏打、食用碱、食盐、白糖、鸡蛋壳、紫甘蓝汁、柠檬汁、铁钉、塑料瓶等。要求在家长陪同下进行，不使用明火或只在成人陪同下使用蜡烛。
- **禁止**出现在实践作业里：混合含氯消毒液与洁厕剂（会产生氯气）；在家制取或点燃氢气；使用浓酸、浓碱、强氧化剂；品尝、闻（扇闻法除外）任何实验药品；收集和燃烧燃气。
- 涉及食品安全、药品的题目，不给出具体的"家庭用药方案"。

### 5.3 情境闸门在化学里的补充

- 删除测试：把"某工厂""某同学在家"删掉后，题目只剩方程式计算的，情境就是装饰。真正承担认知任务的化学情境是：需要学生自己判断"发生了什么反应""哪部分质量对应哪种物质""这样做有什么问题"。
- 工艺流程和科研情境（新型催化剂、碳捕集）里的具体数值，核对过才写真实来源，否则写"（数据为虚构）"。品牌、厂名一律用泛称。

## 6. 正确性验证

`verify_items.py` 已执行 `from sympy import *`。注意：sympy 已占用一些常见名字（`I` 虚数单位、`E`、`N`、`S`、`Q`、`product`）。不要用它们作变量名或写在 `expect` 里；要用 itertools 的 `product`，就在 code 里先写 `from itertools import product`。

化学验算工具已经放在 `scripts/chem_tools.py`（原子计数、配平、相对分子质量，已在 sympy 1.14 下跑通），在 `check.code` 开头 import 即可：

```python
from chem_tools import atoms, balance, mr, AR   # 工具在 scripts/chem_tools.py，验算时可直接 import
```

用法（接在上面代码后面）：

```python
# 1) 检查答案稿里的系数：2KMnO4 =△= K2MnO4 + MnO2 + O2↑
ans = balance(["KMnO4"], ["K2MnO4", "MnO2", "O2"]) == [2, 1, 1, 1]          # expect "True"

# 2) 求配平系数（与答案对照）；高中离子方程式同时检查电荷守恒
ans = [balance(["Fe2O3", "CO"], ["Fe", "CO2"]),
       balance(["C2H5OH", "O2"], ["CO2", "H2O"]),
       balance(["Cu", "H[+]", "NO3[-]"], ["Cu[2+]", "NO", "H2O"])]
# expect "[[1,3,2,3],[1,3,2,3],[3,8,2,3,2,4]]"

# 3) 方程式计算：50 g 7.3% 稀盐酸与足量碳酸钙反应生成 CO2 的质量
Ar = {'H': 1, 'C': 12, 'O': 16, 'Cl': Rational(71, 2), 'Ca': 40}    # 题干给出
Mr = lambda f: mr(f, Ar)
coef = balance(["CaCO3", "HCl"], ["CaCl2", "H2O", "CO2"])           # [1, 2, 1, 1, 1]
m_HCl = 50*Rational(73, 1000)
ans = m_HCl/(coef[1]*Mr("HCl"))*coef[4]*Mr("CO2")                  # expect "Rational(11,5)"，即 2.2 g
```

更多要点：
- `balance` 返回 `None`，说明写的反应物或生成物不对（或者这个"反应"可以按多种比例配平，题目本身有问题），不要硬配。
- **能配平不等于反应存在。** 实测 `balance(["Fe","HCl"],["FeCl3","H2"])` 和 `balance(["Cu","HCl"],["CuCl2","H2"])` 都能给出系数。程序只查守恒，反应是否发生、产物价态对不对，要按 5.1 逐条人工核对。
- 溶解度、溶液配制、元素质量分数都用 `Mr` 和 `Rational` 算；Cl 写 `Rational(71, 2)`，不用浮点数 35.5，避免舍入误差。
- 推断题：把推出的物质代回每一步，用 `balance` 检查每个反应都能配平；颜色、状态等条件写在 `blind_answer` 里逐条核对。实验现象、方案设计、评价题用 `blind`。

## 7. 常见病题（审卷时重点查）

- **反应不存在或产物错**：见 5.1 的编造清单。
- **"恰好完全反应""足量""过量"没写清**：不知道该用哪种物质的量来计算，或反应后溶质成分有多种可能。
- **混合物当纯净物**：已知条件给的是溶液质量或样品质量，答案却直接代入方程式。
- **理想化条件缺失**：用"反应后总质量减少"求 CO₂ 时，没写"忽略水分蒸发和盐酸挥发"；用"杂质"时没写"杂质不溶于水也不参与反应"。
- **现象与结论混写**：答案把"生成二氧化碳"写进"现象"一栏。
- **溶解度没指明温度**、溶液没说是否饱和。
- **数据不自洽**：质量分数超过 100%；按方程式算出的沉淀质量与题给数据矛盾；溶液质量分数超过该温度下的饱和值。
- **相对原子质量没给**，或给了 35.5 却按 35 算。
- **实验图与文字不一致**：装置图中长颈漏斗下端没伸入液面以下，题干却说"装置气密性良好、可以收集气体"。
- **选择题两个选项都对**：如"用肥皂水区分硬水和软水"与"用煮沸的方法降低水的硬度"同时出现在"说法正确的是"里。

## 8. 三层微型示例（九年级上·利用化学方程式的简单计算）

课时目标：学生能根据化学方程式，由一种物质的质量计算另一种物质的质量，并能处理含杂质样品。

**A1（基础巩固，计算题）** 用 10 g 碳酸钙与足量稀盐酸反应，最多能生成二氧化碳多少克？（可能用到的相对原子质量：C 12，O 16，Ca 40）
- 答案：CaCO₃ + 2HCl ＝ CaCl₂ + H₂O + CO₂↑，100/44 = 10 g/x，x = 4.4 g。
- 画像：k0 s4 c0 r0 o0 g1。支架（可选）："先写出化学方程式，再在 CaCO₃ 和 CO₂ 下方写出相对分子质量。"

**B1（能力提升，计算题）** 为测定鸡蛋壳中碳酸钙的含量，取 10 g 鸡蛋壳放入烧杯，加入足量稀盐酸，充分反应后烧杯中物质的总质量减少了 3.96 g。（鸡蛋壳中其他成分不溶于水，也不与盐酸反应；忽略水分蒸发和盐酸挥发。）求鸡蛋壳中碳酸钙的质量分数。
- 答案：质量减少的 3.96 g 是逸出的 CO₂；100/44 = x/3.96 g，x = 9 g；质量分数 9 g/10 g × 100% = 90%。
- 画像：k1 s5 c2 r1 o0 g2。
- upgrade：from A1，dims [c, k, r]，"已知量不再是纯净物的质量，要自己发现'减少的质量就是 CO₂'，再由纯物质质量求样品中的质量分数"。
- 数据真实性：鸡蛋壳中碳酸钙含量通常在 90% 左右（经验值），本题数据为虚构但合理。
- check.code：`x = Rational(396, 100)*100/44; ans = [x, x/10*100]`，expect `"[9, 90]"`。

**C1（拓展挑战，探究与评价）** 某小组按 B1 的方法实际操作，测得的碳酸钙质量分数比真实值偏大。(1) 指出一个可能的原因，并说明它为什么使结果偏大；(2) 提出一项改进措施。
- 参考答案要点：(1) 逸出的 CO₂ 带走了水蒸气（或盐酸挥发出氯化氢），使减少的质量大于真实的 CO₂ 质量，算出的碳酸钙偏多（2 分：原因 1 分，推理链 1 分）；(2) 改用锥形瓶，在瓶口连接装有干燥剂的干燥管，吸收逸出的水蒸气（答出"吸水且不吸收 CO₂ 的干燥剂"即可，不要求写出具体名称；写氢氧化钠固体不给分，因为它也吸收 CO₂）；或使用较稀的盐酸（1 分，措施要与所述原因对应）。
- 画像：k2 s4 c2 r1 o2 g3。
- upgrade：from B1，dims [o, g, k]，"从理想条件下的计算转到真实实验，要分析误差的来源和方向，并设计对应的改进"。
- check：`blind`。注意：不能接受"用碱石灰吸收水蒸气"，碱石灰也会吸收 CO₂，写进批改关注点。

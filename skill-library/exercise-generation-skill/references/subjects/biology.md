## 1. 课标锚点

### 1.1 核心素养（写 `objective` 时用学段对应的说法）

| 学段 | 核心素养 |
|---|---|
| 初中（2022 版义务教育生物学课标，已核对原文） | 生命观念（结构与功能观、物质与能量观、进化与适应观、生态观等）、科学思维、探究实践、态度责任 |
| 高中（2017 年版课标，已核对原文；2020 修订版未核实是否改动） | 生命观念、科学思维、科学探究、社会责任 |

注意：初中是"探究实践、态度责任"，高中是"科学探究、社会责任"，不要混用。`objective` 写"知识点 + 素养表现"，例如"根据叶片结构解释其适于光合作用（生命观念·结构与功能观）""从对照实验中找出变量并得出结论（探究实践）"。

初中 7 个学习主题（原文）："生物体的结构层次""生物的多样性""生物与环境""植物的生活""人体生理与健康""遗传与进化""生物学与社会·跨学科实践"。前 6 个约占总课时 90%，最后一个约占 10%。

### 1.2 课标对作业和命题的要求（原文摘要）

**2022 版义务教育生物学课标**

- 设问："题目以简洁、清晰的图文呈现，设问要与问题情境紧密关联，问题要求明确，有清晰的层次和严谨的逻辑"。

- 学业质量列出四类问题情境：与健康和疾病相关、与生物资源开发和利用有关、与生物和环境有关、与生物技术有关。每类的行为动词都呈"识别、描述 → 分析、推测 → 提出方案、辩证分析"的递进。

**普通高中生物学课标（2017 年版）**
- "学业质量水平二是高中毕业生在本学科应该达到的合格要求。学业质量水平四是学业水平等级性考试的命题依据。"
- "一、二级水平，除解决问题的情境相对简单和解决问题的程度相对较低外，涉及的大概念、方法等仅限于必修课程内容"；"三、四级水平，解决问题的情境相对复杂……包括必修课程和选择性必修课程的全部内容"。
- 命题："试题情境应围绕现实问题（包括热点问题）展开，尽量做到新颖、真实、科学、恰当，有一定的信息量和适当的复杂度"；"设问要有清晰的层次和严谨的逻辑，指向核心素养的不同水平"。

### 1.3 分层锚点

- **初中**：课标没有单列认知水平分级，按学业质量里的动词阶梯分层：A 层"识别、描述"（识图、说出结构和功能）；B 层"解释、分析、推测"（用生命观念解释现象、分析实验数据）；C 层"论证、决策、提出方案"（设计实验、评价方案、社会性科学议题）。
- **高中**：A ≈ 水平二（合格考），B ≈ 水平三，C ≈ 水平三到四。**按课标原文，三、四级涉及选择性必修内容**，所以必修课时的 C 层只能提高情境复杂度和推理要求，不能引入选必知识；确需引入的，教师版标"选学"。

## 2. 生物出卷老师的组卷方法

1. **母题 = 一个结构与功能关系、一个生理过程或一个经典实验。** 例如"叶片结构"可以串起识图、气孔开闭、蒸腾作用、光合作用原料进出。
2. **升级路线**：
   - **识图 → 析图 → 跨图整合**：标出结构名称 → 说明结构如何适应功能 → 把两张图（如心脏结构图和血液循环途径图）联系起来分析。
   - **经典实验复现 → 改变量 → 设计新实验 → 评价方案**：说出实验步骤的目的 → 换一个变量重新推结论 → 自己设计 → 指出别人设计的缺陷。
   - **读资料 → 解释 → 论证或决策**：从资料中提取事实 → 用所学概念解释 → 针对议题提出有证据支持的观点。
   - **遗传正推 → 逆推 → 概率 → 验证**：已知亲代推子代 → 由子代性状比例推亲代基因组成 → 计算概率 → 设计杂交实验验证。
   - **个体 → 群体 → 生态系统**：从一个生物的适应特征，到种群数量变化，再到生态系统中能量和物质的流动。
3. **数据由程序生成**：实验数据、种群数量、能量流动数值都先定规律，再生成数据并验算（第 6 节），并标"（数据为虚构）"。
4. **不靠记忆量升级**：多让学生背两个结构名称不算升级。

### 2.1 难度画像在生物里的含义

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| `k` | 一个概念或结构 | 两个（结构 + 功能；光合作用 + 呼吸作用） | 三个及以上或跨主题（消化、吸收、循环综合） |
| `c` | 信息直接给出 | 需读结构图、曲线、表格、遗传系谱图，或把资料文字转成生物学事实 | **隐含**：要自己找出实验变量、发现对照组设置有问题、从曲线拐点推出生理变化、从子代比例反推亲代 |
| `r` | 教材经典图和经典实验 | 熟悉的生活情境（饮食、运动、种植），需要自己联系所学 | 陌生资料（新研究、陌生物种、新技术），需要迁移 |
| `o` | 唯一答案 | 需解释原因、说明理由 | 设计实验、提出方案、就议题论证 |
| `g` | 识别、说出 | 描述、简单解释 | 分析推测、数据推理 |

`g=3`：设计实验、评价方案、在社会性科学议题中作出有依据的决策。

## 3. 题型与命题规范

| 题型 | 规范 |
|---|---|
| 选择题 | 四选一。干扰项各对应一个错因：**结构与功能错配**、**概念混淆**（呼吸作用与呼吸运动、动脉与动脉血）、**以偏概全**（"所有植物都有根茎叶"）、**因果倒置**、**单一变量违背** |
| 识图题 | 本技能交付的是文字作业，图要写进 `figure`：用教材通用的示意图（细胞、叶片横切、心脏、肾单位、关节等），逐个说明各标号指向的位置，不说明它是什么结构。答题格式"[　]内填序号，___上填名称"。不要依赖只有看图才能分辨的细节 |
| 资料分析题 | 资料来自真实来源或标"（材料为虚构）"；每个问题的答案都必须能从资料加所学知识推出，不能依赖资料以外的冷门事实 |
| 实验探究题 | 要求或考查：**单一变量**、**对照组**、**重复实验或样本数量足够**（种子、鼠妇不能只用 1 个）、**无关变量相同且适宜**。预期结果和结论用"若……则……"写，结果与结论要一一对应 |
| 遗传题 | 初中：用 A、a 表示显隐性基因，遗传图解写清亲代、生殖细胞、子代和性状比例。高中：P、F₁、F₂、配子、"×"、"⊗"等符号规范，比例写成最简整数比。题干要说清显隐性或给出能判断显隐性的条件 |
| 曲线/表格题 | 坐标轴有名称和单位；曲线趋势要符合生理事实（光合速率随光照增强先升后趋于稳定，不会无限上升） |
| 社会性科学议题 | 给出真实议题（转基因食品、外来物种、抗生素使用）；评分按"观点 + 证据 + 推理"分层次给分，不按观点本身给分 |
| 实践作业 | 种植、养殖、调查、制作模型。写清任务、观察记录的要求、提交成果和评价要点；周期较长的放在单独的实践作业里，不计入一次作业的时长 |

## 5. 情境与数据规则（重点）

- **不编造实验结论。** 经典实验的步骤、目的和结论按教材写：绿叶在光下制造淀粉（暗处理、遮光对照、酒精隔水加热脱色、碘液检验）；唾液对淀粉的消化（约 37 ℃、碘液检验）；种子萌发需要适宜的温度、一定的水分和充足的空气；鼠妇喜欢阴暗潮湿的环境。改编实验时，结论必须是真实的生物学规律，不能为了出题"设定"一个结论。
- **不编造物种事实。** 用真实物种时，形态、分类、习性要准确：蝙蝠是哺乳动物；鲸、海豚是哺乳动物；银杏、松是裸子植物，种子裸露、没有果实；海带、紫菜是藻类，没有根茎叶的分化；葫芦藓有茎叶但没有真正的根；病毒没有细胞结构；细菌没有成形的细胞核，酵母菌有。不确定的物种事实，有搜索工具就核对，没有就换成教材里的物种。
- **不编造研究。** 不写"某大学最新研究发现……"然后给出编造的结论。陌生资料可以用真实的生物科学史，或写成"某兴趣小组做了如下实验（数据为虚构）"。
- **数据要符合生理事实**（经验值，以教材为准）：人体正常体温约 37 ℃；成人安静心率约 60–100 次/分；空腹血糖正常约 3.9–6.1 mmol/L（高中）；相邻营养级能量传递效率约 10%–20%；种子发芽率不超过 100%；对照组和实验组除变量外条件相同。
- **安全与伦理**：实践作业不伤害动物，观察后放回原环境；不采集、不购买保护物种；不采食野生菌和野菜；不在家采集血液等样本；发酵食品制作注意卫生，不食用变质产物。涉及青春期、疾病、遗传病的题目，用中性表述，不对学生或某类人群贴标签。
- **情境闸门补充**：生物题的情境常常承担真实的认知任务（健康决策、生态问题），但"小明一家去郊游，看到一棵树……请写出叶片的结构"仍然是装饰，删掉。

## 6. 正确性验证

生物多数题用 `blind`。能计算的（遗传概率、性状分离比、能量传递效率、种群数量估算、发芽率）写 `check.code`。

注意：sympy 已占用一些常见名字（`I` 虚数单位、`E`、`N`、`S`、`Q`、`product`）。不要用它们作变量名或写在 `expect` 里；要用 itertools 的 `product`，就在 code 里先写 `from itertools import product`。

```python
# 遗传概率：一对表现正常的夫妇都是白化病基因携带者（Aa × Aa）
from itertools import product
from collections import Counter
kids = Counter("".join(sorted(a + b)) for a, b in product("Aa", "Aa"))
total = sum(kids.values())
ans = [Rational(kids["aa"], total),                       # 孩子患病概率
       Rational(kids["AA"], kids["AA"] + kids["Aa"])]     # 表现正常的孩子中纯合子比例
# expect "[Rational(1,4), Rational(1,3)]"

# 高中：两对相对性状 YyRr 自交，F2 表现型比例
from itertools import product
from collections import Counter
gam = lambda g: ["".join(p) for p in product(g[0:2], g[2:4])]
pheno = lambda z: ("Y" if "Y" in z else "y") + ("R" if "R" in z else "r")
cnt = Counter(pheno(a + b) for a, b in product(gam("YyRr"), gam("YyRr")))
ans = [cnt["YR"], cnt["Yr"], cnt["yR"], cnt["yr"]]        # expect "[9, 3, 3, 1]"

# 能量传递效率（题干表格，数据为虚构，单位 kJ）
E = {'生产者': 10000, '初级消费者': 1500, '次级消费者': 180}
ans = [Rational(E['初级消费者'], E['生产者'])*100,
       Rational(E['次级消费者'], E['初级消费者'])*100]     # expect "[15, 12]"
```

非计算题的门禁重点（`blind`）：
- **资料分析题**：逐问检查答案能否只用"资料 + 本课所学"推出；需要资料外冷门知识的，改题。
- **实验题**：检查对照组是否只差一个变量；"若……则……"的每种结果是否都对应唯一结论。
- **识图题**：只看 `figure` 的文字描述，能否唯一确定每个标号指的结构。

## 7. 常见病题（审卷时重点查）

- **变量不唯一**：作为对照的两组同时改变了两个条件，却要求学生得出单一结论（除非这正是要学生识别的错误）。
- **样本太少却要求得出结论**：每组 1 粒种子、1 只鼠妇。
- **结论超出证据**：只做了一种植物的实验，答案却写"所有植物都……"。
- **概念性错误表述**："植物白天进行光合作用，晚上进行呼吸作用""动脉里流的都是动脉血""细菌是最小的生物"。题干和答案都不能出现。
- **图文不清**：`figure` 没写清标号指向，结构可以有两种解读。
- **遗传题显隐性没交代**，也不能从题中信息判断。
- **数据失真**：发芽率超过 100%；能量传递效率 50%；种群数量出现小数个体。
- **价值导向问题**：为了出题设定伤害动物、破坏环境的操作，或用歧视性语言描述疾病和人群。

## 8. 三层微型示例（七年级上·种子萌发的环境条件）

课时目标：学生能分析对照实验的变量，根据实验结果得出种子萌发所需的环境条件。

实验情境（三层共用）：取 4 个相同的罐头瓶，各放 50 粒同种、饱满、大小相近的菜豆种子。1 号不加水，放在 25 ℃ 环境；2 号加少量水使种子湿润，放在 25 ℃；3 号加水淹没种子，放在 25 ℃；4 号加少量水使种子湿润，放在 4 ℃ 的冰箱冷藏室。

**A1（基础巩固，选择题）** 1 号和 2 号对照，探究的是哪个条件对种子萌发的影响？（　　）A. 温度　B. 水分　C. 空气　D. 光照
- 答案：B。干扰项：A 对应"把 2 号与 4 号的对照当成本题的对照"；C 对应"把 2 号与 3 号的对照当成本题的对照"；D 对应"把植物生长需要光照迁移到种子萌发"。
- 画像：k0 s2 c1 r0 o0 g1。

**B1（能力提升，分析说理）** 一周后结果如下（数据为虚构）：1 号 0 粒、2 号 46 粒、3 号 0 粒、4 号 0 粒萌发。(1) 由 2 号和 4 号可以得出什么结论？(2) 小明说："比较 1 号和 3 号，可知种子萌发需要水。"你同意吗？说明理由。(3) 每瓶用 50 粒种子而不是 1 粒，目的是什么？
- 答案：(1) 种子萌发需要适宜的温度；(2) 不同意。1 号和 3 号相比，水分和空气两个条件都不同，不是单一变量，不能得出结论（应比较 1 号与 2 号）；(3) 避免偶然因素导致的误差，使结论更可靠。
- 画像：k1 s5 c2 r0 o1 g2。
- upgrade：from A1，dims [c, g, o]，"从'找出给定一组对照的变量'变为'自己判断一组比较是否符合单一变量'，并解释样本数量的作用"。

**C1（拓展挑战，实验设计）** 有同学猜想"光照会影响菜豆种子萌发"。请利用上述材料设计实验：写出实验组和对照组的处理方法，并用"若……则……"写出可能的结果和对应的结论。
- 参考答案要点：两组各 50 粒种子，都加少量水、放在 25 ℃，一组放在有光处，一组用黑纸箱遮光（2 分：单一变量 1 分，其他条件相同且适宜 1 分）；若两组萌发数相近，则光照对菜豆种子萌发没有明显影响；若有光组明显多于（或少于）遮光组，则光照促进（或抑制）菜豆种子萌发（2 分）。
- 画像：k1 s4 c1 r1 o2 g3。
- upgrade：from B1，dims [o, g]，"从分析别人的实验转为自己设计实验，并预测多种结果"。
- check：`blind`。教师版注明：菜豆种子萌发一般不需要光照（教材结论），学生不必预先知道；评分看设计和"结果—结论"的对应，不看猜测是否正确。

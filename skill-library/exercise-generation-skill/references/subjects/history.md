# 历史（初中 + 高中）

学科是历史时必读。历史作业最大的风险不是"太难"，而是**史实错、史料是编的、选择题有两个对的**。第 5、6 节是本文件的重点。

---

## 1. 课标锚点

### 1.1 核心素养（初中、高中名称相同，要求不同）

| 素养 | 一句话（课标原文摘要） | 义务教育阶段的要求（原文摘要） |
|---|---|---|
| 唯物史观 | "揭示人类社会历史客观基础及发展规律的科学的历史观和方法论" | "初步学会在唯物史观的指导下看待历史" |
| 时空观念 | "在特定的时间联系和空间联系中对事物进行观察、分析的意识和思维方式" | "学会在具体的时空条件下考察历史" |
| 史料实证 | "对获取的史料进行辨析，并运用可信史料努力重现历史真实的态度与方法" | "初步学会依靠可信史料了解和认识历史" |
| 历史解释 | 以史料为依据，对历史作出认识和评判的态度、能力与方法 | "初步学会有理有据地表达自己对历史的看法" |
| 家国情怀 | 学习和探究历史应具有的人文追求与社会责任 | "形成对家乡、国家和中华民族的认同，具有国际视野" |

`objective` 写成"史事 + 素养表现"，如"秦朝郡县制与巩固统一的关系（历史解释）"。不要只写素养名。

### 1.2 课标对作业与命题的要求（原文摘要）

**义务教育历史课标（2022 年版）**
- 作业形式："完成课后练习、制作历史模型、撰写历史调查报告或历史小论文等"。
- 作业要求："在注重理解和应用的基础上，加强综合性、探究性和创新性，体现层次性；针对不同学生的特点，布置不同层次的作业，供学生选择"；评价时"教师应和学生一起设计可行的量规"。
- 命题规范："确保命题框架合理、内容准确无误、情境符合事实、问题设计恰当、语言表述清晰"。
- 题型导向："要减少简单考查机械记忆能力的题型，提高探究性、开放性、综合性、创新性题型的比例"。
- 评分标准："对可能出现的各种合理答案进行分类和相应水平划分"；"鼓励制定分层次的评分标准，尽量减少'点对点'式的硬性机械赋分方式"。
- 期末纸笔测试"要设计完整的多维细目表"。

**普通高中历史课标（2017 年版 2020 年修订）**
- 命题要求"测试梯度能反映学业质量水平的不同层次"；试题"在立意、设问、答案和评分标准等方面做到科学、合理、可操作"。
- "以新情境下的问题解决为重心"。新情境分四类：**学习情境**（史料、图表、历史叙述、史论）、**生活情境**（听长辈回忆、看影视剧、游览古迹时遇到的问题）、**社会情境**（社会风俗的来源、国际争端的历史背景）、**学术情境**（史学家对同一问题有多种看法）。

### 1.3 学业质量：分层时怎么对

**初中**：义务课标把 7–9 年级作为一个学段，学业质量不分级。分层按课标描述里的动作递进：
- A：把史事放进正确的时间和空间；从教材和课上见过的可信史料中"辨识其中的含义"。
- B：运用史料"对重要史事进行简要说明"；认识四种联系，即古今联系、因果联系、不同领域的横向联系、中国与世界的联系。
- C："有理有据地表达自己的看法"，即自拟观点、史论结合。

**高中**：学业质量分 **4 级**。水平 2 是合格要求，水平 4 是等级性考试的命题依据。这和数学的三级不同，`layering.md` 里"A≈水平一"的说法在历史中改按下表：

| 层 | 对应水平 | 史料实证的表现（课标 1-3 至 4-3，摘要） | 历史解释的表现（课标 1-4 至 4-4，摘要） |
|---|---|---|---|
| A | 1–2 | 知道史料的类型，能从史料中提取有关信息 | 讲述史事的经过和结果；概述基本进程 |
| B | 2–3 | 认识不同类型史料的不同价值；尝试用史料作证据论证观点 | 区分历史叙述中的史实与解释；对史事作出解释 |
| C | 3–4 | 辨析史料并判断其价值，让不同史料互证；辨别史料作者的意图 | 分辨不同的历史解释，说明产生分歧的原因并评析；尝试验证已有说法 |

课标里有一道样题可以做参照：把关于"公车上书"的个人回忆和档案研究两则材料放在一起。只能指出"材料 1 是个人回忆、材料 2 依据档案"的，算水平 1；能说明两类史料价值不同的，算水平 2。**同一道材料题，靠设问和评分等级就能分出层次**，这是历史分层最常用的办法。

## 2. 历史出卷老师的组卷方法

1. **一则材料，一条主线。** 母题通常是"一则材料 + 一个核心史事"。三层围绕同一个史事展开，靠改设问来升级，不必每层另找一段材料。
2. **升级路线**（只动结构，不靠堆材料）：
   - 信息：提取材料里的显性信息 → 提取隐含信息（作者立场、时间暗示、言外之意）→ 两则材料比较、互证
   - 因果：说出一个原因 → 区分根本原因与直接原因、主观原因与客观原因 → 用古今、中外、横向联系来解释
   - 解释：复述史实 → 区分材料中哪些是史实、哪些是作者的观点 → 评析不同的历史解释，说明分歧从哪里来
   - 时空：给事件定位、排序 → 划分阶段、概括时代特征 → 选择合适的时空尺度做比较
   - 表达：判断给定的观点 → 论证给定的观点 → 自拟观点，史论结合（小论文）
   - 动机与影响：说出做了什么 → 区分主观动机和客观影响（唯物史观的入门训练）
3. **材料要承担认知任务。** 情境闸门的"删除测试"在历史里是"删材料测试"：删掉材料，学生凭记忆也能答，材料就只是装饰。这时要么去掉材料，改成直接设问；要么改设问，让答案必须来自材料。
4. **评分搭台阶。** 主观题用 (1)(2)(3) 分小问：提取概括 → 结合所学解释 → 评价或启示。开放题用等级评分（见 3.1）。

### 2.1 难度画像在历史中的含义

| 键 | 0 | 1 | 2 |
|---|---|---|---|
| `k` | 一个史事或概念 | 两个史事，或史事加一种方法（如因果分析） | 跨单元、跨时段，或需要中外联系 |
| `c` | 直接问史实，或材料直接给出答案 | 要从材料中提取显性信息，再和所学史事对上（如从诗句判断说的是哪项制度） | **要从史料中提取并辨析隐含信息**：作者立场、材料的性质（回忆录还是档案）、材料与结论之间的推断，或材料里有干扰信息 |
| `r` | 教材原有的材料或标准设问 | 新材料，但指向熟悉的史事（学习情境、生活情境） | 陌生材料、学术情境（多种解释并存），或跨领域的社会情境 |
| `o` | 唯一答案（选择、排序、填空） | 要说明原因或依据，或可以从多个角度作答 | 自拟观点论述、小论文、探究方案 |
| `g` | 0 识记（时间、人物、事件）；1 理解应用（概括、解释、用材料说明）；2 分析（比较、因果、辨析史料价值、区分史实与解释）；3 评价创造（评析解释、自拟观点论证、设计调查） | | |

`s` 按解析里真正需要的推理环节来数。例如"读出材料关键信息 → 对应到所学史事 → 推出结论"是 3 步。

## 3. 题型与命题规范

| 题型 | 规范 |
|---|---|
| 材料型单项选择题 | 四选一。设问用"材料反映了""据此可知""最能说明""主要意图是"这类限定。**正确项必须同时得到材料和所学的支持。**干扰项从下面这些错法里选，每个都要有一处说得出的硬伤：本身正确但材料没有体现、时代错置、因果倒置、绝对化（"完全""彻底""根本改变"）、以偏概全、与材料矛盾 |
| 时序、年代题 | 年代必须准确。有公元前或跨公元的时间计算时，用程序验算（第 6 节） |
| 材料分析题 | 史料、表格、年表、地图、漫画都可以作材料，**图像一律用文字描述**。设问搭台阶：提取概括 → 结合所学解释 → 评价、启示 |
| 历史解释辨析题 | "有人认为……你是否同意？请说明理由"。给出的观点必须真的有争议、可以评析；不要拿一句明显错误的话让学生去批 |
| 论述题、小论文 | 给一则材料或一份年表，让学生自拟观点、史论结合，用等级评分 |
| 实践与探究 | 家史访谈、口述史记录、参观博物馆或遗址的记录、制作年表或历史小报、做模型。写清任务、成果形式和量规，一般放 C 层，或作为单独的长作业 |

### 3.1 主观题评分：观点 + 史实 + 逻辑

开放题照义务课标样题的四级评分来定（原文摘要）：

| 等级 | 拟定的观点 | 材料运用与论述 |
|---|---|---|
| 4 | 明确，有新意或有思想深度 | 紧扣自己的观点加以论述，运用材料中两个以上的史实，能够做到史论结合，逻辑清晰 |
| 3 | 明确 | 能够围绕观点论述，运用了材料中的史实，但不够充分或不够典型，条理基本清楚 |
| 2 | 不够明确 | 有论述或说明，但材料不充分，或史论结合不充分 |
| 1 | 没有凝练出观点 | 观点、论述与材料无关，或仅仅重复材料中的史实 |

封闭的主观题写要点评分。每个要点都要注明来源，是"材料第 X 句"还是"所学"，并写清楚这一点该得几分。

## 5. 材料与事实准确性（本学科最重要的规则）

### 5.1 史实

- **没把握不用。**能用的是统编教材明确写到的年代、人物、事件、制度，以及你确定无误的通识。细节数字（伤亡人数、赔款数额、产量）只在完全有把握时使用，否则改成定性表述，或者整道题换一个点。
- 年代、人名、地名、条约名、会议名用教材的规范写法。古今地名要对应准确；写不准的，不要放进题干。
- 有联网工具时，题目里每个具体的年代、引文和数字都核对一次，优先采用教材和权威来源。核对不了的就降级处理：改成定性表述、标明自拟，或者删掉。

### 5.2 史料：绝不编造引文

题中出现的每段材料，都必须属于下面三类之一，并且在学生版里标注出来：

| 类型 | 何时可用 | 学生版怎么标 |
|---|---|---|
| 原文 | 只用广为人知、能确证原文的史料（如教材中出现过的原文、经典名句）。有联网工具时核对原文 | "——《书名》"或"——《书名·篇名》"，**不编卷数和页码** |
| 摘编、改写 | 确实有这本书或这份文献，而且内容大意你有把握 | "——据《书名》改写" |
| 自拟 | 情境化的叙述，如某同学的笔记、某兴趣小组的调查、示意性的年表 | "（材料为自拟）"，或用"某同学整理的笔记"等方式让人一看就知道是自拟 |

- **绝不把自拟的文字挂到真实的人物、著作或档案名下**（如"梁启超说：'……'"）。学生会把它当真记下来。
- "有学者认为"只能用于学界确实存在的观点。拿不准时，写成"有同学认为"，把它当作一道评析题来出。
- 教师版的 `source.note` 写明每段材料属于原文、摘编还是自拟；需要老师核对原文的，在 `teacher_note` 里写"请核对原文"。
- 地图、漫画、文物图片一律用文字描述，标明时期和标注内容。描述只交代"图上有什么"，不能替学生得出结论。不要描述你无法确认细节的真实藏品。

### 5.3 价值导向与敏感内容

- 历史结论和人物评价以统编教材的口径为准。涉及国家主权、领土、民族关系、宗教、党史和重大历史事件的，使用国家统一表述。
- 不出现历史虚无主义的材料（戏说、翻案、丑化英雄人物）。需要辨析错误观点时，选教材或权威来源中已有定论的。
- 宗教史只讲史实和影响，不评价教义。民族关系按"统一多民族国家的形成和发展"的口径来写。
- 不考查当代尚无定论的敏感时政。

## 6. 正确性验证

大多数题写 `check.method: "blind"`，按 `verification.md` 的要求试做。有年代计算的写 `python`：

```python
# 公元纪年没有公元 0 年：跨公元的年数要减 1
def span(a, b):            # a、b 为年份，公元前写成负数
    return b - a - (1 if a < 0 < b else 0)
ans = span(-221, 220)      # 秦统一（前221）到东汉灭亡（220）：440 年
# 世纪：1 世纪是公元 1–100 年，所以 1900 年属于 19 世纪
def century(y):
    return (y - 1)//100 + 1 if y > 0 else -((-y - 1)//100 + 1)   # 负数表示公元前
ans = [century(1840), century(1900), century(-221)]   # [19, 19, -3]
```

出题时避开 1900、2000 这类边界年份，不然学生的答案容易和教材说法起争议。

### 6.1 材料型选择题：最容易出两个都"对"的选项

按门禁 B，每个选项都写一行"它是正确答案的最强理由"。历史选择题里，"第二正确答案"常见的来源有四种：

1. **本身正确，但材料没有体现。**题干必须写"材料反映""据材料可知"。正确项要靠材料推出，干扰项要能指出"材料没有提到"。
2. **层次不同的两个正确表述**，比如直接原因和根本原因，加强集权和巩固统一。题干要限定"直接""根本""主要"；限定不了的，删掉其中一个。
3. **包含关系**：一个选项的说法包含了另一个，比如"发展经济"包含"发展农业"。
4. **材料能同时支持两种推断**：补一句限定材料的话，或者换一段材料。

干扰项要"错得说得出来"：时代错置、与材料矛盾、绝对化、因果倒置。只是"不够好"的选项，老师讲评时会有争议，不要用。

### 6.2 主观题

- 每个评分要点都必须能从"材料 + 所学"推出来。推不出来的要点，说明题干给的信息不够。
- 开放题列出**可接受答案的类型**（不同的观点方向），再配等级评分，不能只给一个标准答案。
- 试做时，拿"只复述材料"的答案按评分标准打一次分。如果它也能拿高分，评分标准就要改。

## 7. 常见病题

- **材料装饰**：删掉材料照样能答。
- **两解选择题**：干扰项"本身正确"，题干却没写"材料反映"。
- **设问超出材料**：要的答案材料里没有，课本里也没有。
- **自拟材料冒充原文**，或者给自拟材料编出处、编页码。
- **史实或年代错误**：公元前计算、世纪换算、条约内容张冠李戴。
- **图像描述替学生下结论**，如"图中可见清政府的腐败无能"。
- **偏题怪题**：考冷僻细节，如人物的字号、条约的第几款。
- **以今度古或绝对化的标准答案**，如"××完全是错误的"。
- **开放题只给一个标准答案**，或者评分标准没有分等级。

## 8. 三层微型示例（七年级上册·秦统一中国）

课时目标：学生能说明秦朝巩固统一的主要措施及其作用。三层围绕同一主线：郡县制与巩固统一。

**A1（材料型单选）** 秦朝在全国推行一种地方行政制度：地方长官由皇帝直接任免，不能世袭。这种制度是（　）
A. 分封制　B. 郡县制　C. 行省制　D. 三省六部制
- 答案 B。干扰项：A，把"管理地方"直接联想到西周分封，没注意"不能世袭"；C，时代错置，行省制是元朝的制度；D，把中央官制当成地方制度。
- 画像 k0 s2 c1 r0 o0 g1；`check: blind`。

**B1（材料比较 + 说理）** 材料（自拟）：甲制度下，地方首领的职位世代相传，在自己的封地内拥有较大权力；乙制度下，地方长官由皇帝任免，随时可以调换。
(1) 甲、乙分别是哪个朝代推行的什么制度？
(2) 从"地方长官怎样产生"比较两者的不同，并说明乙制度为什么有利于巩固统一。
- 升级：相对 A1，从"由特征认制度"变为"两种制度比较，并推出作用"。`dims: c, g`。
- 画像 k1 s4 c1 r1 o1 g2。
- 要点：(1) 甲是西周的分封制，乙是秦朝的郡县制。(2) 分封制下世袭，郡县制下由皇帝任免；郡县制使皇帝能直接控制地方，防止地方势力坐大、形成割据。

**C1（评析观点）** 有同学认为："秦始皇统一文字、货币和度量衡，只是为了方便自己统治，和老百姓没有关系。"你是否同意？请结合所学说明理由。
- 升级：相对 B1，从"说明作用"变为"区分主观动机与客观影响，评析一个观点"。`dims: g, o`。
- 画像 k1 s4 c2 r1 o2 g3。
- 按 3.1 的四级评分。水平 4 的表现：指出这些措施的直接目的确实是巩固统治，同时用至少两项措施说明它们在客观上方便了各地的经济、文化交流，有利于统一多民族国家的巩固；能区分"动机"和"影响"。
- 教师版要标明：本题的观点是自拟的，没有出处。学生"部分同意"（承认有巩固统治的动机，但不同意"和老百姓没有关系"）最合理；完全同意、只讲动机不讲影响的，最高到等级 2。

# 道德与法治（小学、初中）· 思想政治（高中）

学科是道德与法治或思想政治时必读。这门课的风险在两头：一头是**事实性风险**，比如时政编造、法条引错、讲话杜撰；另一头是**题目退化成表态**，A 层全是"我们应该……"的填空，没有思考。第 5、6 节是重点。

---

## 1. 课标锚点

### 1.1 核心素养：小初与高中的表述不同，不要混用

| 学段 | 核心素养 | 注意 |
|---|---|---|
| 小学、初中（义务道德与法治 2022） | **政治认同、道德修养、法治观念、健全人格、责任意识** | 说"法治**观念**"；没有"科学精神""公共参与" |
| 高中（思想政治） | **政治认同、科学精神、法治意识、公共参与** | 说"法治**意识**"；没有"道德修养""健全人格" |

义务课标的定义（原文摘要）：
- 法治观念："树立宪法法律至上、法律面前人人平等、权利义务相统一的理念"，还包括"守法用法意识和行为"和"生命安全意识和自我保护能力"。
- 责任意识：包括主人翁意识、担当精神和"有序参与"，即"守规矩，重程序，能够依规依法参与公共事务"。
- 健全人格：包括自尊自信、理性平和、积极向上、友爱互助。
- 道德修养：包括个人品德、家庭美德、社会公德、职业道德。

`objective` 写成"教材观点 + 素养"，如"行使权利要以合法方式进行（法治观念）"。

### 1.2 课标对作业与命题的要求（原文摘要）

**义务道德与法治课标（2022 年版）**
- 作业："作业内容要结合学生生活，创新作业方式，采用开放性、情境性、体验式等形式多样、难度适宜、数量适当的作业"；"注重设计带有团队合作性质的、项目任务性质的作业"。
- 作业评价："既要关注结果……也要关注过程"；"更加重视书面或口头反馈"。
- 纸笔测试："注重增加综合性、开放性、应用型、探究性试题比例，不出偏题怪题，减少记忆性试题，防止试题难度过大"。
- 情境："考虑情境的真实性、典型性、适切性、复杂性"；"情境素材选取要源于真实的社会生活，情境的描述和展开要符合生活常识"。
- 任务："任务应具有多样性，如描述特征、论证、辨析、评价、制订方案等"；"任务设计应具有合适的思维水平层级"。
- 评分："评分标准在基本立场、观点上要坚持统一尺度，鼓励学生运用不同素材，提出不同的问题解决方案"。
- 评价时"尊重学生的人格，保护学生的隐私"。

**普通高中思想政治课标（2017 年版；2020 年修订版此处未逐字核对）**
- 学科任务分四类：**描述与分类、解释与论证、预测与选择、辨析与评价**。
- 情境的复杂程度（摘要）：涉及的行为主体越多、相互竞争的目标越多、影响因素越多、不确定性越大、立场观点或利益越多样且冲突越大，情境就越复杂。**这是本学科调节 `r` 的直接依据。**
- 情境要"保留关键性的事实与特征，剔除无关紧要的细枝末节，创设信息支持充分的评价情境"；"要兼顾地区和城乡差异；要尽量避免使用学生不熟悉的术语"。
- 评分：要"有相当数量的开放性试题"；评分标准"要兼顾共同性与差异性"。

### 1.3 学业质量：分层时怎么对

**小学、初中**：学业质量按四个学段描述（1–2、3–4、5–6、7–9 年级），学段内不分级。分层按课标里的动作递进：
- A：能讲述、能识别（如"知道宪法是国家根本法""辨识失信失德的行为表现"）。
- B：结合实例说明、判断是非并说理（如"运用实际案例说明与生活相关的法律规定""根据社会主义核心价值观判断是非对错"）。
- C：论证、评价、制订方案（如"就如何实现可持续发展提出建议"）。

**高中**：学业质量分 4 级。2017 年版原文是"学业质量水平二是高中毕业生在本学科应该达到的合格要求。学业质量水平三是学业水平等级性考试的命题依据"。注意，这与历史、地理以水平 4 作为等级考依据**不同**；2020 年修订版有没有调整，未核实。

| 层 | 对应水平 | 关键动词（课标摘要） |
|---|---|---|
| A | 1 | 引用典型事例、列举、讲述、引述 |
| B | 2 | 分析具体事例、归纳、比较不同的涉法行为、预测其后果、阐释 |
| C | 3（个别到 4） | 选择恰当论据论证、辨析、用矛盾分析法权衡利弊、评估方案 |

## 2. 出卷老师的组卷方法

1. **情境锚 + 议题。**母题是"一个真实情境 + 一个教材观点"。三层最好共用同一个情境（校园、家庭、社区里的一件事），只改任务。这门课本身强调情境，但情境仍要过 `situation.md` 的情境测试。
2. **升级路线**，对应课标的任务类型：
   - 识别：这是什么行为，体现了什么观点（描述与分类）
   - 解释：为什么这样做是对的或错的，用教材观点说明（解释与论证）
   - 辨析：判断一个说法或做法，并且一分为二（辨析与评价）
   - 选择：在几种方案或利益之间权衡（预测与选择）
   - 方案：设计一个依法、有序、可行的行动方案（制订方案）
3. **不要用表态代替思考。**"我们应该热爱祖国""我们要遵纪守法"这类填空只是识记。A 层可以有识别题，但要求学生把观点和情境中的具体行为对上。
4. **一分为二是本学科最自然的 `c=2`。**同一个人的做法里既有正当的部分，也有不当的部分，学生要自己拆开来分析。

### 2.1 难度画像在本学科的含义

| 键 | 0 | 1 | 2 |
|---|---|---|---|
| `k` | 一个教材观点 | 两个观点联动（如权利与义务） | 跨课、跨模块（如经济与政治、法律与道德） |
| `c` | 情境直接点明行为性质，问"体现了什么" | 要自己识别行为的性质，并对应到教材观点 | **隐含**：行为要一分为二；主体身份需要自己发现（如当事人是未成年人）；多主体多利益；含干扰信息 |
| `r` | 教材案例或标准设问 | 熟悉的校园、家庭、社区情境 | 陌生的社会议题，或多主体利益冲突（见 1.2 中的情境复杂度） |
| `o` | 唯一答案 | 判断并说理，或可以从多个角度作答 | 方案、倡议、议题探究 |
| `g` | 0 识记观点；1 运用观点解释；2 辨析、比较、预测后果；3 评价、权衡、制订方案 | | |

## 3. 题型与命题规范

| 题型 | 规范 |
|---|---|
| 情境单选 | 四选一，设问写"材料体现""这启示我们""下列做法正确的是"。干扰项各对应一个错因：说法本身正确但与材料无关、主体错位（把国家的职责安到中学生头上，或者反过来）、绝对化、混淆概念（违法与犯罪，人大与政府） |
| 组合式选择（①②③④） | 高中和初中常用。**每个说法都要能单独判定**：要么本身错误，要么本身正确但与材料无关，要么正确且材料体现。不允许出现"说法有争议"的项。四个组合选项里正确组合只有一个 |
| 判断说理（小学为主） | "小红这样做对吗？为什么？"判断有唯一答案，理由按要点给分 |
| 辨析题 | "有人认为……请辨析。"标准结构：判断（全对、全错或部分对）→ 说明对在哪里 → 说明错在哪里 → 正确的认识应当是什么 |
| 材料分析题 | 设问写清楚"运用××知识"，限定作答范围。问"怎么做"时要写明主体，如"作为中学生" |
| 方案、倡议、宣讲提纲 | 写清楚对象、目的、字数或条数；评分看可行性、合法性、针对性 |
| 实践作业 | 家庭劳动、社区观察、采访、模拟法庭、班级议事。写清时长、安全要求和成果形式；**不要求学生暴露家庭隐私** |

**评分结构：立场 + 观点 + 联系材料 + 逻辑。**
- 立场必须正确，这是课标说的"在基本立场、观点上要坚持统一尺度"。教师版写明：立场错误的作答不给分。
- 观点给分：用到对应的教材观点。
- 联系材料给分：观点要落到情境里的具体行为上。只背观点、不联系材料的，扣这一项。
- 开放题按等级评分，列出可接受的不同角度，体现"共同性与差异性"。

## 4. 按学段的题型谱（统编教材，册次以所用教材为准；2024 年起七年级用新版）

| 学段 / 主题 | 常考题型 | 典型错因（可观察行为） |
|---|---|---|
| 小学：规则、安全、家庭、公共生活 | 看图或情境判断对错并说理由；安全标识识别；生活实践打卡 | 只判断对错，说不出理由；把"规则"理解为"老师在的时候才要遵守" |
| 小学高年级：法治启蒙、国家机构、公民身份 | 判断说理；情境中的权利识别 | 认为"小孩没有权利"或"小孩不用守法" |
| 初中：生命安全与健康、自我与人际 | 情境选择；行为辨析；情绪调节建议 | 建议只写"要乐观"，没有具体方法；把正常的青春期心理当成"问题" |
| 初中：法治教育（宪法、权利义务、违法与犯罪、未成年人保护） | 权利类型识别；违法类型判断；维权途径选择；辨析题 | 把违法等同于犯罪；把隐私权、名誉权、肖像权混为一谈；把未成年人保护的"六大保护"（家庭、学校、社会、网络、政府、司法）归错类；维权只写"打官司" |
| 初中：国情教育、国家机构、民主法治 | 机构职能匹配；制度识别；材料分析 | 把全国人大（最高国家权力机关）和国务院（最高国家行政机关）的职权混淆；把人民政协当成国家机关 |
| 初中：中华优秀传统文化与革命传统 | 材料解析（如课标样题以"家"字的字形、"长征"火箭的命名作材料）；开放命名、设计题 | 只复述材料，提炼不出文化内涵 |
| 高中必修 1–2（中国特色社会主义、经济与社会） | 组合选择；经济现象的传导分析；曲线图 | 传导链断档，从原因直接跳到结论；需求曲线移动和沿曲线移动不分；把"市场起决定性作用"误写成"市场决定一切" |
| 高中必修 3（政治与法治） | 主体职能辨析；组合选择 | 主体错位，把人大、政府、政协、党组织的职能张冠李戴 |
| 高中必修 4（哲学与文化） | 原理与方法论的对应；辨析题 | 原理贴标签，不结合材料；把矛盾的普遍性和特殊性、量变和质变用反 |
| 高中选必 2（法律与生活）、选必 3（逻辑与思维） | 案例分析（合同、侵权、婚姻家庭）；推理有效性判断 | 用旧法表述作答（见 5.2）；把"肯定后件"当作有效推理 |

## 5. 材料与事实准确性（本学科最重要的规则）

### 5.1 时政与权威表述

- **时政材料只用确定的、权威发布的内容**，如新华社、人民日报、中国政府网、全国人大网等发布的。要写明时间，有联网工具时核对。核对不了的不用，改用自拟的生活情境。
- **不编造政策条文、会议提法、领导人讲话和统计数字。**引用讲话必须是确证的原文；拿不准原文就不要用引号，也不要转述成"××指出"。
- 理论表述以统编教材的写法为准，不自行改写、简化或"通俗化"重要提法。
- 时政有时效性。教师版的 `source.note` 写明材料的发布时间，提醒老师使用前确认没有过时。

### 5.2 法律条文

- 法律名称用全称或规范简称，如《中华人民共和国未成年人保护法》《中华人民共和国民法典》。
- **拿不准条文号就不写条文号**，改成"根据××法的规定"，并且只陈述你确定的内容。课标样题引用地方条例时给出了原文和条号，这种写法只在原文确证时使用。
- **注意法律修订。**要用现行有效的版本。例如，民法典施行后，侵害肖像权不再以"以营利为目的"为要件；刑事责任年龄的规定近年也有修改。这类点出题前必须核对，不要沿用旧教辅的说法。
- 法律后果要说准："违法"不等于"犯罪"；民事责任、行政处罚、刑事处罚不能混用。

### 5.3 价值导向与敏感内容

- 立场正确是硬要求。涉及国家主权、领土、民族、宗教、党和国家制度的内容，一律用国家统一表述。
- 不出现戏谑、调侃党和国家政策、英雄人物的情境；也不为了"辨析"而引用错误言论的原文。需要辨析错误观点时，用概括性的转述（"有人认为……"）。
- **两难情境要有合理的出路。**不出"无论怎么选都违背价值观"的题，也不出诱导学生说出错误价值判断的题。
- **保护学生**：情境人物用化名；不要求学生写家庭收入、家庭矛盾或个人心理问题的细节；校园欺凌、侵害、自我伤害这类题材，只在课时目标确实需要时出，采用保护视角，写明求助途径（告诉老师、家长，必要时报警），不描写伤害细节。
- 小学的情境要贴近儿童生活，不出现成人化的社会冲突。

## 6. 正确性验证

基本都是 `check.method: "blind"`，按 `verification.md` 的要求试做。本学科要特别做两件事：

### 6.1 选择题、组合选择题逐说法过一遍

每个说法写一行，标三种状态之一：**本身错误 / 本身正确但材料没体现 / 正确且材料体现**。只有第三种能进入答案。然后检查：
- 有没有一个说法"可对可错"，要看怎么理解？有，就改写或换掉。
- 有没有两个组合都"说得通"？常见原因是题干没限定"材料体现"，或者某个说法和材料的关系模棱两可。
- 主体是否一致？题干问"国家应该"，选项里却有"中学生应该"。

### 6.2 主观题

- 每个评分要点都要能从"材料 + 教材观点"推出来，并注明对应的是哪个观点。
- 辨析题的"判断"部分只能有一个结论（全对、全错或部分对）。试做时如果发现两种判断都站得住，就是题目有歧义。
- 开放题拿"只背观点"的答案和"只谈感受"的答案各打一次分。如果它们能拿高分，评分标准就要改。
- **法条和时政逐条核对**：有联网工具就查，没有就降级（去掉条文号，或者换成自拟情境）。在自检记录里写明"本份作业未引用具体法条和时政"或"已核对"。

## 7. 常见病题

- **表态题**：答案是口号，任何学生都能照抄。
- **观点和情境硬贴**：情境里根本没有这个观点对应的行为。
- **说法有争议的选项。**
- **时政过期或无法核实**；法条号错误；沿用旧法的说法。
- **主体错位**：问中学生怎么做，答案却是国家措施。
- **两难情境没有合理出路**，或者诱导出错误的价值判断。
- **涉及学生隐私**，如"写出你家每月的开支"。
- **开放题说"言之有理即可"，却没有评分等级。**

## 8. 三层微型示例（八年级下册·依法行使权利）

课时目标：学生能辨析情境中行使权利的方式是否正当，并说明理由。三层共用一个社区情境，A1 作为铺垫。

**A1（情境单选）** 下列做法中，属于依法行使权利的是（　）
A. 为了讨回欠款，把欠款人的照片和家庭住址发到网上
B. 网购的商品有质量问题，向消费者协会投诉
C. 认为罚款不合理，当场辱骂执法人员
D. 为了让物业重视噪声问题，组织邻居堵住小区大门
- 答案 B。干扰项：A，以为维权可以公开他人的个人信息，侵犯了他人的隐私等权利；C，把发泄情绪当成维权；D，以为目的正当就可以影响公共秩序和他人通行。
- 画像 k0 s2 c1 r1 o0 g1。

**B1（评析）** 某小区新装的快递柜挡住了一段人行道，推婴儿车的家长和坐轮椅的老人经过很不方便。居民老王（化名）先在业主群里发帖提出调整位置的建议，收集邻居的意见；看到物业一直没有回应，他就在晚上把快递柜的电源拔掉，说这样"才能让物业重视"。请评析老王的做法。
- 升级：相对 A1，从"四个做法中选出正当的"变为"同一人的两个做法一分为二地评析"，学生要自己拆分行为并分别说理。`dims: c, g, o`。
- 画像 k1 s4 c2 r1 o1 g2。

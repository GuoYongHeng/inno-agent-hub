# 数学 · 小学题型谱（primary）

用于小学数学（一至六年级）。先读 `overview.md`。

---

## 1. 小学数学的硬边界（先看）

- **一、二年级不布置家庭书面作业**（"双减"意见原文："可在校内适当安排巩固练习"）。用户要一二年级的"作业"时，默认出**课内练一练**，或者非书面任务：数学游戏、动手操作、口头说算理、"身体上的尺子"测量、购物模拟。分层照做，题量要少。
- **三至六年级**每天书面作业合计平均不超过 60 分钟，这是所有学科加起来的。数学单科一次作业默认 15–20 分钟（A+B 层）。
- **小学不出"解方程"和"列方程解应用题"。** 2022 版课标把"方程与不等式"放在第四学段（七至九年级）；小学第三学段只要求"根据具体情境理解等式的基本性质"和"探索用字母表示事物的关系、性质和规律"。人教版新教材五年级上册已改为"用字母表示数和数量关系"，应用题用算术思路解。
  - 例外：用户明确说用的是旧版教材、正在学"简易方程"时，照用户说的出，并写进 `assumptions`。
- **可能性只做定性描述**："可能、一定、不可能""可能性大小"。不算概率分数（如 3/8），那是初中的内容。
- **百分数突出统计意义**：百分率、折扣、税率、利率都可以出。复杂的"连续涨跌""浓度配比"放 C 层，也不宜过多。
- **负数只在主题活动里"了解"**，不出负数运算。
- **教材在换版**：人教版新教材从 2024 年秋季一年级开始启用，逐年推进，单元位置和旧版不同。所以**本题型谱按知识块组织，不按单元号**。用户说"五上第三单元"时，按知识内容理解；不确定新旧版时，写进 `assumptions`。

## 2. 核心素养在小学题目上的样子

| 素养 | 题目长什么样 |
|---|---|
| 数感 | 先估一估再算；判断结果是否合理（"小明算出一本书 300 元，对吗？"）；在数轴上找位置 |
| 量感 | 给物体填合适的单位；估测（一个苹果约重 200 克）；用身体尺测量；单位换算 |
| 符号意识 | 用字母表示数和规律（小棒摆三角形，n 个要几根） |
| 运算能力 | **说算理**（"为什么竖式第二行要空一位？"）；圈出错步并订正；一题多算；选择简便方法 |
| 几何直观 | 画线段图解题；看图列式；用面积模型解释乘法 |
| 空间观念 | 由物想形、由形想物；展开图；从不同方向看；平移、旋转后画图 |
| 推理意识 | 找规律并说理由；判断对错并举例或说明 |
| 数据意识 | 根据问题选择统计图并说理由；读图后提出问题、作出判断 |
| 模型意识 | 加法模型、乘法模型（总价＝单价×数量，路程＝速度×时间）的同构题组 |
| 应用意识 / 创新意识 | 真实任务（购物、出行、营养午餐）；自己编题；答案不唯一的开放题 |

`objective` 里的素养用"意识"这类小学说法，不用"推理能力""模型观念"等初中说法。

## 3. 分层在小学的样子

| 层 | 小学典型题 |
|---|---|
| A 基础巩固 | 口算、竖式、填空；看图列式；一步应用题；判断正误。前两题可以给图示支架（线段图、圆片图、方格），每题最多 1–2 处提示，之后撤掉 |
| B 能力提升 | 两步应用题；说算理或找错订正；比较、选择方案；同一模型换情境；从统计图中读出并比较信息 |
| C 拓展挑战 | 找规律并用字母表示；开放题（答案不唯一）；编题；动手操作或实践小任务（测量、调查、设计）；数学广角类的思维题，但不出奥数技巧 |

- **小学 C 层不是奥数。** 鸡兔同笼、植树问题这类可以出，用列表法、画图法、假设法等教材里的方法；不出需要竞赛技巧的题。
- **题干要短。** 一二年级每句约 10 字以内，尽量配图（用 `figure` 描述）；三至六年级每句约 20 字以内。读不懂题会掩盖数学上的差异。
- **作答形式要多样**：圈一圈、连一连、涂一涂、画一画、说一说（写下来）。

## 4. 题型谱（按知识块）

| 知识块（大致年级） | 常考题型 | 经典母题结构 | 典型错因（可观察行为） |
|---|---|---|---|
| 20 以内加减（一年级） | 口算；看图列式；凑十、破十填空；比多少 | **一图四式**：a+b、b+a、c−a、c−b | 看图只列出一个算式；求"比……多几"时用了加法；破十时拆错 |
| 100 以内加减（一、二年级） | 口算；竖式；求比一个数多（少）几的数 | 竖式进位和退位；"多几""少几"的互逆题组 | 竖式忘记加进位的 1；退位后十位没有减 1 |
| 表内乘除（二年级） | 看图写乘、除法算式；平均分；有余数的除法 | **每份数×份数＝总数**三变式；租船问题（余数要进一） | 每份数和份数的意义说反；余数大于除数；该进一时直接舍去 |
| 万以内数、大数（二、三、四年级） | 读写数；比大小；近似数；数位顺序 | 中间、末尾有 0 的数的读写 | 中间的 0 漏读或多读；"读作"和"写作"混用；求近似数时看错数位 |
| 多位数乘除（三、四年级） | 竖式；估算；验算；积和商的变化规律 | **乘法模型同构题组**：单价×数量＝总价，速度×时间＝路程 | 竖式数位没对齐；商的中间或末尾漏写 0；该估算时却精算 |
| 小数（三、四、五年级） | 意义与性质；加减乘除竖式；单位换算 | 积的小数位数＝因数小数位数之和；除数是小数时转化为整数 | 积的小数点点错；商的小数点没有和被除数对齐；只扩大了除数 |
| 分数的意义与运算（三至六年级） | 意义；通分约分；分数加减乘除 | 异分母加减"先通分"；分数乘除的意义 | **分子分母分别相加**（1/2+1/3＝2/5）；约分不彻底；除以分数时没有乘倒数 |
| 分数（百分数）应用题（六年级） | 求一个数的几分之几；已知一个数的几分之几求这个数；量率对应 | **单位"1"** 题组：正向乘、逆向除 | 单位"1"找错；把"3/4 米"和"3/4"混为一谈；该用除法时用了乘法 |
| 四则运算与简便计算（四至六年级） | 运算顺序；运算律；凑整 | 101×a、a×99＋a、(a＋b)×c 的拆分 | 写成 a×(b＋c)＝a×b＋c；a−(b＋c) 写成 a−b＋c；没有括号也先算加减 |
| 用字母表示数（五年级） | 用式子表示数量；代入求值；找规律 | 小棒摆三角形：2n＋1 | 把 a² 写成 2a；省略乘号不规范，比如写成 a5 |
| 因数与倍数（五年级） | 找因数、倍数；质数合数；最大公因数、最小公倍数应用 | 用正方形铺满长方形（最大公因数）；同时出发再相遇（最小公倍数） | 质数和奇数混淆；把 1 当成质数；两种应用题的模型用反 |
| 比和比例（六年级） | 化简比、求比值；按比分配；比例尺；正比例、反比例的判断 | 按比分配三步法；图上距离与实际距离 | 化简比和求比值混淆（结果写成比还是数）；比例尺单位没有统一；把"都在增加"当成成正比例 |
| 百分数（六年级） | 百分率；折扣、成数、税率、利率；扇形统计图 | 增加或减少百分之几；先涨价后降价 | 出勤率的分母取错；以为先涨 10% 再降 10% 等于原价 |
| 长度、面积、体积单位与量感（各年级） | 填单位；换算；估测 | "一个苹果重 200（　）""教室门高约 2（　）" | 进率记错（面积 100、体积 1000）；单位选得离谱 |
| 周长与面积（三、四年级） | 长方形、正方形；组合图形；周长相等而面积不同 | 拼、剪图形后周长和面积的变化 | 周长和面积混淆；以为剪去一角后周长一定变小 |
| 多边形面积、圆（五、六年级） | 公式推导（转化）；组合图形；阴影部分面积 | 平行四边形、三角形、梯形之间的转化；外方内圆、外圆内方 | 三角形面积漏乘 1/2；把直径当半径；圆周长写成 πr |
| 立体图形（五、六年级） | 表面积、体积；展开图；容积；等积变形 | 无盖水箱；圆柱削成最大的圆锥；放入物体后水面上升 | 表面积多算或少算面；圆锥体积漏乘 1/3；容积和体积不分 |
| 图形的运动（各年级） | 平移、旋转、轴对称作图；密铺 | 在方格纸上按要求画图 | 平移格数数成了间隔数；旋转中心或方向弄错 |
| 位置与方向（各年级） | 数对；八个方向；路线图 | 以某点为观测点描述"北偏东 30°" | 换了观测点却没换方向；数对中列和行写反 |
| 统计（各年级） | 读图；补图；选图；平均数 | 条形图、折线图、扇形图的选用；平均数的意义 | 坐标刻度不等距；以为平均数就是每个数据的值 |
| 可能性（五年级） | 定性判断；按要求设计摸球方案 | 按要求放球，使摸到红球的可能性最大 | 把"可能性大"理解成"一定发生" |
| 数学广角（各年级） | 搭配、集合；鸡兔同笼；植树问题；找次品；鸽巢原理 | 列表法、假设法；植树的三种情况（两端都种、只种一端、两端都不种） | 把间隔数直接当棵数；假设法中用差值去除时除错 |
| 综合与实践（各学段） | 主题活动：欢乐购物街、时间在哪里、身体上的尺子、曹冲称象、校园平面图、营养午餐等 | 真实任务＋记录表＋汇报 | 任务要求写不清；只有"做"，没有"数学"（没有测量、计算或比较） |

## 5. 小学出题特别注意

- **数据要贴近儿童生活**：价格用 2026 年的合理水平（一支铅笔 1–3 元，一本练习本 2–5 元，一盒牛奶 3–6 元），人数和物品数都是整数，路程和时间合乎常识（步行每分钟约 60–80 米）。
- **一题多算、说算理**是小学升级最自然的路线：A 层"算一算"，B 层"说一说为什么这样算"或"找出错误并订正"，C 层"想出另一种算法"或"编一道用这个算式解决的问题"。
- **画图是支架，也是能力。** A 层可以给半成品的线段图，让学生补全；B 层要求学生自己画图；C 层让学生用图解释或比较方法。
- 计算题的数据也要设计：考进位就要真的进位，考"商中间有 0"就要真的出现 0。一组题里的数不要每次都一样难，也不要全是巧数。

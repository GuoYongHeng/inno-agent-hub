# 数学 · 初中题型谱（junior）

用于初中数学（七至九年级）。默认人教版，兼顾北师大版等，按知识内容对应。先读 `overview.md`。

每章包含三部分：
- **常考题型**，标注典型层级：[基] 基础巩固 / [中] 能力提升 / [压] 拓展挑战
- **母题变式链**：A → B → C 三层怎么从同一个母题变出来，可以直接用作蓝图
- **典型错因**：可观察的学生行为，用来设计干扰项和写讲评

> 版本说明：人教版新教材从 2024 年秋季七年级起分年级启用。七年级上册已把"有理数的运算""代数式"单独成章，八、九年级新版的章序以学校实际使用的教材为准。所以本表按**知识内容**组织，章名只作检索用。用户报了单元号但对不上时，按知识内容理解，并写进 `assumptions`。

## 1. 中考命题风向 → 出题规则

依据：2022 版课标的命题建议，教育部办公厅 2022 年中考命题通知，以及 2025–2026 年各地中考数学评析。

1. **严格依标，不超标。** 不用高中内容、竞赛题、培训机构的"秒杀模型"。偏题、怪题不出。
2. **减少记忆性、单纯技能熟练性的题，增加探究性、开放性、综合性的题。** 作业里纯计算的同构题限量（每层最多 2 道）。
3. **关注通性通法，淡化特殊技巧。** "手拉手""将军饮马""一线三等角"这类模型可以作为 B、C 层的母题，但解析要讲清楚为什么这样做，比如为什么要构造全等，而不是"套模型"。
4. **情境分三类：生活情境、数学情境、科学情境。** 要真实，可以适当引入数学文化（《九章算术》、赵爽弦图、杨辉三角）。各地中考爱用本地和时事素材（新能源车、快递物流、体育赛事、科技新闻）。作业里可以用，但数据要合理，或者标明"虚构"。
5. **重视"数学阅读"和"现实情境数学化"。** 常见形式是新定义题、阅读材料题、从真实规则中抽取数量关系的题。这类题适合放在 C 层，按"由浅入深的多问"来设计。
6. **开放、综合题要配多层次的评分标准。** 比如统计决策题，"选对统计量并说明理由"给满分，"只算出统计量"给部分分。
7. **试卷整体比例**：中考常见的易、中、难比例约为 7:2:1，各地不同。一份分层作业不按这个比例组卷，而是按三层的定位组卷。整份作业算下来通常 A 层占四成多，B 层占三成多，C 层占两成左右。

## 2. 按章题型谱

### 数与代数

**有理数 · 有理数的运算（七上）**
- 题型：相反数、绝对值、倒数辨析[基]；数轴比较大小，数轴上两点的距离[基]；科学记数法（时事大数）[基]；含乘方、绝对值的混合运算[基]；数轴动点问题[中]；程序框图或数列规律[中]
- 母题链：数轴上 A、B 两点表示的数（A 层：求两点距离、中点）→ 两点同时出发相向运动，求相遇时刻（B 层：用 |a−b| 表示距离，列方程）→ 求两点距离为定值时的 t，需要分类，并说明有几个解（C 层）
- 错因：把 −3² 和 (−3)² 混为一谈；减法变加法时只改运算符号，不改减数的符号；乘除混合时先乘后除，没有从左到右；科学记数法写成 12×10⁵；|x|＝3 只取 3

**代数式 · 整式的加减（七上）**
- 题型：列代数式（文字、图形周长和面积）[基]；同类项判定，求待定指数[基]；去括号化简求值[基]；整体代入[中]；"结果与 x 的取值无关"求参数[中]；图形个数规律，第 n 个图形[中]
- 母题链：化简求值（A）→ 已知 a−2b＝3，求 2a−4b＋1，整体代入（B）→ 化简后与 x 无关，求 m、n，或者"小明看错了一个符号，结果却正确，为什么"（C，说理）
- 错因：括号前是负号时只变第一项的符号；把 3a 和 3a² 当成同类项合并；合并同类项时连指数也相加；代入负数不加括号

**一元一次方程（七上）**
- 题型：去分母、去括号解方程[基]；由方程的解求参数[基]；应用题：行程（相遇、追及）、工程、配套、打折利润、分段计费、比赛积分[中]；看错系数后还原原方程[中]
- 母题链：直接列方程求解的一步应用题（A）→ 打折后仍盈利 20%，求进价（B，量的关系要转化）→ 两种方案的分段计费，问在什么情况下哪种更划算，需要讨论（C）。注意：本章不用不等式，比较方案可以通过"求相等的点，再代入数值比较"来完成
- 错因：去分母时漏乘不含分母的项；分子是多项式时没加括号；移项不变号；利润率以售价为基数；单位不统一

**实数（七下 / 八上）**
- 题型：平方根、算术平方根、立方根[基]；识别无理数[基]；估算 √n 的整数部分和小数部分[基→中]；实数运算[基]；在数轴上表示 √2[基]
- 母题链：求 √20 在哪两个整数之间（A）→ √n 的整数部分为 a、小数部分为 b，求含 a、b 的代数式的值（B）→ 在数轴上作出表示 √5 的点，并说明理由（C，几何直观与说理）
- 错因：√16 的平方根写成 ±4（应为 ±2）；认为带根号的数都是无理数；把 22/7 当成无理数；|1−√2| 去绝对值时符号错

**二元一次方程组（七下 / 八上）**
- 题型：代入消元、加减消元[基]；同解或错解求参数[中]；整体求 x＋y[中]；应用题：鸡兔同笼、调配、《九章算术》[基→中]；求非负整数解的方案[中]
- 母题链：已知两种物品的单价和总价求数量（A）→ 先求单价，再在总费用固定的条件下求购买方案数（B，二元一次方程的非负整数解）→ 结合"费用最少"选最优方案，并说明理由（C）
- 错因：一个方程乘了倍数，另一边没乘；两式相减时负号只作用于第一项；求出 x 后忘记回代求 y；方案题没有检验整数性

**不等式与不等式组（七下 / 八下）**
- 题型：不等式性质，乘除负数要变号[基]；解不等式（组），在数轴上表示，求整数解[基]；含参数：有解、无解、整数解个数[中→压]；求最多、最少[中]
- 母题链：列一元一次不等式求"最多、至少"（A）→ 先用方程组求单价，再用不等式求"至少买几件"（B）→ 由整数解个数反求参数范围，或者多约束下的最省方案（C）
- 错因：乘除负数不变号；数轴上空心点和实心点混用；"不超过"写成 <；参数端点不检验；"至少"时向下取整

**整式的乘法与因式分解（八上）**
- 题型：幂的运算辨析[基]；乘法公式及其拼图验证[基→中]；化简求值[基]；提公因式法与公式法[基]；由 a＋b、ab 求 a²＋b²[中]；杨辉三角[中]
- 母题链：用完全平方公式计算（A）→ 已知 a＋b＝5、ab＝6，求 a²＋b² 和 (a−b)²（B，公式变形）→ 用面积拼图说明 (a＋b)²＝a²＋2ab＋b²，并设计一个图来说明 (a＋b＋c)² 的展开式（C，几何直观与构造）
- 错因：(a＋b)² 漏掉中间项；a³·a²＝a⁶；x⁴−1 分解不彻底；提公因式后漏掉"1"

**分式（八上）**
- 题型：分式有意义、值为 0 的条件[基]；化简后选值代入[基→中]；负整数指数，小数的科学记数法[基]；解分式方程并检验[基]；由增根、无解求参数[中]；两次进货的单价问题[中]
- 母题链：解分式方程并检验（A）→ 两次进货的数量与单价关系，列分式方程，并检验实际意义（B）→ 关于 x 的分式方程无解，求参数的所有可能值（C，需要分两类：去分母后的整式方程无解，或者解是增根）
- 错因：值为 0 时忘记分母不为 0；选的代入值使原分母为 0；不检验根；化简分式时当成解方程去分母

**二次根式（八下）**
- 题型：有意义的条件[基]；结合数轴上的范围化简 √(a²)＝|a|[中]；最简二次根式、同类二次根式[基]；混合运算、分母有理化[基]；代入 x＝√3＋1 求值[中]
- 母题链：二次根式的混合运算（A）→ 根据数轴上 a、b 的位置化简 √(a²)−|a−b|（B）→ 已知 x＝√3＋1，求 x²−2x 的值，比较直接代入和先变形两种方法（C，说理和方法选择）
- 错因：√2＋√3＝√5；√(a²) 直接写成 a；结果没有化成最简二次根式

**一次函数（八下）**
- 题型：由 k、b 判断图象和性质[基]；待定系数法[基]；交点与不等式的图解[基→中]；行程、注水的分段图象[中]；方案最优（带自变量取值范围）[中]；与坐标几何综合[中→压]
- 母题链（两条主线）：
  - **方案选择**：给出两种收费方式，写出 y₁、y₂（A）→ 求临界点，并按区间给出选择结论（B）→ 增加第三种方案，或者加上整数、取值范围的约束，求最优方案并说理（C）
  - **图象信息**：读单一图象的拐点含义（A）→ 甲、乙两车的双图象，求相遇时间和距离（B）→ 由图象反推情境，或者补全图象并说明理由（C）
- 错因：k<0 时增减性记反；读错拐点的实际意义；只求交点，不按区间下结论；漏掉整数等实际限制；自变量取值范围不写

**数据的收集、整理与描述 · 数据的分析（七下、八下）**
- 题型：普查与抽样；总体、个体、样本容量[基]；条形图与扇形图互相补全，求圆心角[基→中]；用样本估计总体[基]；加权平均（权的含义）[基]；中位数、众数、方差[基]；选用统计量做决策（开放说理）[中]；数据都加 a 或都乘 k 后统计量的变化[中]
- 母题链：两图联动，求样本容量并补全条形图（A）→ 求扇形的圆心角，估计全校人数，并评价抽样是否合理（B）→ **决策型开放统计**：甲乙两组成绩，从不同统计量出发评价，或者自己设计权重来决定录用谁，并说明理由（C，参考课标例 93 的招聘情境）
- 错因：样本容量带单位；总体漏写考查对象（应为"全校学生的视力"，而不是"全校学生"）；中位数不排序就取；偶数个数据不取中间两数的平均；把众数写成出现次数；以为方差越大越好

**一元二次方程（九上）**
- 题型：由 a≠0 求参数[基]；配方法、公式法、因式分解法[基]；判别式[基→中]；根与系数的关系（人教版作为选学，各地考查要求不同）[中]；增长率、靠墙围栏、传播、降价促销[中]
- 母题链：增长率问题求平均增长率（A）→ 靠墙围栏，结合墙长检验舍根（B）→ 每降价 1 元多卖 k 件，利润能否达到某个值，用判别式说明（C，存在性说理）
- 错因：两边约去含 x 的因式导致丢根；二次项系数不是 1 就直接配方；判别式题忘记 a≠0；连续两次增长写成 (1＋2x)；不检验实际意义

**二次函数（九上）**
- 题型：开口方向、对称轴、顶点、增减性[基]；由图象判断 a、b、c 的符号及 a＋b＋c、2a＋b 的符号[中]；平移[基]；三种形式的待定系数法[基]；利润、拱桥、投球的最值（限定自变量取值范围）[中]；存在性、面积最值、线段最值[压]
- 母题链：
  - **实际最值**：给出解析式求最值（A）→ 由"每涨 1 元少卖 10 件"列出利润函数，求最大利润，顶点在取值范围内（B）→ 顶点不在取值范围内，或者增加"每天至少卖 m 件"的约束，需要在端点取最值并说理（C）
  - **几何综合**：求抛物线解析式及与坐标轴的交点（A）→ 求 △PBC 面积的最大值（B，铅垂高）→ 平行四边形或等腰三角形的存在性（C，分类讨论）
- 错因：对称轴 −b/2a 漏掉负号；平移"左加右减"用反；顶点不在取值范围内仍取顶点值；存在性问题分类不全

**反比例函数（九下）**
- 题型：性质（"在每个象限内"）[基]；k 的几何意义[基→中]；与一次函数的交点，看图写不等式解集[中]；压强、药物浓度等分段实际问题[基→中]；与几何综合[压]
- 母题链：求反比例函数的解析式和函数值（A）→ 与一次函数交于 A、B 两点，求两个解析式和 △AOB 的面积（B）→ 写出 y₁>y₂ 时 x 的取值范围（含两支），或者点在曲线上移动时面积是否不变并说理（C）
- 错因：描述增减性时漏掉"在每个象限内"；把三角形面积当成 |k|（应为 |k|/2）；写不等式解集时漏掉 x<0 那一支

### 图形与几何

**几何图形初步（七上）**
- 题型：正方体展开图找相对面[基]；线段中点与和差[基→中]；余角、补角、角平分线、钟面角[基→中]；方位角[基]；"两点之间线段最短"的生活解释[基]
- 母题链：已知中点求线段长（A）→ "双中点"问题：C 在线段 AB 上，M、N 分别是 AC、BC 的中点，求 MN（B）→ C 在线段 AB 的**延长线**上时结论是否仍成立，需要分类，并推广到角平分线（C）
- 错因：漏掉点在延长线上的情况；度分秒按 100 进制换算；展开图的相对面判错；钟面角没有算时针的移动

**相交线与平行线（七下）**
- 题型：推理填空并写理由[基]；"拐点"求角[中]；纸条折叠求角[中]；平移与"小路"面积[基]；命题的真假、举反例[基]
- 母题链：由平行线求角并写理由（A）→ AB∥CD，点 E 在两线之间，证明 ∠BED＝∠B＋∠D（B）→ E 在两线外侧时结论如何变化，并探究一般规律（C）
- 错因：判定和性质的理由互相用反；不看截线就认同位角、内错角；"垂线段最短"和"两点之间线段最短"混用

**平面直角坐标系（七下 / 八上）**
- 题型：各象限和坐标轴上点的符号[基]；点到坐标轴的距离[基]；平移后坐标的变化[基]；平行于坐标轴的直线上点的特征[基]；割补法求面积[中]；螺旋、跳跃型坐标规律[中]
- 母题链：求点平移后的坐标（A）→ 用割补法求 △ABC 的面积（B）→ 在坐标轴上找点 P，使 S△PAB＝S△ABC，需要分类，写出所有的点（C）
- 错因：点到 x 轴的距离写成 |x|；平移时把横坐标的变化加到纵坐标上；由 |y|＝3 只取正值；横纵坐标颠倒

**三角形（八上）**
- 题型：三边关系，求第三边的范围[基]；等腰三角形的边要分类讨论[基→中]；内角和外角[基]；多边形的内角和、外角和[基]；中线平分面积[基]
- 母题链：已知两边求第三边的范围（A）→ 等腰三角形两边长为 4 和 9，求周长，分类后要验证三边关系（B）→ 角平分线夹角：证明 ∠BOC＝90°＋½∠A，再研究外角平分线的情形（C）
- 错因：分类后不验证三边关系；钝角三角形的高画在了内部；以为外角和随边数变化

**全等三角形（八上）**
- 题型：补全判定条件（SSA 陷阱）[基]；证全等，再推出线段或角相等[基→中]；角平分线的性质[基]；倍长中线、截长补短[中→压]；共顶点的旋转全等[中→压]；测河宽[基]
- 母题链：给出条件证全等（A）→ 两个共顶点的等边三角形，证明 BD＝CE（B）→ 绕公共顶点旋转后结论是否仍成立，并求两线所夹的角（C，探究）
- 错因：用 SSA、AAA 判全等；对应顶点的顺序写乱；三个条件没有列全；没有作垂线就用"角平分线上的点到两边距离相等"

**轴对称（八上）**
- 题型：识别轴对称图形（文化标志、汉字）[基]；用垂直平分线转化周长[基]；等腰三角形三线合一[基→中]；关于坐标轴对称的点[基]；最短路径（将军饮马）[中]；等腰三角形的存在性[中→压]
- 母题链：作出关于直线的对称点（A）→ 在直线 l 上找一点 P，使 PA＋PB 最小，作图并说明理由（B）→ 在坐标轴上找点 P，使 △PAB 为等腰三角形，有几个？（C，分类讨论）
- 错因：存在性问题漏解；对不是等腰的三角形用三线合一；关于 x 轴对称时改了横坐标

**勾股定理（八下）**
- 题型：求第三边（要讨论哪条是斜边）[基]；逆定理[基]；折叠中列勾股方程[中]；圆柱、长方体表面的最短路径[中]；梯子滑动、折竹[基→中]；赵爽弦图[基]
- 母题链：已知两直角边求斜边（A）→ 矩形纸片折叠，点落在边上，设 x 列方程（B）→ 长方体表面的最短路径，比较几种展开方式并说明哪种最短（C）
- 错因：不讨论哪条是斜边；用逆定理时不先找最长边；长方体只算一种展开方式

**平行四边形 · 特殊平行四边形（八下 / 九上）**
- 题型：判定与性质的证明[基→中]；三角形中位线，直角三角形斜边上的中线[基]；中点四边形[中]；动点构成平行四边形，求时间 t[中]；正方形中的十字架、半角模型[中→压]
- 母题链：证明一个四边形是平行四边形（A）→ 再加一个条件，证明它是菱形或矩形（B）→ 中点四边形：原四边形满足什么条件时，中点四边形是菱形、矩形或正方形？说明理由（C，探究和一般化）
- 错因：判定条件不足（"一组对边平行，另一组对边相等"）；菱形面积用边长×边长；动点问题漏掉对应顶点的不同情况

**旋转（九上）**
- 题型：中心对称图形[基]；由旋转的性质求角和线段[基]；在坐标系中旋转 90°、180°[基→中]；旋转构造（已知 PA、PB、PC 求 ∠APB）[中→压]；图案设计[基]
- 母题链：求点绕原点旋转 90° 后的坐标（A）→ 由旋转得到等腰三角形，求角度（B）→ 等边三角形内一点 P，已知 PA、PB、PC，求 ∠APB，需要构造旋转（C）
- 错因：顺时针、逆时针弄反；坐标旋转时符号错；中心对称与轴对称混淆

**圆（九上）**
- 题型：垂径定理、拱高[基]；圆周角定理[基]；切线的证明（连半径证垂直，或作垂直证半径）[中]；切线与相似、三角函数结合求线段[中]；弧长、扇形面积、阴影面积[基→中]；圆锥的侧面展开、正多边形[基]；隐圆最值[压]
- 母题链：用垂径定理求弦长或拱高（A）→ AB 是直径，CD 与 AB 的延长线交于 D，∠DCA＝∠B，证明 CD 是切线（B）→ 再给出 tan 的值求半径，或者研究点运动时某个量的最值（C）
- 错因：一条弦所对的圆周角漏掉一个解（优弧、劣弧上各一个）；两种切线证法用错场合；圆锥的母线和底面半径混淆

**相似（九下）**
- 题型：比例、黄金分割[基]；判定，面积比等于相似比的平方[基]；A 字型、8 字型、一线三等角[中]；影长、标杆、平面镜测高[基→中]；位似[基]；动点相似的存在性[压]
- 母题链：用相似三角形测高（A）→ 一线三等角：∠B＝∠APD＝∠C，证明 △ABP∽△PCD（B）→ 动点 P 运动时，CD 的最大值是多少，或者是否存在 P 使两三角形相似，需要讨论对应关系（C）
- 错因：对应边写错；面积比直接用相似比；只考虑一种对应关系；位似漏掉另一侧的图形

**锐角三角函数（九下）**
- 题型：在网格中按定义求值[基]；特殊角的三角函数值[基]；仰角、俯角、坡度、方位角（双直角三角形）[中]；实际建模（摄像头俯角、自动门、遮阳棚）[中]
- 母题链：在直角三角形中求边（A）→ 两处测得仰角 α、β，两处相距 a，设公共边为 x 列方程（B）→ 从真实装置中抽象出直角三角形并判断设计是否合理，比如遮阳棚能否挡住正午的阳光（C，建模与检验）
- 错因：sin、cos 对应的边用错；把坡度当成角度；俯角画在铅垂方向；中间步骤过早取近似值

**投影与视图（九下）**
- 题型：识别三视图[基]；由三视图求表面积、体积[基→中]；小正方体个数的最多与最少[中]；中心投影与平行投影[基]
- 母题链：画出简单几何体的三视图（A）→ 由三视图求几何体的表面积（B）→ 给出主视图和俯视图，求小正方体最多、最少各几个，并说明理由（C）
- 错因：虚线和实线用反；"长对正、高平齐、宽相等"对应错；俯视图的位置放错

### 统计与概率

**概率初步（九上）**
- 题型：随机事件、必然事件、不可能事件[基]；列表法、树状图法（放回与不放回）[基]；用频率估计概率[基]；游戏是否公平[基→中]
- 母题链：从四人中选两人，求恰好选中甲、乙的概率（A）→ 不放回摸球，用树状图求概率（B）→ 设计一个公平的游戏规则，或者判断一个游戏是否公平并修改规则（C，开放）
- 错因：不放回的情境按放回列表；结果不是等可能的（把"一正一反"的概率当成 1/3）；树状图漏掉分支

## 3. 跨章专题（适合做 C 层或单元作业）

- **尺规作图**：作垂直平分线、角平分线、垂线、等长线段。题目写"保留作图痕迹，不写作法"。C 层可以出"用尺规作图解决实际选址问题"。
- **新定义题**：先给一个新概念，配一个示例；第 (1) 问判断给定对象是否满足定义，第 (2) 问求参数或范围，第 (3) 问综合推广。定义只能依赖已学知识。
- **规律探索**：数式规律、图形规律。要求写出第 n 项，并验证或说明。答案用程序算出前几项来核对。
- **自定义变量建模**（参考课标例 92 的纸杯叠放）：只给示意图和实测数据，让学生自己确定自变量和常量，写出函数关系，再检验。
- **综合与实践项目**：按"素材 → 任务一、二、三"呈现，比如包装盒设计、校园测量、出行方案。最后一问要求学生"反思模型的合理性"。作为 C 层或单独的长作业。
- **跨学科**：以物理、地理等为载体，比如弹簧伸长、温度换算、坡度、电费阶梯，但考查的是数学概念。科学数据要真实，或者标明"示意"。

## 4. 初中出题特别注意

- **几何题一定要写 `figure`**，用文字完整描述图形；能建系的给坐标，方便用程序验算。
- **证明题的 `answer_points`** 按"条件—推理—结论"分步给分。解析里的每一步都写出依据（定理名）。
- **分类讨论是 B、C 层的核心升级手段**：点的位置、等腰三角形的腰和底、对应关系、参数的正负。但分类要有必要，答案必须把所有情况写全。
- **"至少""最多"、整数、取值范围**等限定，在应用题里一律写明。
- **数据规整**：初中题的答案尽量是整数或简单分数；根式只在本课内容需要时出现；三角函数实际问题给出近似值的取法，比如"√3 取 1.73，结果精确到 0.1 米"。

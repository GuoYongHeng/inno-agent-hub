# 数学 · 高中题型谱（senior）

用于高中数学（人教 A 版 2019 新教材为默认；北师大版、苏教版、湘教版按知识内容对应）。先读 `overview.md`。

---

## 1. 分层锚点：学业质量水平与情境（课标原文要点）

| 层 | 学业质量 | 情境 | 问题 | 课标对能力的典型表述 |
|---|---|---|---|---|
| A 基础巩固 | 水平一（合格考的依据） | 熟悉的情境 | 简单问题 | "在熟悉的情境中，直接抽象出数学概念和规则"；"模仿学过的数学建模过程解决问题" |
| B 能力提升 | 水平二（高考的命题依据） | 关联的情境 | 较复杂问题 | "在关联的情境中"；"在新的情境中选择和运用数学方法"；"通过举反例说明某些数学结论不成立"；"合理选择运算方法、设计运算程序" |
| C 拓展挑战 | 水平二到三 | 综合的情境 | 复杂问题 | "构建过渡性命题，探索论证的途径"；"在得到的数学结论基础上形成新命题"；"创造性地建立数学模型" |

情境分三类：现实情境、数学情境、科学情境。每类分熟悉的、关联的、综合的三档。教师版"情境"一列写成"数学情境·熟悉"这样的格式。

课标的命题原则：
- 要有一定数量的应用问题、开放性问题和探究性问题；
- 开放题"遵循满意原则和加分原则"；
- "逐步减少选择题、填空题的题量；适度增加试题的思维量"。

## 2. 新高考命题风向 → 出题规则

**卷面结构**：新课标卷（2024 年起）共 19 题。8 道单选（每题 5 分）、3 道多选（每题 6 分，部分选对按比例得分）、3 道填空（每题 5 分）、5 道解答题（13/15/15/17/17 分），满分 150。2026 年新课标 I、II 卷仍是这个结构。

**评析的关键词**：2024–2026 年教育部教育考试院等的公开评析反复强调"重基础、强思维、反套路、重应用、求创新""多想少算""淡化解题技巧和二级结论""摒弃细分试题类型、总结解题套路的备考模式"。压轴题常用**新定义**（2024 年 I 卷以数列为背景、2026 年 I 卷以函数为背景的新定义题），或者导数的多问递进。

**变成出题规则**：
1. **A 层考概念和通法，不考二级结论。** 解析里不使用"秒杀公式"。需要用到某个结论时，先推一遍，或者在题干里给出。
2. **B 层设计"套路失效"的变式**：把固定点改成参数；换一个函数族（比如从幂指对换成三角）；把"求值"改成"判断能否取到"；把条件改成多个可选的条件，让学生自己选（结构不良题）。
3. **选择和填空要"多想少算"**：优先用对称性、几何定义、数形结合，压缩运算量。不要出一道纯靠长计算区分学生的小题。
4. **C 层可以用新定义或多问递进**：(1) 读懂定义，代入具体例子验证；(2) 用定义推出一个性质；(3) 推广或分类讨论。定义必须完整无歧义，并给一个示例。
5. **多选题只在高中出**：设 2–3 个正确选项。每个错误选项都要对应一个具体错误；正确选项之间不要互相蕴含得太明显。
6. **数学建模和数学探究**按课题研究的方式组织，经历"选题、开题、做题、结题"，成果可以是专题作业、测量报告、算法程序、实物、研究报告或小论文。适合放在 C 层，或作为单独的长作业。

## 3. 题型谱（按章节）

| 章节 | 常考题型 / 经典母题 | 典型错因（可观察行为） |
|---|---|---|
| 集合与常用逻辑用语 | 交并补运算（常与解不等式结合）；由包含关系求参数；充分必要条件；含量词命题的否定 | 由 A⊆B 求参数时漏掉 A＝∅；端点开闭写错；否定时只改结论不改量词 |
| 一元二次函数、方程和不等式 | 一元二次不等式（含参数讨论）；基本不等式求最值；不等式恒成立 | 用基本不等式不检验"一正二定三相等"；含参数时漏讨论二次项系数为 0 |
| 函数的概念与性质 | 定义域与值域；单调性的定义法证明；奇偶性、周期性、对称性的综合，如由 f(x＋2)＝−f(x) 推周期；分段函数 | 求定义域漏掉条件；用定义证单调性时没有作差变形到能判断符号；把"关于 x＝1 对称"和"周期为 2"混淆 |
| 指数函数、对数函数、幂函数 | 比较大小（借助中间量 0、1）；指对运算；零点个数（数形结合）；函数模型（指数增长、对数模型） | 对数的真数没有限制为正；底数与 1 的大小没有讨论；换底公式用错 |
| 三角函数 | 诱导公式、同角关系求值；恒等变换；y＝Asin(ωx＋φ) 的图像与性质；由图像求解析式；ω 的取值范围 | 开方时象限符号判断错；图像平移时忘记提出 ω（左移 π/6 写成 ωx＋π/6）；ω 范围的端点开闭弄错 |
| 解三角形（必修二） | 正余弦定理边角互化；面积；中线、角平分线；实际测量 | 由正弦值求角时漏掉钝角解，或者没有舍去；边角互化后约分时丢根 |
| 平面向量 | 线性运算与基底表示；数量积求模、夹角、投影；坐标运算；三点共线 | 夹角为钝角时没有排除两向量反向共线；系数比较时没有说明基底不共线 |
| 复数 | 四则运算；模；共轭；几何意义；复数相等求参数 | 把 i² 当成 1；分母实数化时符号出错；"纯虚数"漏掉虚部 ≠ 0 |
| 立体几何初步 | 表面积、体积；外接球与内切球；平行、垂直的判定与性质证明 | 证明时缺少"直线在平面外（内）"等关键条件；外接球的球心位置找错 |
| 统计（必修） | 抽样；频率分布直方图；百分位数；平均数、方差 | 求百分位数前没有排序；把直方图的纵轴（频率/组距）当成频率 |
| 概率（必修） | 古典概型；互斥、对立、独立事件 | 混淆互斥与独立；列出的基本事件并不等可能 |
| 空间向量与立体几何 | 建系求线面角、二面角、距离；存在性探索题（点在线段上，求比例） | 线面角用了余弦而不是正弦；二面角是锐角还是钝角判断错；法向量计算错 |
| 直线和圆的方程 | 位置关系；弦长；切线；圆与圆；对称 | 设点斜式时漏掉斜率不存在的情况；切线条数判断错 |
| 圆锥曲线 | 定义法；离心率（值与范围）；焦点三角形；直线与曲线联立后用韦达定理求弦长、面积、定点、定值、范围 | 联立后没有检验 Δ>0；设直线时漏掉特殊情形；计算链过长导致出错（**命题时要压缩运算量**） |
| 数列 | 由 aₙ 与 Sₙ 的关系求通项；等差、等比的判定与证明；错位相减、裂项相消求和；数列与不等式；新定义数列 | 由 Sₙ 求 aₙ 时漏验 n＝1；错位相减时最后一项的符号或项数错；证明"是等比数列"时漏证首项不为 0 |
| 一元函数的导数 | 切线（"在点"与"过点"）；单调区间；极值、最值；含参数讨论；恒成立（分离参数或端点效应）；零点个数；不等式证明 | 没有先写定义域；含参数讨论分类不完整；"在点"和"过点"混淆；分离参数后最值取不到也照写 |
| 计数原理 | 排列组合（相邻、不相邻、分组分配）；二项式定理（特定项、系数和） | 分组分配时重复计数（平均分组没有除以组数的阶乘）；把"二项式系数"和"项的系数"混淆 |
| 随机变量及其分布 | 条件概率；全概率公式；二项分布与超几何分布；期望与方差；实际决策题 | 有放回和无放回的模型选错；分布列的概率之和不为 1 也没有检查 |
| 成对数据的统计分析 | 相关系数；一元线性回归；2×2 列联表与独立性检验 | 把相关当成因果；独立性检验的结论表述错（如说成"有 99% 的把握某人患病"） |

## 4. 高中出题特别注意

- **运算量要控制。** 解析几何、导数的题，在 A、B 层尽量把数据设计得规整：判别式是完全平方，导数零点是整数或简单根式。计算繁琐不等于考思维。
- **含参数讨论**是 B 层最常用的升级维度（`c=2`）。题目要让分类的标准自然出现，答案按分类完整写出。
- **"在区间上单调"不等于"定义在区间上"**：题干写"f(x) 在 (−1, 2) 上单调递减"，就不能在答案里用"定义域是 (−1, 2)"去限制变量；需要这个限制，就把题干写成"定义在 (−1, 2) 上的减函数 f(x)"。
- **端点、定义域、特殊情形**是高中最大的病题来源。每道求范围的题，审卷时都要把端点代回去检验；直线与圆锥曲线的题，要检查斜率不存在、与渐近线平行等特殊情形。
- **证明题**的 `answer_points` 按步写得分点，与高考评分习惯一致：关键步骤给分，结论给分。
- **排版**：复杂式子用 LaTeX（`$...$`），简单的仍用 Unicode。
- **选必内容的先后**：选必一（空间向量、直线与圆、圆锥曲线），选必二（数列、导数），选必三（计数原理、随机变量、成对数据）。出作业时只用本节及之前学过的内容。高一的作业不出导数，必修一的函数作业不用导数判断单调性。

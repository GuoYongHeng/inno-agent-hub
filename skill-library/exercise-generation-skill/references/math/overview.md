# 数学 · 总纲（overview）

学科是数学时必读。读完这份，再读对应学段的题型谱：`primary.md`（小学）、`junior.md`（初中）、`senior.md`（高中）。

---

## 1. 课标锚点

### 1.1 课标对命题和习题的要求（2022 版义务教育数学课标，原文摘要）

- **命题原则**："关注数学的本质，关注通性通法"；"适当提高应用性、探究性和综合性试题的比例，题目设置要注重创设真实情境，提出有意义的问题"。
- **命题规划**："试卷呈现避免套路化"；"要着重减少单纯考查技能熟练性的题目"；要"科学制订多维细目表"，内容包括题型题量、难易程度、分值比例。
- **试题命制**："明确考查意图"，即每道题要考查的知识和核心素养表现；"设计合理的生活情境、数学情境、科学情境，关注情境的真实性"；"注重考查学生的思维过程，避免死记硬背、机械刷题"；"对开放性、综合性较强的试题，合理设计多层次任务的评分标准"。
- **习题设计**："满足巩固、复习、应用、拓展的学习需要；满足不同学生的学习需要"。综合与实践类作业可以包括查阅资料、校外调查、自主探索。

落到本技能：
- 细目表、考查点、情境要必要，这几条已经写进流程。
- **用"减少单纯技能熟练性"来约束题量**：一份作业里纯计算的同构题不超过 2 道，其余题都要求思考。

### 1.2 核心素养（写 `objective` 时用学段对应的说法）

| 学段 | 核心素养表现 |
|---|---|
| 小学 | 数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识 |
| 初中 | 抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识 |
| 高中 | 数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析 |

注意：小学说"意识"（推理意识、模型意识），初中说"能力/观念"（推理能力、模型观念），不要混用。

`objective` 的写法是"知识点 + 素养表现"，例如"一次函数图像与性质的对应（几何直观）"。不要只写一个素养名，因为那等于没写。

### 1.3 高中的分层锚点

高中课标给出了学业质量水平和情境划分，可以直接用来分层：
- 情境分三类：现实情境、数学情境、科学情境；每类又分**熟悉的、关联的、综合的**。问题分**简单、较复杂、复杂**。
- 水平一：熟悉情境中直接模仿学过的方法解决简单问题。这是合格考的依据。
- 水平二：关联情境中选择和运用方法。这是高考的命题依据。
- 水平三：综合情境中运用或创造方法。
- 对应三层：**A ≈ 熟悉情境 + 简单问题，B ≈ 关联情境 + 较复杂问题，C ≈ 综合情境 + 复杂问题**。

## 2. 数学出卷老师的组卷方法

1. **抓通性通法，不抓技巧。** A、B 层考的都是这一课的通用方法，比如"设—列—解—验"、待定系数法、数形结合。C 层可以综合、可以一般化，但**不出竞赛技巧、偏题怪题**。
2. **母题 + 题组。** 选一道最能代表本课的母题，按"正用 → 逆用 → 变式 → 综合 → 一般化"的顺序变出题组。数学最常用的升级路线：
   - **改问法**：求值 → 求参数 → 求范围 → 判断存在性 → 说明理由
   - **改条件给法**：直接给式子 → 给表格 → 给图像 → 给文字情境；条件从显性变为隐含（比如"图中两线平行"由角相等推出）
   - **改对象数量**：一个 → 两个比较 → 一族（含参数）
   - **加分类讨论**：点的位置不确定、等腰三角形的腰和底、绝对值、含参数的一次项系数正负
   - **由算到说**：判断他人解法对错并订正，说明结论为什么成立，举反例
   - **由做到编**：给出模型，让学生编题
3. **解答题搭台阶。** B、C 层的综合题用 (1)(2)(3) 分小问：(1) 基础，大多数人能得分；(2) 中档；(3) 区分。这本身就是"题内分层"，可以和"层间分层"同时用。
4. **反向设计数据。** 先定好想要的规整答案，再倒推条件中的数。比如想让交点是 (2, 3)，就先选好直线再写系数。数据要规整：初中尽量是整数或简单分数；根式只出现在本课就是根式运算的情况下；答案里不出现 4.137 这类数，除非题目要求近似。
5. **运算量不是好的升级旋钮。** 把数从个位换成三位、把系数换成分数，只会更繁，不会更需要思考，这正是课标要"减少"的。要升级，就动条件给法、问法、知识综合度、说理要求。

## 3. 数学题型规范

| 题型 | 规范 |
|---|---|
| 选择题 | 小学、初中、高中单选都是四选一。干扰项各对应一个具体错误；选项按数值大小或逻辑顺序排列；不用"以上都对"；题干问"不正确的是"时要加着重号或用括号标明。新高考有多选题（每题 2–3 个正确选项），只在高中出 |
| 填空题 | 答案唯一，或者在题干里明确"写出一个即可"。范围类答案写清端点开闭；结果要求"化成最简""保留 π"等，要在题干里写明 |
| 解答题 | 写"请写出解答过程"；需要设未知数的要求"列方程（不等式、函数）解答"；分小问搭台阶 |
| 作图题 | 尺规作图要写"保留作图痕迹，不写作法"；网格作图要给出网格的规格 |
| 证明 / 说理题 | 明确已知和求证；说理题给出要判断的观点（"小明认为……你同意吗？说明理由"） |
| 新定义 / 阅读理解题 | 定义要完整、无歧义，并配一个示例；新定义只用本学段已有的知识就能理解 |
| 开放 / 探究题 | 写清任务要求；评分标准分层次（写出 1 种得几分，写出 2 种或给出一般规律得几分） |
| 综合与实践 / 长作业 | 小学、初中可用：测量、调查、制作、设计方案。写清任务、步骤、要提交的成果和评价要点。一般放在 C 层或作为单独的实践作业 |

### 3.1 最常见的"病题"（审卷时重点查）

- **图形位置不唯一**：没给图时，点可能在线段上，也可能在延长线上；等腰三角形没说哪条边是腰；圆中的弦可能在圆心同侧，也可能在异侧。要么在题干里给出图，要么把"分类讨论"当作考查点，并在答案里写全所有情况。
- **范围端点**：开区间还是闭区间，取不取到边界值；含参数题的端点要逐个代回检验。
- **定义域与实际意义**：函数应用题要写自变量的取值范围；人数、件数是整数；长度、时间是正数。
- **条件冗余或矛盾**：多给的条件和其他条件矛盾（比如三边长不满足三角形三边关系）；勾股数和角度不匹配。
- **近似与精度**：要求近似时写明"精确到 0.1"或"结果保留整数"；π 取不取近似值也要写明。
- **单位**：题中单位统一，或者明确要求换算。
- **选择题出现两个等价形式的正确选项**：比如 1/2 和 0.5，或 (x+1)² 和 x²+2x+1。

## 4. 用程序验算的套路（写 `check.code`）

`verify_items.py` 已经执行了 `from sympy import *`。下面是常用写法：

```python
# 解方程 / 方程组
x, y = symbols('x y'); ans = solve([Eq(2*x+y, 7), Eq(x-y, -1)], [x, y])   # expect "{x: 2, y: 3}"
# 解不等式，给出区间
ans = solve_univariate_inequality(3*x - 5 <= 7, x, relational=False)    # expect "Interval(-oo, 4)"
# 整数解 / 方案数：直接枚举
ans = [n for n in range(0, 50) if 8*n + 5*(20-n) <= 136][-1]
# 函数最值（含定义域）
f = -x**2 + 4*x + 5; crit = solve(diff(f, x), x); ans = f.subs(x, crit[0])
# 闭区间上的最值：端点和驻点一起比较
cands = [f.subs(x, v) for v in [0, 3] + [c for c in crit if 0 <= c <= 3]]; ans = max(cands)
# 几何：用坐标算
A, B, C = Point(0, 0), Point(4, 0), Point(1, 3); ans = Triangle(A, B, C).area
# 勾股、距离
ans = sqrt(3**2 + 4**2)
# 概率：枚举样本空间
from itertools import product
S = list(product(range(1, 7), repeat=2)); ans = Rational(sum(1 for a, b in S if a + b == 7), len(S))
# 统计量
data = [86, 90, 78, 90, 95]; ans = [Rational(sum(data), len(data)), sorted(data)[2]]   # 平均数、中位数
# 选择题：算出正确值，再匹配选项
val = solve(Eq(3*x+2, 11), x)[0]; opts = {'A': 1, 'B': 3, 'C': 9, 'D': Rational(13,3)}
ans = [k for k, v in opts.items() if v == val][0]                        # expect "'B'"
```

更多要点：
- **一个题有多个小问时，`ans` 写成列表**，`expect` 也写成列表，顺序与小问一致。
- **几何证明题**不能完全靠程序。可以用坐标验证结论在一个具体图形上成立，比如两线段相等、角相等、三点共线，`method` 写 `both`，并在 `blind_answer` 里写证明思路要点。
- **找规律题**要验证规律对给出的前几项都成立，并用程序算出所问的那一项。

## 5. 数学表述与排版

- **小学和初中**用 Unicode 数学符号：x²、√2、≤、≥、≠、π、∠、△、⊙、∥、⊥、≌、∽、°、÷、×。分数写成 3/4 或"四分之三"；带分数写成"2又1/3"。这样老师复制到 Word 里不会乱码。
- **高中**的复杂式子可以用 LaTeX，写在 `$...$` 里，比如 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$。简单的式子仍然用 Unicode。
- **图形要画出来**：几何题、函数图象题、立体图形题写 `figure_spec`（见 `references/figures.md`），脚本会按坐标精确画图。先定坐标，图、题干和 `check.code` 用同一组坐标。同时在 `figure` 字段里用文字完整描述：顶点、已知长度和角度的位置、哪些点在哪条线上、网格规格；能给坐标时尽量给坐标。描述只交代"图上有什么"，不能替学生推出结论。
- 术语要和教材一致：小学用"长方形"，初中用"矩形"；小学用"倍""份"，初中用"比"和"比例"；不提前使用未学的术语。

## 6. 数学分层要点

| 层 | 数学里的典型样子 | 支架怎么给（只用于 A 层前两题） |
|---|---|---|
| A 基础巩固 | 本课通性通法的标准题；概念辨析（判断、选择）；找错订正；最基础的应用题（一步建模） | 提示第一步该做什么（"先设……，写出……"）；给一个图示框架（线段图、表格、数轴）；把大问拆成小问 |
| B 能力提升 | 逆用、条件转化（表格、图像、文字）、两个知识点结合、分类讨论入门、方案比较、需要说理的应用题 | 不给支架 |
| C 拓展挑战 | 一般化（具体数变为字母）、构造（举例、反例、编题）、新定义或阅读理解、综合情境建模、为后续知识铺垫的探究、压轴题的前两问 | 不给支架；可以分小问搭台阶 |

**基础层的支架指向前置知识。**比如学生列不出不等式，支架是"先像列方程那样找出相等关系，再看题目里的'不超过'应该换成哪个符号"，指向七上列方程的经验。**不要用"关键词策略"当支架**（如"看到'一共'就用加法""'不超过'就是 ≤"）：它绕过理解，换个说法学生就不会了。

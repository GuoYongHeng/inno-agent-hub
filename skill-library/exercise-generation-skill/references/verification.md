# 试做与审卷（verification）

**这份文件要等 `homework.json` 写完、学生版已经渲染出来之后再读。**写题时不要提前看。理由是：题写到一半时，你心里清楚自己"想要"的答案，一道有两个正确答案的题在你眼里也会显得没问题。所以下面的门禁要求你**把成品当文本读回来**、**把结论写下来**、**在成品存在之后再做**。

这对应上海 2025 年作业管理要求里的"布置前要完整试做"，也是老师最在意的一点：**答案不能错**。老师批到一道错题，对整个工具的信任就没了。

---

## 门禁 0：机器检查

```bash
python3 scripts/verify_items.py output/homework.json --write   # 计算题独立验算
python3 scripts/check_homework.py output/homework.json          # 结构、阶梯、时长、选项
```

两个脚本都要跑到 0 个 ERROR。WARN 逐条看，能改就改。

`check.code` 的写法：**只用题干给出的条件**，从头再算一遍，不要把答案直接抄进去。

```python
# 好：从题干条件出发重新算
x = symbols('x')
yA = 10 + 2*x            # 方案甲：月租10元，每分钟2元（题干）
yB = 3*x                 # 方案乙：每分钟3元（题干）
ans = solve(Eq(yA, yB), x)[0]
# 不好：ans = 10   （直接把答案抄进去，等于没验）
```

对选择题，代码应该算出正确值，再判断它对应哪个选项。例如 `ans = 'B'`，同时 `expect="'B'"`。代码里也可以把每个干扰项按其错因算一遍，验证门禁 C。

## 门禁 A：独立试做

1. 读回 `output/学生版.md`（学生自学时是 `output/练习.md`），**只看这一份**，不看答案和解析。
2. 逐题从零做一遍，把你的答案写进草稿文件 `work/trial.md`（写在 output 以外）。
3. 和 `homework.json` 里的 `answer` 逐题对照：
   - 一致：通过。
   - 不一致：先弄清是题错、答案错还是你试做时做错了。题目表述能让人做出另一个合理答案的，就是题有问题。
4. 如果环境能派子代理（subagent），把**学生版**交给一个不了解上下文的子代理去做，让它报告每道题所有站得住的答案。它不知道你"想要"哪个答案，更容易发现歧义。

非计算题（概念判断、说理、阅读、开放题）的 `check.method` 写 `blind`，写入 `check.blind_answer`（试做时得到的答案要点）和 `check.status`。

## 门禁 B：答案唯一，条件恰好

逐题回答下面的问题，结论写进草稿：

- **条件够不够？** 不加任何额外假设，能确定唯一答案吗？常见漏洞包括："f(x) 在区间 D 上单调"被当成"f(x) 的定义域是 D"；物理题没说"水未溢出""不计绳重和摩擦"；英语时态题句中没有时间标志或语境，几种时态都说得通；没说"整数"或"正整数"；没说"车必须坐满"或"可以不坐满"；没说取值范围、定义域；没说是"至少""至多"还是"恰好"；没说精确到哪一位；单位没统一；图上的信息文字里没给。
- **条件矛盾吗？** 比如数据前后不一致，或者解出来是负数、小数个人数。
- **选择题：每个选项各写一行"它是正确答案的最强理由"**，只能依据题干和图，然后数一数站得住的有几个：
  - 恰好 1 个：通过。
  - 2 个及以上：在题干里点明关键条件；不行就删掉这个选项。
  - 0 个：答案本身错了，或者图示信息没有用文字交代。
  - 四个常见的"第二正确答案"来源：等价形式同时出现（1/2 和 0.5）；结论对但理由错的选项；精度、单位没说清；"以上都对"类选项。
- **开放题**：评分标准是否列出了可接受答案的类型和得分点？

## 门禁 C：干扰项和错因真的"到得了"

先用代码或手算求出题干里的**实际数量**，比如差、比、交点、总数，再把每个干扰项所标的错因套到这些数上，看是否确实落在那个选项：
- 落在该选项：通过。
- 落在别的选项，或者这个错因在本题里根本用不上：说明干扰项没有学生会选。换一个本题能产生的错因，重写这个选项。

## 门禁 D：审卷清单（出卷人视角）

逐条过，有问题就改：

- [ ] **不超纲**：每道题用到的知识都在本课时及之前的内容里。C 层用了后续内容的，教师版要标"选学"。
- [ ] **课时目标覆盖**：三层都在练同一个目标；重点、难点都有题落实。
- [ ] **阶梯真实**：把每道 B、C 层题和它的 `upgrade.from` 原题放在一起比，确认新增的是思考，不只是数字变大或步骤变长。只换了数的，要么降到 A 层做平行题，要么重新改编。
- [ ] **画像与解析一致**：`profile.s` 和解析步数对得上；标了 `c=2` 的题确实有隐含条件。
- [ ] **难度系数单调**：预估难度系数 A 层约 0.85–0.95，B 层约 0.65–0.80，C 层约 0.40–0.60。层内由易到难。
- [ ] **情境四测**（用了情境的题）：删除、反问、数据、改写风险，见 `situation.md`。
- [ ] **表述规范**：用语准确，符合本学段的术语；否定词要加着重号（"不正确的是"）；单位和符号统一；图文一致。
- [ ] **不套路化**：同一层里同构题最多 2 道；整份作业不是一套题型重复几遍。
- [ ] **学生版干净**：没有答案、解析、"层级""支架""错因"这类设计术语，也没有给学生贴的标签。
- [ ] **时长合理**：前两层不超预算。
- [ ] **教师版也对**：解析每一步、易错表、讲评建议、检验方法，逐句核对学科上是否正确。常见翻车：给学生的"检验口诀"本身是错的，比如"两个分数的和在两个加数之间"；原创材料内部前后矛盾，比如分类、编号、顺序对不上。
- [ ] **前后一致**：同一份作业里共用的数据（班级数、人数、价格、距离）前后一致；原创阅读材料里的事实、分类、数字自洽。
- [ ] **图与题一致**：有 `figure_spec` 的题，图上的点、长度标注、直角、等长标记和题干条件一致；图上没有标出要学生求的量，也没有画需要学生自己添的辅助线。
- [ ] **不互相泄露**：提示、图形描述、前一题题干没有透露后面题的答案；图形描述没有写出题目要问的性质。
- [ ] **课标转述有据**：`curriculum_refs` 和教师版里提到课标的地方，都只是概括。没有出现"课标必做实验""课标原文规定"这类说法，除非参考文件原文写了。
- [ ] **干扰项都有人会选**：没有一眼就能排除的荒谬选项，每个干扰项都能说出"哪类学生、因为什么想法"会选它。

## 修复之后

改完重新渲染、重新跑门禁 0 到 D 里受影响的部分。修一道题的题干，可能会弄坏原本没问题的选项。**同一道题修了两次还不过，就换一道题，不要第三次打补丁。**

**自检记录只写你真正核对过的事实**，每个数字都要与题目和解析一致。比如写"第 9 题恰为临界"之前，先把那个数算一遍。

所有门禁都通过后，才能把每道题的 `check.status` 设为 `"pass"` 并交付。试做和审卷的过程**不要讲给用户听**。教师版末尾的"自检记录"只写结论，比如"全部 12 题已独立试做并验算；第 7 题原表述有两解，已补充条件"。

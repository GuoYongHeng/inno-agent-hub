# 04 排版与标点规范

> 用途：审稿 Step 3 检查通病六、Step 6 修改时引用。分两大部分：公文/正式文稿规范、新媒体排版规范。

## 一、公文与正式文稿

### 1. 标点基本规范

- **顿号**：并列的词或短语之间用顿号（"北京、上海、广州"）；并列的短语较长或内部已有顿号时改用逗号。**常见错误**：动词并列滥用顿号（"调查、研究、解决了问题"应为逗号或分号）
- **逗号/句号**：一句话未完用逗号，完成用句号。**一逗到底**是最高频硬伤——检查每个逗号处能否换句号
- **分号**：多重复句内并列分句之间用分号，尤其在列举条目之间
- **冒号**：提起下文时用（"会议指出："）
- **引号**：先双后单，外层双引号内层单引号；引号内末句号放引号内，独立引文如此；引号内容若是句子成分，句号放引号外
- **书名号**：书名、报刊名、文件名、法规名、栏目标题用书名号（《条例》〈通知〉《公众号栏目名》）；**常见错误**：把标题、主题词、课程名误加书名号
- **数字用法**：公文正文一般用汉字（"五个一""三严三实"），具体数据用阿拉伯数字（"截至 8 月 11 日，共 128 人"）；时间"8月11日"与"八月十一日"全篇统一
- **破折号/省略号**：占两格，一字线/省略号各占两字；不可用三个句点或下划线代替

### 2. 段落与层级

- **段落**：一个自然段只表达一个中心意思；段首缩进两字符（空两格），全篇统一
- **层级序号**（公文标准）：一、 → （一） → 1. → （1）。**不得跳级**（"一、"直接接"1."）；同一层级同级别并列项内容分量应相当
- **标题**：标题层级字型一致（一级标题黑体、二级楷体、三级仿宋加粗，视单位规范而定），同级标题格式必须统一
- **落款**：发文机关 + 日期右对齐，全角日期，发文机关名称完整

### 3. 版面

- 正文一般用仿宋三号、行距适中（约 28-30 磅），视单位规范
- 标题居中、副标题之下不空行过多；文末标注来源/报送单位

## 二、新媒体文案（微信推文 / 小红书）

### 微信推文

- **段落**：手机阅读每段 2-3 行为宜，超过 5 行必拆；段间空一行
- **小标题**：多用小标题切分长文，小标题要有信息量（不是"第一部分""第二部分"）
- **强调**：用加粗代替全篇感叹号；金句单独成行
- **标点**：全角中文标点；情绪表达适度用感叹号，不叠用（"！！！"禁止）；省略号最多一组"……"
- **视觉**：注明配图位置（【图 1】）；封面、引导关注语、赞赏位等平台元素不遗漏

### 小红书文案

- **排版**：短句一行一段，多用换行制造呼吸感；emoji 适度（每条 3-5 个以内），不堆砌
- **编号**：干货清单用"① ② ③"或"1. 2. 3."分行列出
- **标签**：末尾话题标签 3-5 个，覆盖场景词 + 人群词 + 品类词
- **开头**：前 3 行必须抓住人（痛点/悬念/反差），平台按停留时长分发流量

## 三、通用检查清单（快速过一遍）

- [ ] 全文有无一逗到底段落（连续 3 个逗号以上无句号）
- [ ] 顿号/逗号/分号层级是否混乱
- [ ] 段落是否该拆未拆、该合未合（一句话成段 3 处以上也要警惕碎片化）
- [ ] 层级序号是否跳级、同级格式是否统一
- [ ] 数字、时间写法是否全篇统一
- [ ] 是否有残留的 Markdown 标记（联动通病五）
- [ ] 标题/落款/署名是否完整

# 03 AI 痕迹人工核对清单

> 用途：审稿 Step 3 中，`scripts/ai_trace_scan.py` 机器快筛之后，用本清单做人工定性。核心原则：**单信号不定罪，多信号 + 整体判断才定性**。宁可标"疑似"提示作者自查，不轻易下"照搬"结论。

## 一、格式残留类（高置信信号）

命中以下任意一项，基本可判定为未处理的 AI 直接输出：

- [ ] 正文中出现 Markdown 语法标记：`**加粗**`、`*斜体*`、`##`/`###` 标题、`- ` 无序列表、`1.` 有序列表、`| 列 |` 表格、`>` 引用、`` `代码` ``、`---` 分隔线
- [ ] 出现 AI 常见的"输出结构"残留：开头"以下是……的内容"、"好的，我来为您撰写"
- [ ] 英文冒号后接中文、半角标点混用等工具生成特征

## 二、高频词与套话类（中置信信号，需叠加）

- [ ] 逻辑口头禅："值得注意的是""需要注意的是""总的来说""综上所述""总而言之""由此可见""换句话说""不难发现""众所周知""不可否认""毋庸置疑"
- [ ] 时代腔模板："在当今……的时代""随着……的不断发展""在……的大背景下""当今社会"
- [ ] 职场黑话堆砌："赋能""抓手""闭环""颗粒度""落地""维度""矩阵""痛点""底层逻辑""方法论""组合拳""精细化运营"
- [ ] 空洞升级词："大幅提升""显著增强""极大促进""具有重要意义""产生深远影响""开创了新局面"
- [ ] 结尾万能句："让我们携手共进""共同谱写新的篇章""展望未来，我们信心满怀""不忘初心，砥砺前行"

## 三、结构套路类（中置信信号，需叠加）

- [ ] 段落模式高度雷同：每段均为"观点句 → 解释句 → 总结句"三段式
- [ ] 全篇并列结构工整到不自然：每个小节字数接近、句式对称，像按模板生成
- [ ] 小标题模板化："一、背景""二、现状""三、问题""四、建议"，但各节内容互相没有推进
- [ ] 有骨架没血肉：结构完整但缺少具体人名、时间、数字、细节，全篇"正确但空"

## 四、内容缺陷类（辅助信号）

- [ ] 全文无一处具体数据、无出处、无细节场景，全是抽象概括
- [ ] 对同一件事反复用同义句描述（凑字数特征）
- [ ] 观点正确到没有立场：任何角度挑不出错，也记不住说了什么

## 五、定性规则

| 信号组合 | 定性 | 报告表述 |
|---|---|---|
| 命中格式残留 1 处 | 高概率照搬 | "存在未处理的 AI 生成格式残留，疑似直接照搬，建议作者重写并自查" |
| 无残留，但高频词 ≥ 5 类 + 结构套路 ≥ 2 项 | 疑似 AI 辅助 | "文本呈现明显 AI 生成特征（套话集中、结构套路化），建议融入个人表述" |
| 仅高频词 1-2 处 | 不作定性 | "个别表述偏模板化，可替换为更自然的说法" |
| 内容空洞但无其他信号 | 提示信息密度 | 归入通病七（空话泛滥）处理，不涉及 AI 判定 |

## 六、修改建议模板（按需套用）

- 清除格式：删除全部 Markdown 标记，按文种规范重排（参考 `04-format-rules.md`）
- 去套话：逐句问"这句话在讲事实还是讲场面话"，场面话删；参考 `06-rewrite-examples.md`
- 补血肉：为每个抽象论断补一个具体例子、一组真实数字、一个可核对的事实
- 改句式：破坏模板腔——长短句交错、加口语过渡、加入作者视角的个性化表达
- 提示作者：说明"不是不能用 AI，而是要用 AI 出素材、自己出观点和语言"

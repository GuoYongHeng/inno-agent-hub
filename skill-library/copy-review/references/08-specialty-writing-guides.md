# 08 专项写作规范（新闻稿 / 活动预告 / 结果公示 / 主持词）

> 用途：当文稿属于以下四类时，审稿 Step 1「定场合」除对照 `01-scene-matrix.md` 外，**必须同时加载本文件对应章节**，作为专项检查标尺；Step 3 诊断时逐条核对。本文件为写作规范与审稿标准合一：写作时按此写，审稿时按此查。

---

## 一、新闻稿（消息稿）

### 1.1 结构：倒金字塔

- **定义**：按新闻事实的重要性程度或受众关心程度**依次递减**的次序安排材料。最重要的信息放最前面，其余事实按其重要性依次写下去，形如倒置的金字塔/三角形
- **组成**：标题 → 导语 → 主体 → 结尾（可选）→ 补充信息（可选）
  - 标题：概括核心事实，一眼看懂
  - 导语：浓缩最重要信息，通常一段
  - 主体：按重要性递减展开细节
  - 结尾：收束（可选，非必需）
  - 补充信息：背景、数据、人物简介等（可选）
- **检验方法**：读者只看标题和前两段，能否获知"发生了什么"；砍掉后半部分，核心信息是否依然完整。两者都成立，才是合格的倒金字塔
- **审稿检查点**：
  - 最重要的事实是否在导语？（通病：背景铺垫占导语、核心事件放到第三段）
  - 导语是否完整交代何人、何时、何地、何事（按需加何因、如何）？
  - 各段是否按重要性递减，而非按时间流水顺序？
  - 结尾和补充信息是否可整体删除而不损核心？

### 1.2 导语提名规则（校园新闻场景）

> 原则：导语只提**与本次活动直接相关、具有标志性意义**的人物；一般参加人员放正文或结尾提名。

- **规则 A（学校首页平台发布的重要新闻）**：导语可提名——院士级别；正厅级及以上领导；校领导和校区领导正职；承担重要角色的人物
- **规则 B（校园动态等栏目、各单位自有平台）**：导语可提名——院级领导或处级干部
- **规则 C（仅参会，无致辞/讲话/颁奖等具体活动）**：导语**不提名个人**，代之以范围概括，如"学生代表""各学院师生代表"等
- **其他参加人员**：一律放正文或结尾提名
- **审稿检查点**：
  - 提名级别是否与发布平台/栏目层级匹配（学校首页重要新闻提了处长？校园动态提了院士？均属错位）
  - 导语中是否出现仅参会、未承担具体活动的人名
  - 平台层级判断不清时，标记"待确认发布平台"，不臆断

### 1.3 领导排序规则

- **总原则**：党内职务优先、行政职级次之；级别从高到低；党务在前、行政在后；同级别党务优先。整体上**党口在前，学院在后，最后是班主任、辅导员等**
- **学院新闻典型顺序（从高到低）**：
  1. 学院党委书记
  2. 院长
  3. 党委副书记
  4. 专职党务人员（如组织员）
  5. 副院长（主持工作）
  6. 副院长
  7. 院长助理
  8. 系所党支部书记
  9. 兼职党务人员
  10. 专业教师
  11. 辅导员
  12. 班主任
  13. 教务员
  14. 学生代表
- **人数过多时的简写**：可简写为"学院党政领导、师生代表"等
- **审稿检查点**：
  - 并列提名的人名是否按上述顺序排列（最常见的错：把院长排到党委书记前面、把辅导员排到副院长前面）
  - 是否遵循"党务在前、行政在后"（如院长助理与系所党支部书记并列时）
  - 简写是否在确实人数过多时才使用

### 1.4 人名与职务称法

- 开头介绍职务后，**后文直呼其名即可**，不必反复带职务（"党委书记王××指出……王××强调……"重复职务显笨拙）
- **人名绝不能写错**——错字是新闻稿硬伤，审稿时必须逐一核对
- **同一人名段内出现次数不宜过多**："×××指出"之后可替换为"他明确了……""他表示……"等，防止文本单调
- **审稿检查点**：
  - 职务只在首次出现时全称，后文是否直呼姓名
  - 人名是否有错别字/同音字混用（如"莉/丽""峰/锋"）
  - 同一人名密集出现处是否可换表述

### 1.5 语言要求

- **先求晓畅，再求文采**；语言首先让人读得顺、读得懂
- 不提倡文绉绉的语言；滥用文言、生僻词反而伤害新闻的可读性
- **审稿检查点**：是否存在"为文采而文采"的句子——读三遍还不顺口的，一律建议改平实

### 1.6 会议新闻特别规则

- **意义部分的取舍**：若意义部分是"一看就是官样文章"、无实际意义、不能为后续工作奠基，**直接删除**；召开就是召开
- **写意义的门槛**：必须已有实际成果、实际数据产生效应，才能**用实际事例**来写意义——空谈意义不如不写
- **总方针**：会议新闻**重在陈述事实**（谁参加、议了什么、定了什么、做了什么），少提或干脆不提意义
- **审稿检查点**：
  - 意义段落是否有具体成果/数据支撑；没有则建议整体删除
  - "进一步推动了""奠定了坚实基础"等空转表述是否可删
  - 事实部分是否完整（时间、地点、参会范围、议定事项、下一步安排）

### 1.7 会议与活动新闻实务要点

> 本节约定来自校园新闻改稿实战经验，适用于会议、典礼、培训、颁奖等活动类新闻的采写与审校。

**写作准备（写前就要做，不是写后补救）**
- **提前要到活动流程和人员名单**：大型会议/活动，流程单与名单是新闻稿的骨架，现场边听边记
- **现场录音**：会议类活动（致辞、汇报、发言多）全程录音，会后转文字，挑关键点按逻辑组织——比凭记忆写准得多
- **信息不全要主动补查**：现场没记全的内容，查往届推文、学院/单位公布的信息，或直接询问相关人员；不允许"不知道就略过"
- **审稿检查点**：事实细节（流程、名单、发言要点）是否有明显缺口；稿面信息能否追溯到现场或可靠来源

**开头要素（导语四件套）**
- 固定交代：**什么时间、什么会/活动、什么地点、谁主持、谁参会**；参会领导单独列出（见 1.2 提名规则）
- 时间格式统一；年份视平台惯例（年度内同一平台可不重复带年份，全文统一即可）
- **审稿检查点**：四件套是否齐全；主持人与参会人是否区分清楚；有没有成分残缺（如"××主持"缺主语，应为"会议由××主持"）

**名单与排序**
- **人多的场合**：先突出学校和外部机构，学院领导老师放在最后面
- **媒体代表**：统一放在所有嘉宾之后，表述为"××、××等媒体代表"
- **人数过多可简写**：如"学院领导班子成员、系所负责人、班主任、辅导员、本研教务秘书等"
- **排序逻辑**：政治属性在前（党—团—学生组织）；嘉宾按级别从高到低；部门按组织架构顺序，不照搬现场发言顺序
- **审稿检查点**：名单是否臃肿、顺序是否错乱、媒体是否单列于嘉宾后、简写是否得当

**主体顺序**
- **领导/嘉宾发言在前**，各部门（组织）汇报在后
- 部门汇报**按组织逻辑排序**（如"党支部—团委—双创—权益—研究生会—学生会—青志协"这类架构顺序），现场发言顺序打乱时，稿内仍按架构排
- **部门介绍框架**：先提活动或工作 → 再提创新点或成绩 → 最后提不足（没提不足的可以不写）
- **审稿检查点**：领导发言是否前置；部门顺序是否按架构而非现场顺序；每个部门的介绍是否"工作+成绩+（不足）"结构完整

**结尾**
- 活动/会议新闻**结尾写意义**；培训、教育类活动要**体现培训主题**（本次活动的定位是培训的一环）
- **不硬拔高**：意义要落在已发生的实事上，可适当比照同类论述，但严禁凭空升华
- 活动新闻的**背景介绍和意义放最后面**（倒金字塔落点），不放开头
- **审稿检查点**：结尾是否有意义段；培训类是否点出培训主题；背景/意义是否误放开头

**照片与补充信息**
- 遵守单位照片规范（如"领导单人照不发布"类要求）；拿不准的照片先问
- 发布后视需要附**媒体报道链接**作为补充信息（哪些媒体做了报道，可单列）
- **审稿检查点**：配图是否符合单位规范；媒体报到类补充信息是否成体系（媒体名+标题+链接）

### 1.8 语言与表述高频问题（改稿实战高频）

- **口语转书面语**：交稿前通读一遍，凡是有卡壳的地方，检查是不是该改（卡壳往往是口语或病句的信号）
- **句式多样化，防流水账**：多段同句式开头（如每段"×××代表介绍……"）会让全文像流水账；开头要变换说法，语序灵活
- **无主语句要补主语**："接下来是××的致辞""××主持"这类无主语句，改为主动句式（"××指出""会议由××主持"）
- **职务称谓准确完整**：能称"部长/副部长"的不称"负责人"；特殊职务要写全（如"副院长（主持工作）"）；机构、栏目全称要准确（如"××工作室"不能写错）；首次出现全称、后文直呼其名
- **删过誉表述**：对嘉宾、合作单位不作过度吹捧（"××作为领域领军者"类），陈述实际作用即可（联动 `09-tone-and-caliber-review.md` 口径审查）
- **动词搭配规范**：注意固定搭配（如"向××授权"而非"将××授权给××"）
- **段落聚焦**：一段一个主题——荣誉集中写、作品/项目介绍点到意义即可，不过度展开细节
- **标志/品牌类介绍**：发布 logo、标识等内容时，简要说明其内容和理念
- **审稿检查点**：逐段检查以上各项；通读一遍全文，标记所有"读起来卡壳"的句子

## 二、活动预告微信文章

### 2.1 定位

- 一篇活动预告要做两件事：**交代活动的基本信息** + **有足够的趣味性吸引人参加**
- 它是"预告"不是"通知"——读者是被吸引来的，不是被通知来的

### 2.2 结构

1. **标题**：写得吸引人一点（悬念、数字、利益点、反差）
2. **开头（导入）**：引人入胜——从场景、痛点、悬念切入，3 行内抓住读者
3. **主体（主要内容）**：活动的主题、时间、地点、相关提示
4. **结尾**：用有趣味性的话号召大家参加（呼应开头或主题，不用干巴巴的"欢迎大家踊跃报名"）

### 2.3 征稿 / 比赛类预告必须写明的要素

- 征稿类型（体裁、主题、篇幅要求）
- 比赛方式（赛制、流程）
- 截稿日期（具体到日期甚至时间点）
- 参与方式（报名入口/投稿渠道/联系方式——**必须可操作**，读者看完知道"怎么参加"）
- 奖次与奖品（奖项设置、奖品说明）
- **特别注明**：稿件需经过**原创性校验**和 **AIGC 校验**

### 2.4 禁忌（红线）

- **严禁直接搬运通知**——把红头通知原文贴到公众号即为失职写法
- **严禁长篇大论意义**——预告是"来玩"，不是"受教育"；意义只留一句吸引人的话，或不写
- **拿不准的事情严禁打包票**——如"保证获奖""必有大奖""名额充足"等，没把握的承诺一个都不能写
- **尽量不用网图**（版权风险）；确有必要时注明"图片来源于网络"

### 2.5 审稿检查点

- 关键信息是否齐全：主题、时间、地点、参与方式、截稿/报名截止（征稿比赛类逐项对照 2.3）
- 是否注明原创性校验与 AIGC 校验（征稿/比赛类必查项）
- 是否像"通知搬运"（公文腔、逐条照抄）
- 结尾是否有吸引力的号召
- 有无打包票表述；图片来源是否标注

## 三、比赛结果公示与发奖微信文章

### 3.1 定位

- 结果公示**不同于活动新闻稿**——它不追求"报道感"，核心是把结果说清楚、让参与者知道自己有没有得奖、怎么领奖
- 结构比文采重要

### 3.2 结构（四步）

1. **参与情况简要回顾**：一句话或一小段（多少人参与、什么规模），为榜单做铺垫
2. **公布榜单**：奖项名称 → 获奖名单（名次/奖项 + 姓名/队伍；名单长则用清单式排版，勿堆大段）
3. **公布奖品和领奖方式**：奖品是什么；领奖时间、地点/方式（现场领/邮寄/联系谁）——**必须具体可操作**
4. **结尾**：感谢大家参与

### 3.3 禁忌

- **尽量不用网图**（版权风险）；确有必要时注明"图片来源于网络"

### 3.4 审稿检查点

- 榜单是否与评审结果一致（人名、奖项、名次逐项核对——公示文错一个名字都尴尬）
- 领奖方式是否完整（时间、地点、联系人/渠道）
- 是否遗漏参与情况回顾或感谢语（结构四步是否齐全）
- 图片来源是否标注

## 四、主持词

### 4.1 写作前准备

- 先确定：**主持人人数、男女主持比例、活动主题和类型**
- 人数与比例决定分工（见 4.2），主题类型决定报幕内容与语气

### 4.2 结构分工

- **开头与结尾：主持人全上**（开场共同亮相、结尾共同谢幕/致谢）
- **中间报幕：一男一女**交替（按节目/环节轮换，避免单人连续报多个节目）

### 4.3 报幕要求

- 报幕内容与**活动主题、节目内容相贴合**——每个节目报幕至少提到该节目/环节本身，忌一套通用串词套所有节目
- 用词符合**主持者身份**（学生活动、教师活动、嘉宾主持，语气各自相称；主持词是"替主持人说话"，不是"作者自己的话"）

### 4.4 语言硬性要求

- **生僻字、多音字、异读字、外文单词必须注音**——主持词要现场念，念错即事故。注音方式：直接在字后加括号注拼音或同音字，如"参差（cēn cī）不齐""××（英文原词）"
- **尽量不提及敏感内容**（性别议题、阶层议题、地域议题等）；**必须提及的适当淡化**——例如不得不涉及年龄、籍贯等元素时，用中性、概括的表述，不带评价

### 4.5 审稿检查点

- 开头、结尾是否主持人全上；中间是否男女交替报幕
- 每段报幕是否对应具体节目/环节（抽查：去掉节目名，串词还通用吗——通用即不合格）
- 生僻字/多音字/异读字/外文单词是否全部注音
- 有无敏感内容表述；必须提及的是否已淡化处理
- 主持词是"口头发言"——通读一遍，判断是否念得顺、像人话（书面腔过重的段落标记修改）

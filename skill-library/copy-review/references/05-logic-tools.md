# 05 逻辑审查工具箱

> 用途：审稿 Step 3 检查通病二、Step 6 给出逻辑重构建议时使用。

## 一、句间逻辑四问

对任意相邻两句，追问一句：

1. **顺序对吗**？先发生的先说、先因后果、先总后分——顺序颠倒即为逻辑错误
2. **关系标出来了吗**？两句是并列、递进、因果还是转折？没有连接词时，读者能否自行推出这层关系；推不出则要补连接词
3. **主语跳了吗**？两句主语悄悄更换（前句"我们"，后句变成"他们"）会制造混乱
4. **删掉后影响理解吗**？某句删掉后上下文依然连贯，说明它是赘余或与主线无关

## 二、段间衔接三招

1. **过渡句**：段落开头用一句话承接上段（"在上述基础上""与成绩并存的是"）
2. **逻辑连接词**：并列（"同时""此外"）、递进（"进一步""更关键的是"）、转折（"然而""但值得注意的是"）、因果（"由此""因此"）、总结（"综上"）
3. **话题推进**：下一段应是上一段的"自然下一步"——要么展开、要么转折、要么收束，不能横跳。横跳时补一句"为什么接下来讲这个"

## 三、论证闭合检查（观点-论据-论证）

对每个观点，三步验证：

1. **观点是什么**：找论点句（通常在段首或段尾）
2. **论据够不够**：支撑论点的例子/数据/事实是否真实、是否相关——举的例子与论点无关即为"观点论据脱节"
3. **论证通不通**：从论据能否推出论点。常见漏洞：举例只举了"同样结论"的个例（以偏概全）；用"专家说"代替论证（诉诸权威）

## 四、常见逻辑谬误对照表

| 谬误 | 特征 | 示例（病句） | 修改方向 |
|---|---|---|---|
| 强加因果 | 两事时间先后即当作因果 | "因为加强了宣传，所以业绩下滑" | 补全中介环节或改为并列 |
| 因果倒置 | 把结果当原因 | "因为大家更努力，所以制度更严了" | 理清真正的因果方向 |
| 以偏概全 | 个例推全体 | "几位同学反映，可见大家都反对" | 改为"部分同学"，或补全量证 |
| 偷换概念 | 论述中悄悄换词 | "要狠抓质量，所以必须多开会" | 明确概念边界，回归本意 |
| 循环论证 | 用结论证明结论 | "他值得信任，因为他是可信的人" | 换独立论据 |
| 诉诸权威 | 以"权威/领导说"代替论证 | "专家认为可行，所以一定可行" | 说明具体理由与数据 |
| 滑坡谬误 | 无限夸大后果 | "今天不管，明天就乱套" | 只论证直接后果 |
| 非黑即白 | 只有两极，无中间态 | "要么全面开放，要么彻底关停" | 补充中间方案 |

## 五、重构操作法（给作者的改稿步骤）

1. **先列大纲**：把全文每段用一句话概括，贴在文档开头，看全文结构图
2. **画逻辑线**：用箭头把大纲串起来（A → B → C 还是 A/B/C 并列？），箭头断在哪，逻辑就断在哪
3. **动手术再美容**：先删冗余段、调乱序段、补过渡句；结构理顺后再改词句——顺序反了等于白改
4. **一句话测试**：改完后用一句话向别人讲清"这篇文章讲了什么"，讲不清则继续重构

## 六、审稿中的呈现方式

- 逻辑问题不要只报"逻辑不通"，要给出**可操作的修法**：具体哪两段换位、哪两句间补什么过渡、哪个论据换成什么
- 大结构问题（主线断裂、主题漂移）归入通病八处理，优先于局部逻辑问题（通病二）

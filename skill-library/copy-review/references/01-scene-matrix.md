# 01 文种-场合矩阵

> 用途：审稿 Step 1「定场合」时对照本矩阵，明确该文种的**结构骨架 / 语言风格 / 内涵底线**，再以之为标尺诊断全文。矩阵之外遇到新文种，按同样维度自行补充。**凡文种属于新闻稿、活动预告、结果公示、主持词四类，必须同时加载 `08-specialty-writing-guides.md` 对应章节**核对专项要求。

## 一、正式公文与职场文稿

### 1. 通知

- **适用场景**：布置工作、告知事项、发布安排，下行文为主
- **结构骨架**：标题（发文机关+事由+文种）→ 主送单位 → 正文（缘由 → 事项 → 要求）→ 落款（发文机关、日期）
- **语言风格**：准确、简明、规范；动词主导（"请""须""严禁""请于 X 日前报送"）；禁用抒情与修辞
- **内涵底线**：事项必须清晰可执行（谁、做什么、何时、何地、做到什么程度）；时间地点人名不得含糊
- **常见翻车点**：事项笼统无操作细节；语气与受文对象不匹配（对下级命令式、对上级汇报式混用）；缺落款

### 2. 工作总结

- **适用场景**：对一段时期工作回顾，向上汇报或对内复盘
- **结构骨架**：概况（做了哪些事）→ 做法与成效（分条）→ 问题与不足 → 下一步打算
- **语言风格**：客观平实；成绩用数据与事实支撑；不足要具体不回避；全文一致用第一人称复数（"我们"）
- **内涵底线**：成绩与问题比例得当（报喜不报忧是通病）；数据必须真实可查
- **常见翻车点**：只堆成绩无问题；"虽然…但是"套话式转折；数据无出处；时间线混乱

### 3. 汇报材料

- **适用场景**：向上级口头或书面汇报某项工作/事件
- **结构骨架**：是什么（基本情况）→ 怎么做的（措施）→ 什么效果（成效/数据）→ 有什么困难 → 需要什么支持
- **语言风格**：言简意赅、层次分明；上级关心的先说；多用短句、少用长句嵌套
- **内涵底线**：结论在前、论据在后（先给结论再展开）；对成绩不夸大、对问题不遮掩
- **常见翻车点**：开头铺垫过长；流水账无重点；困难提得太实（变成诉苦）或太虚（说了等于没说）

### 4. 工作方案

- **适用场景**：就某项任务给出实施安排，供审批或执行
- **结构骨架**：背景与目标 → 组织领导（责任分工）→ 实施步骤（阶段/时间节点）→ 保障措施 → 预期效果
- **语言风格**：条理化、可操作；多用序号分层（一、（一）1.）；动词明确（"成立""制定""开展"）
- **内涵底线**：目标可量化；责任落到人；时间节点明确；前后步骤逻辑自洽
- **常见翻车点**：只有口号没有步骤；分工模糊（"相关部门""有关人员"）；时间节点缺失或矛盾

### 5. 宣传稿 / 新闻稿（消息稿）

- **适用场景**：对内对外报道活动、成果、人物，媒体或自有平台发布
- **结构骨架**：**倒金字塔**——标题 → 导语（何人何时何地何事，直给核心）→ 主体（细节按重要性递减展开）→ 结尾（可选）→ 补充信息（可选）
- **语言风格**：客观为主，可适度生动；引语真实；标题抓人但不夸大；**先求晓畅，再求文采**
- **内涵底线**：事实准确（人名、职务、数据、时间一个都不能错）；导向正确；不用绝对化用语（"最好""最大""唯一"需有依据）；会议新闻重在陈述事实，无成果支撑的意义段落应删除
- **常见翻车点**：导语拖沓、核心事件被背景挤到后段；以感想代替事实；夸张拔高（"重大突破"配普通小事）；引语编造；领导排序错乱、导语提名越级
- **专项细则**：导语提名规则（校园新闻分级）、领导排序规则、会议新闻意义取舍——见 `08-specialty-writing-guides.md` 第一章

### 6. 简报 / 信息

- **适用场景**：短平快通报工作动态，供领导快速掌握
- **结构骨架**：标题（概括核心）→ 一段式或两段式正文（最新动态+简要意义）→ 报送单位与日期
- **语言风格**：精炼，一般 300-800 字；只写事实和关键信息，不铺陈
- **内涵底线**：新（时效性）、实（事实性）、快（报送及时）；一稿一事
- **常见翻车点**：写成小总结（面面俱到）；加大量评价性语言；篇幅失控

### 7. 讲话稿

- **适用场景**：领导/代表在会议、仪式、活动上发言
- **结构骨架**：称谓（"同志们""各位来宾"）→ 开场（点题+背景）→ 主体（观点分条，层层递进）→ 结尾（号召/希望）
- **语言风格**：口语化书面语，可带排比、递进等修辞；语气与场合匹配（动员会激情、表彰会庄重、座谈会亲切）
- **内涵底线**：政治站位正确；观点有依据；篇幅与场合匹配（长篇大论念不完是硬伤）
- **常见翻车点**：书面腔太重念不顺口；套话连篇无观点；称呼场合写错；结尾口号与主体无关

### 8. 会议纪要

- **适用场景**：会议内容记录整理，作为执行依据存档
- **结构骨架**：会议要素（时间、地点、主持、参加、记录）→ 议定事项（分条：结论+责任人+时限）→ 落款
- **语言风格**：中性、客观，只记结论与行动项，不记争论过程细节
- **内涵底线**：忠实原意不添油加醋；"谁负责、何时完成"必须明确
- **常见翻车点**：写成发言流水账；议而未决也写成已定；责任人不具体

### 9. 主持词

- **适用场景**：活动开场、节目报幕、典礼仪式等现场主持用稿，供主持人宣读
- **结构骨架**：写作前先定要素（主持人人数、男女比例、活动主题与类型）→ 开头（主持人全上：问候、点题）→ 中间（一男一女交替报幕，串词贴合节目）→ 结尾（全上：致谢、号召）
- **语言风格**：口语化书面语，**念得顺是第一位**；生僻字、多音字、异读字、外文单词必须注音
- **内涵底线**：报幕内容与主题、节目贴合，用词符合主持者身份；尽量不触及性别、阶层、地域等敏感议题，必须提及时适当淡化
- **常见翻车点**：一套通用串词套所有节目；书面腔太重念不顺口；漏注音；报幕与节目内容脱节
- **专项细则**：报幕要求、注音规则、敏感内容处理——见 `08-specialty-writing-guides.md` 第四章

## 二、新媒体文案

### 10. 微信推文

- **适用场景**：公众号发布，面向订阅用户，目的在于阅读、转发、涨粉
- **结构骨架**：标题（钩子：悬念/数字/利益点，20 字内）→ 导语（前 2-3 句留住读者）→ 主体（小标题分段，金句突出）→ 结尾（行动号召：转发/留言/关注）
- **语言风格**：口语化、有温度；短段落（手机屏 2-3 行为一段）；善用小标题、加粗金句；适度用问句制造互动
- **内涵底线**：标题不夸大不造谣（标题党过头即通病）；事实与观点分开；来源可溯
- **常见翻车点**：把公文腔直接搬上公众号（生硬）；一段超过 200 字；标题党与实际内容不符；没有配图位置意识；结尾无行动引导
- **常见子类型**（专项细则见 `08-specialty-writing-guides.md`）：
  - **活动预告**（第二章）：交代活动基本信息 + 趣味性吸引；严禁搬运通知、严禁打包票；征稿/比赛须注明原创性与 AIGC 校验
  - **比赛结果公示与发奖**（第三章）：参与回顾 → 公布榜单 → 奖品与领奖方式 → 感谢参与；不同于新闻稿

### 11. 小红书文案

- **适用场景**：小红书笔记，种草/经验分享，面向陌生流量
- **结构骨架**：封面标题（8-10 字内）→ 正文开头（场景共鸣/痛点直击，3 行内）→ 干货主体（分点/编号，可清单化）→ 结尾（价值总结 + 互动引导）；话题标签收尾
- **语言风格**：极度口语化，像朋友聊天；短句为主；可适度用 emoji 与网络语气词（"家人们""谁懂啊"）；第一人称分享体
- **内涵底线**：真实体验不夸大（虚假种草是平台红线）；涉及产品功效不得越界；广告须标注
- **常见翻车点**：写成产品说明书（冰冷无感）；全是套话无干货；排版大段文字无换行；笔记级文案却用公文句式

## 三、跨文种通用提醒

- **场合识别口诀**：先问三个问题——**给谁看**（上级/同事/客户/陌生网友）、**在哪发**（红头文件/会议/公众号/小红书）、**要什么效果**（执行/汇报/传播/种草）。答案不同，写法天差地别。
- 同一素材改写不同文种时，**必须重写结构**，不是改几个词就叫改稿（通病一的根源）。
- 拿不准文种时，按"结构骨架"最接近的类别套用，并在报告 Step 1 结论中说明判定依据。

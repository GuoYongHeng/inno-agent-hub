# 09 口径与分寸审查（政治性·政策性初筛）

> 用途：审稿 **Step 3.5** 使用。针对单位正式材料（总结、汇报、宣传稿、新闻稿等），**先过口径与分寸关，再谈文采**。"顺只是最低要求，稳才是更高要求。"
>
> 来源依据：综合自文稿把关实践经验——领导改稿先看的往往不是文字漂不漂亮，而是每句话站不站得稳：对象、场合、层级、口径和边界对不对。

## 0. 三条原则

1. **稳先于顺**：材料不是散文。成绩能不能写满、问题怎么点、责任怎么表述，都先于"好不好读"。
2. **只列风险，不代结论**：把可疑点挑出来、标出风险、给出降档方向，**最终是否修改由人对照政策文件、上级口径、单位实际和领导习惯判断**——与铁律"不代做判断"一致。
3. **口径问题优先于文采问题**：报告中等同严重度处理，排在文采类问题之前。

## 1. 四类风险检查清单

### 1.1 表述过满、过绝对的词句

- **识别**：绝对化、升级化、"把话说满"的表述
- **典型升级对照**（写手和 AI 都容易把语气往上抬，审稿时逐词查）：

| 稳妥表述 | 过满表述 |
|---|---|
| 基本完成 | 全面完成 |
| 阶段性成效 | 显著成效 |
| 探索做法 | 创新做法 |
| 有所改善 | 明显提升 |
| 正在推进 | 全面铺开 |
| 探索形成 | 形成成熟经验 |
| 取得进展 | 取得突破 |
| 部分单位 | 所有单位 |
| 初步建立 | 建立健全 |
| 及时处置 | 彻底解决 |

- **处理**：列出原句 → 标"表述过满"→ 给出降档方向（如上表左列）→ 是否改由人定

### 1.2 可能超出本单位层级或职责边界的判断

- **识别**：本单位层级"说不出口"的话——
  - 对宏观政策、行业全局形势作定调式解读
  - 代表上级或兄弟单位表态
  - 承诺超出职权范围的事项（如基层单位承诺全局性目标）
  - 以本单位经验断言全行业普遍情况
- **处理**：标"层级风险"→ 建议弱化主语（"我院"→"我校"→"部分单位"）或删除 → 由人确认

### 1.3 需要核对上级统一口径的提法

- **识别**：涉及上级统一表述的内容——政策口号、工作要求、会议精神、提法用词
- **处理**：标"需核对统一口径"→ 列入待核查清单（联动 Step 5 事实核查，由调用者决定是否核查）→ **不擅自改写**
- **注意**：同一提法在不同层级单位用法可能不同，只提示不代改

### 1.4 成绩、问题、措施之间分寸不稳的段落

- **识别**：
  - 成绩写满、问题一笔带过（报喜不报忧过度）
  - 问题定性过重（"严重""重大"）或过轻
  - 措施平平却成绩突出（因果撑不住）
  - 责任表述模糊（"相关部门""有关单位"）或错位
- **处理**：整段标出 → 说明分寸失衡点 → 给调整方向（如"建议按'成绩留有余地、问题点到具体、措施对应责任'重排"）

## 2. 高风险领域（重点审查）

以下内容**不能只看语言顺不顺**，必须过口径关：

- 成绩评价（数字、幅度、定性词）
- 问题定性（性质、责任、影响）
- 责任表述（谁负责、问责指向）
- 改革创新（"首创""领先""突破"类）
- 安全稳定（风险、事故、舆情的表述）
- 群众感受（满意度、获得感类表述）

## 3. AI 辅助写作的风险联动

- **AI 不天然懂口径边界**：它按高频语料补最顺口的表述（看到成绩补"显著成效"，看到推进补"全面落实"）——常见不等于当前材料适用
- **AI 会把语气往上抬**：为了气势把"有所改善"写成"明显提升"、把"正在推进"写成"全面铺开"。**凡文本带 AI 痕迹（联动通病五），必须重点核查 1.1 类升级表述**
- **保密纪律**（提示作者与调用者）：使用 AI 注意保密纪律，不该用 AI 的地方不能用；工作信息以脱敏信息或定性描述为主，不把敏感原文直接投喂工具

## 4. 与现有维度联动

| 现有维度 | 联动方式 |
|---|---|
| 通病四（用词粗放） | 绝对化用词（"最""第一""彻底"）是交集，但口径审查判定更严，且只标风险不代改 |
| 通病三（不做调研） | 1.3 类"统一口径"提法进入事实核查分支（Step 5） |
| 通病七（空话泛滥） | 空转套话可删；口径表述**不能乱删乱改**，先标风险再定 |
| 通病五（照搬机器） | 文本有 AI 痕迹时，优先查语气抬升类表述（1.1） |

## 5. 报告呈现方式

- 口径风险条目在问题清单中标注类型为 **"口径风险（需人工复核）"**，默认严重度**严重**（影响材料能否通过把关）
- 总评"口径与分寸"一行：`<稳 / N 项口径风险（见问题清单，需人工复核）>`
- 每条口径风险只给"风险点 + 降档方向"，**不代写最终定稿**，交由调用者对照单位实际判断

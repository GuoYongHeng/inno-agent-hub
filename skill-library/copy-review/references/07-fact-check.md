# 07 事实核查规范

> 用途：审稿 Step 5「事实核查」分支。规范三类内容：**哪些内容需要核查**（对象分级）、**如何核查**（方法）、**如何表述结果**（四态结论）。

## 一、核查对象与优先级

### 高风险（必须核查，影响文章成立）

- 具体数据与统计数字（"营收 1280 万元""就业率 95%"）
- 人名及其职务、头衔（"张明主任""李华教授"）
- 政策法规条文与表述（引用法规名称、条款号、政策文件号）
- 事件的时间、地点、规模（"8 月 5 日""上海""3000 人参加"）
- 引语（"领导在会上强调：……"）
- 具有宣传后果的成就性表述（"全国第一""行业首创"）

### 中风险（建议核查，影响可信度）

- 机构名、项目名、奖项名（"XX 创新大赛一等奖"）
- 历史事件与人物背景描述
- 学术概念、行业术语的定义与归属
- 产品参数、功能描述（新媒体文案常见）

### 低风险（可提示，不必逐条核查）

- 一般性常识
- 作者自身的经历、观点陈述（默认作者有权表述，除非明显可疑）

## 二、核查方法

1. **官方渠道优先**：政府网站、官方公告、机构官网、官方公众号为第一信源
2. **一手来源**：引用出处尽量追到原始发布（原文链接、文件号），不用二手转述
3. **交叉验证**：至少两个独立来源佐证；单信源结论标"存疑"
4. **时效性**：核查时注意数据年份与政策版本，确认是否已更新
5. **反查原文**：被引用的引语，尽量找到原始报道/讲话全文比对，防止断章取义

## 三、结果四态与表述模板

对清单中每条，核查后给出唯一结论，禁止含糊：

| 结论 | 判定条件 | 报告表述模板 |
|---|---|---|
| **属实** | 官方/权威来源一致证实 | "✅ 属实。经核，XX 官网 2026 年 X 月发布的数据为……，与原文一致" |
| **失实** | 权威来源证伪，或与事实明显不符 | "❌ 失实。原文称……，但……（来源）显示……。建议改为：……" |
| **存疑** | 多个来源说法不一，或仅有单一非权威信源 | "⚠️ 存疑。检索到两种说法：A 来源称……，B 来源称……，建议与当事人/主管部门确认" |
| **无法核实** | 无公开渠道可查证（内部数据、未公开事件） | "❓ 无法核实。无公开来源佐证，建议作者补充依据或删除该表述" |

> 注：报告中使用「属实/失实/存疑/无法核实」四态标签，符号（✅❌⚠️❓）仅作视觉辅助。

## 四、核查结果的落点

1. **写入报告**：核查结果以独立板块（"事实核查结果"）呈现，逐条列出：原文引用 → 核查结论 → 来源 → 处理建议
2. **联动通病三**：凡核查确认失实的条目，在问题清单中标注"事实失实（已核查）"，严重度至少为中等
3. **修订稿处理**：
   - 失实 → 必须替换正确信息或删除该表述
   - 存疑 → 弱化为"据公开报道"等留有余地的表述，或删除
   - 无法核实 → 删除或要求作者补来源
   - 属实 → 保持不变，但可建议补注来源
4. **记录来源**：每条结论后附来源链接/出处名称，便于调用者复核

## 五、不核查时的处理

- 调用者选择不核查时，待核查清单原样保留在报告中，状态标注"待核查"
- 每条附"自查建议"：作者应去哪个渠道、用什么关键词检索
- 报告总评中提示："本文存在 N 项事实表述未经核实，正式发布前建议完成核查"

# 单位硬性要求（最高准则）

> 本文件存放**你所在单位对稿件的硬性要求**。审稿时只要本文件已填写实际内容，就一律作为**最高准则**：凡与通用规则（`references/` 下各规范）冲突之处，**以本文件为准**。
>
> 配置方式二选一（详见 `config/README.md`）：
> 1. **让 AI 配置**：把单位的制度文件、格式要求、审稿要点粘贴在对话中，说"帮我配置到 copy-review 的单位规范"，AI 会整理成下方格式写入本文件。
> 2. **手动配置**：直接编辑本文件，删除示例条目，按维度填写。每条表述要具体、可判定（如"导语不超过 80 字"），不要写"注意格式"这类无法判定的要求。
>
> 配置完成后审稿自动生效，无需其他操作。

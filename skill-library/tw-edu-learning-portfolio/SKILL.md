## 语言与场景适配


所有面向用户的标题、表头、正文均用简体中文；原英文技能名和代码标识可保留，但不要以英文说明开场。匿名、虚构或标明为测试的学生、教师与学校材料不得写入学习者画像、记忆、台账或其他持久化服务，也不要调用相应写入工具；仅在用户提供真实材料并明确要求保存、且当前工具可用时才考虑持久化。
默认使用简体中文回复用户；用户明确要求其他语言时按用户要求回复。以用户给定的学段、教材、地区和任务要求为准。未经用户提供或核实，不引用特定地区课程标准条文、标准编号、学生数据或研究效果；不要把上游示例当作真实资料。文中提到的其他 Skill 仅是搭配建议；未在当前对话实际选用并运行时，不得声称已调用、已串联或已完成。仅在当前环境确有工具、依赖且用户要求文件时执行文件生成；未运行时只交付文本并如实说明。

## 客户端执行细则

开始执行时第一句用简体中文说明“我先核对任务要求、本机依赖和输入规格，再生成文件。”；后续进度与交付也只用简体中文，不输出英文开场。依赖检查只用当前 `python3 -c "import docx"` 和当前工作区明确存在的解释器；不要全盘搜索用户目录或应用程序，不执行联网安装。当前脚本自带离线 JSON 规格校验后备实现，`jsonschema` 缺失不应阻断 `--validate-only`。验证与生成使用同一个解释器；实际核对文件、校验记录和任务内容后才能称为完成。

## 中国大陆环境使用要求

核心教学与评价任务应能依据用户提供的材料、本地文件和当前 InnoSpark 能力完成。不得把访问受限境外网站、观看外部视频平台、配置代理或 VPN、注册付费第三方账号作为使用前提。需要核实而当前无法直接取得的课程标准、文献或数据，应明确标为“待核验”，继续完成不依赖该来源的部分，不编造内容。需要生成文件时先检查本机依赖；依赖缺失则先交付可用的纯文本结果，不要求用户自行访问受限网站安装。来源与许可链接仅供追溯，不是运行步骤。

# 学习历程指导

协助整理学习证据、反思与成果。适用于启创·InnoSpark，默认使用简体中文输出。

## 开始前

读取 [共用工作方式](references/common/workflow.md)。如工作区已有 `teacher-profile.md`，可作为一般教学偏好参考；无需为使用本技能新建此文件。本次要求优先。已提供的信息不要重问。

## 任务要求

区分学生原始成果、反思提问与教师建议。依实际资料整理动机、过程、困难、修正与学习证据，不代造经历、心得或成绩；未提供内容保持待补。

## 工作流程

1. 确认用户要完成的成果，读取素材与必要教学脉络。
2. 依上述任务要求提出具体内容，保留来源与待确认事项。需要重大选择时提供可评估的草稿。
3. 读取本技能的 `schemas/` 输入规格与 `examples/` 范例；以实际内容建立 JSON。范例中的资料不得混入正式成品。
4. 从任意工作目录使用下列 CLI。先验证，再生成，最后检查成品及验证纪录。

```bash
# SKILL_DIR 为本技能安装目录；TASK_DIR 为目前工作区的任务输出目录。
python3 "$SKILL_DIR/scripts/generate_portfolio.py" --input "$TASK_DIR/input.json" --validate-only
python3 "$SKILL_DIR/scripts/generate_portfolio.py" --input "$TASK_DIR/input.json" --output "$TASK_DIR/output.docx"
# 仅在明确需要展示时使用；输出标示为范例。
python3 "$SKILL_DIR/scripts/generate_portfolio.py" --example --output "$TASK_DIR/example.docx"
```

## 本机依赖与文本交付

生成 DOCX 前先检查本机 Python 是否具备 `python-docx`。`jsonschema` 为可选依赖；脚本自带仅覆盖当前输入规格关键词的离线校验后备实现。用同一个解释器先运行 `--validate-only`，通过后再生成并打开 DOCX 核对。若 `python-docx` 缺失，交付完整简体中文纯文本并如实说明未生成文件；不联网安装。旧版只传主题或科目的调用不再生成固定范例；依 schema 填入实际内容。

## 交付检查

核对学段、科目与实际内容；不把未查证的资料写成事实。确认学生可见成品未混入内部答案或理由。提供成品路径与尚待教师确认项目，未执行的外部操作不标记完成。

# 校准样本

这四个样本是 `scripts/check_copy.py` 的回归集。改词表或改阈值之后跑一遍，
四条结论都对得上，才算没把母本判死。

```bash
cd ..
for f in examples/0*.md; do
  echo "--- $f"
  python3 scripts/check_copy.py "$f" | grep -E '^\[结论\]'
done
```

| 样本 | 是什么 | 期望结论 |
|---|---|---|
| `01-factory-notice.md` | 工厂门口手写通知，本项目的母本正例 | 机器这边没抓到问题 |
| `02-stuffed-brand-copy.md` | 堆满假亲昵、公文腔、AI 腔、空承诺、说教的合成反例 | 重写（命中红线） |
| `03-support-reply.md` | 按公式改写后的客服话术 | 机器这边没抓到问题 |
| `04-opinion-statement.md` | 零禁词但通篇观点陈述——脚本最容易漏的那类 | 需要大改 / 先补现场信息 |

第一版脚本把 `01` 判成了"需要大改"：具体度只统计数字和单位，
漏掉了"车间、饭堂、空调、泥头车"这类可拍摄名词；对象感又因为全文没出现"你"
判成广播。**母本被自己的检测器判死，是这类工具最典型的失败方式**，
所以它留在这里当第一道防线。

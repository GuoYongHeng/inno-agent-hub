# 原理详解

## 一、为什么"没文笔"的文字反而打动人：四个观察

以一张工厂门口的手写通知为样本（原文见 `casebook.md` 正例 1），它火起来靠的是四件事：

1. **没有"文案意识"** — 写的人没想着传播，只想着把事说清楚。凡是"想被转发"的痕迹，都会先被读者识别为表演。
2. **不是"正确"，是"关心"** — 官方通知强调制度，它强调人。写"不准带小孩进车间"只完成了禁止；紧接着回答"那孩子怎么办"才是关心。
   **禁止只解决了发布方的责任，没解决对方的问题。**
3. **每一句都能看见现场** — 一楼食堂、有电视、有空调、泥头车很多。读者会觉得写的人每天都路过那里。
4. **善意没有包装** — 它不像制度，像厂长站在门口跟你说话。

## 二、三条原则

### 原则一：不是表达自己，是解决对方的问题

品牌爱说"我们是什么"：来自哪里的原料、什么独特工艺、一个听起来很厉害的理念。
用户真正想知道的是：**那我怎么办？**

iPod 第一代没写"容量高达 5GB，采用火线接口传输"，写的是"把 1000 首歌装进口袋"。
它没解释任何参数，但消除了一种真实的焦虑：出门跑步、坐地铁、长途飞行时，我能不能把想听的歌都带上。

> 好的文案不是发布规定，是消除阻力。

自检：这段文案回答的是"我是谁"还是"你接下来怎么办"？

### 原则二：具体名词比抽象概念更容易让人相信

抽象概念打不动人，是因为它们被"提纯"过——滤掉了场景、温度和生活痕迹，只剩正确但空洞的结论。

- 不写"提供休息区域"，写"一楼食堂"
- 不写"提供娱乐设施"，写"有电视"
- 不写"注意交通安全"，写"门口泥头车太多"
- 不写"匠心品质"，写"每一颗都要过三遍手"
- 不写"严选原料"，写"豆子来自云南保山，海拔 1600 米"

1958 年奥格威给劳斯莱斯写的那句："在时速 60 英里时，这辆劳斯莱斯车内最大的噪音来自电子钟。"
他没有说"安静"，但你瞬间感受到了安静。**电子钟的滴答声是一个可以被想象、被验证的具体画面。**

> 你说的是概念，对方听到的是距离；你说的是细节，对方听到的是真诚。

### 原则三：有温度的文案都有"对象感"

同一件事：
- "请大家注意安全"——对着所有人广播
- "不要拿自己生命开玩笑"——像对着一个人说

传播学里这叫**对象感（Audience Design）**：真正好的内容永远像在跟一个人讲话，而不是广播。
这也是"第二人称文案"越来越流行的原因——**"你"永远比"用户"有温度**。

操作方法：写之前先在脑子里选定一个具体的人（那个刚入职的新人、那个抱着孩子站在门口的女工、那个第一次来店里的顾客），全程只对他说话。写完念一遍，如果像在念稿子，就是丢了对象感。

## 三、公式：场景细节 + 行动指令 + 情绪锚点

大多数品牌文案失效，根源是叙事逻辑错位：它们用的是"观点 + 价值观"结构——"我们相信陪伴""我们坚持品质""我们倡导环保"。
这种结构的本质是品牌视角的自我表达：先立一个抽象立场，再试图让用户认同。问题在于抽象观点缺乏场景锚点，用户无法把它转化成可感知、可行动的认知。**信息传递了，但沟通没有发生。**

有效结构是三层递进：先让用户"看见"现场，再告诉用户"怎么做"，最后用一句人话完成情绪共振。

### 第一层：场景细节 — 怎么找

从 Step 1 的第 2 问里捞。合格的场景细节满足：能被拍照、能被计数、能被指认。
- 地点（一楼食堂、门口、电梯里、后厨）
- 物件（电视、空调、泥头车、雨伞、货架第三层）
- 时间与数量（两个月、三遍、1600 米、多开几分钟）
- 动作与声音（闻了很多树、滴答声）

写不出来 = 没去现场。**去查，不要编。编出来的细节读者一眼能看出来，代价比抽象词更大。**

### 第二层：行动指令 — 怎么写

必须解决**真实阻力**，不是补一句"请知悉"。
判断标准：如果对方照做，他刚才那个"那我怎么办"的问题是不是就没了？

- 阻力"孩子没人看" → "去人事处登记，在一楼食堂玩，有空调有电视，这两个月免费吃饭"
- 阻力"逆行省时间" → "多开几分钟去调头"
- 阻力"狗要闻很久，怕店家嫌烦" → "没关系，我们等它闻完"

只写"禁止"不写"那怎么办"，是这一层最常见的塌陷。

### 第三层：情绪锚点 — 四种合法形态

只有四种写法是真诚的：

1. **我方承担了成本** — "我们等它闻完"（承担时间）、"这两个月可以免费在饭堂吃饭"（承担钱）
2. **我方给出许可** — "如果它一路闻了很多树，没关系"（允许对方麻烦你）
3. **承认对方的真实处境，不评价** — "假期到了，有些员工带小孩来工厂"（陈述，不指责）
4. **说出自己的担心** — "不要拿自己生命开玩笑"（说的是我怕你出事）

非法形态（写出来立刻删）：
- 夸自己（"我们始终以客户为中心"）
- 教育对方（"那是因为你还年轻"）
- 替对方定义情绪（"相信你一定会爱上它"）
- 替对方感动（"看到这里，你是不是也红了眼眶"）

### 三层都必须真实

这个结构的有效性不取决于辞藻华丽，取决于三个要素的真实性：
场景细节必须来自真实观察，行动指令必须解决真实阻力，情绪锚点必须对应真实感受。
**任何一层"表演"，整个结构都会塌。**

## 四、人感不是万能药

人感是**结果**，不是**手段**。

把"说人话"当成一种可套用的文案技巧——对话式、故作亲昵、强行共情——结果反而令人反感。
那张工厂通知之所以打动人，不是因为它"故意说人话"，而是因为那些字背后站着一个真实的厂长，担心工人逆行出车祸，怕孩子进车间被机器伤到。**"人话"是关心的自然流露，不是精心设计的话术。**

同样是"说人话"，区别在动机：
- "我关心你，所以我说人话" — 成立
- "我想说人话，让你以为我关心你，然后下单" — 翻车

所以学"人话"之前先想清楚：你说的话，是真的为对方好，还是只是想让对方觉得你很真诚？
**人感的底色永远是真诚。没有真诚的人感，只是另一种包装。**

## 五、边界：什么时候不要人感

以下场合优先精确，人感会削弱效力甚至制造风险：

| 场合 | 原因 |
|---|---|
| 法律条款、用户协议、隐私政策的条款正文 | 措辞即义务边界，模糊表达会被解释为对己不利 |
| 合规声明、金融风险提示、医疗药品剂量与禁忌 | 有法定表述要求，改写可能违规 |
| 安全操作强制项（高压、明火、机械急停） | 指令必须唯一、无歧义、可执行 |
| 事故定责、仲裁与诉讼相关说明 | 任何情绪表达都可能被当作事实认定 |
| 面向机器的文本（接口错误码、日志、告警） | 读者不是人 |

正确做法是分层：**条款正文保持精确，在它的前后加一段人话**解释"这对你意味着什么、你现在该做什么"。
例：隐私政策条款照旧，页首加一句"这份文件里只有两件事跟你有关：我们存了什么、你怎么删掉它。"

## 六、节奏与形态

- 一句话只说一件事，说完就断。工厂通知全篇最长的句子不超过 25 个字。
- 短句不是为了"口语化"，是因为读者在门口、在电梯里、在地铁上，只有一眼的时间。
- 排版不需要设计感。手写、竖排、红纸黑字都不影响传播——**传播的是信息，不是版式。**
- 别怕重复。"要小心再小心"比"务必提高警惕"更像人说的话。

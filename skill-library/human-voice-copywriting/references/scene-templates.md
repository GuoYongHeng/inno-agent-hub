# 分场景骨架

所有骨架都是同一个公式的变形：**场景细节 → 行动指令 → 情绪锚点**。
骨架只用来防止漏层，不要当填空题套；填不进去的层说明素材没查够，回去查。

---

## 1. 通知 / 告示（园区、门店、物业、公司内部）

```
[什么情况发生了]（陈述，不指责）
[不能做什么]，[会有什么后果]。
[那就去做什么]：地点 + 动作 + 对方能得到什么。
[一句担心或一句许可]
```

> ✗ 请广大员工提高安全意识，共同守护生命安全。
> ✓ 门口泥头车太多。开车别在公路上逆行，多开几分钟去调头。不要拿自己生命开玩笑。

注意：**禁止句后面必须有出路句**。只写禁止 = 只完成免责。

## 2. 故障 / 延迟 / 道歉

```
[出了什么事]：具体到系统、时间、影响范围（不用"部分用户"）
[对方现在会遇到什么]
[他现在该做什么 / 不用做什么]
[我方承担了什么] + [下一次告知的时间点]
```

> ✗ 因系统升级，部分用户可能存在访问异常，我们将第一时间修复，如有不便敬请谅解。
> ✓ 今天 14:20 起，用支付宝登录的用户会卡在验证码那一步，微信登录不受影响。
> 不用反复重试，重试也进不去。工程师在改，19:00 前我们再发一条，无论好没好都发。
> 这期间的会员时长按天补回来。

注意：**不写"第一时间"，写钟点**。承诺"再发一条"比承诺"尽快修复"更该被兑现。

## 3. 产品卖点 / 详情页

```
[参数] → 换算成用户自己的单位（首、天、次、趟、顿、平米）
[放进一个他每天都碰的场景]
[一个可被验证的细节做证据]
```

> ✗ 容量高达 5GB，采用火线接口传输。
> ✓ 把 1000 首歌装进口袋。

> ✗ 精选优质原料，匠心工艺。
> ✓ 豆子来自云南保山，海拔 1600 米；每一颗都要过三遍手。

注意：证据句必须真实且可追问，见 `ban-list.md` 的证伪要求。

## 4. 服务承诺 / 规则说明（退换货、宠物、儿童、无障碍）

```
如果 [对方担心会麻烦到你的具体行为]，
没关系，我们 [我方为此承担的具体成本]。
```

> ✗ 本店欢迎携带宠物入店。
> ✓ 如果它一路闻了很多树，没关系，我们等它闻完。

> ✗ 提供无障碍服务。
> ✓ 门口有三级台阶，跟我们说一声，两个人抬轮椅上来，二十秒。

注意：情绪锚点写"我方承担"，不写"我方热情"。

## 5. 招聘帖

```
[这个岗位每天真实在干什么]（一天里最典型的两三件事）
[什么样的人会觉得这活儿有意思 / 会受不了]（诚实劝退）
[怎么投]：一个动作 + 多久有回音
```

> ✗ 寻找有激情、有担当、善于沟通的优秀人才，共创辉煌。
> ✓ 每天大概三件事：改十几条门店提的小需求、跟运营吵一架该不该改、周四晚上发版守到十一点。
> 喜欢一个人闷头写大功能的会难受，喜欢东西第二天就有人用的会很爽。
> 简历发这个邮箱，三天内一定回，不合适也回。

注意：**诚实劝退是最强的可信度信号**，它过了证伪测试。

## 6. 客服话术

```
[他的东西现在具体在哪 / 卡在哪一步]
[为什么]（一句，不甩锅）
[他要不要做什么]（多数情况是"不用做"）
[几点之前有结果] + [我方承担了什么]
```

> ✗ 亲爱的宝子～这边建议您耐心等待一下下哦，我们会第一时间为您处理呢～
> ✓ 你的包裹卡在杭州中转仓，昨天暴雨停了三班车。不用再催单，催了也不会更快。
> 今天下午 6 点前发出，明天到。晚一天，运费退给你。

注意：删掉所有语气词后信息量应该不变。变了，说明原文靠语气词充数。

## 7. 落地页首屏

```
[一句话说清楚：谁，用它干掉了什么麻烦]
[一个具体到能被复述的场景]
[一个动作按钮：动词 + 对方得到的东西]
```

> ✗ 新一代智能协作平台，赋能团队高效办公。
> ✓ 门店老板不用再等财务对账。收银机关了，账就是平的。
> 按钮：`看一眼我们店的账` 而不是 `立即体验`

注意：首屏不解释"我们是什么"，只回答"那我怎么办"。

## 8. 活动邀请 / 推送

```
[什么时候、在哪、干什么]（一句话，可复述给同事）
[去了会遇到什么具体的东西/人]
[他现在该做的一个动作]
```

> ✗ 诚邀您莅临，共襄盛举，一同开启行业新篇章。
> ✓ 周六下午两点，梧桐路 12 号院子里，八个人烤肉，聊聊各自被甲方改稿最多的一次。
> 带把椅子来就行。人满了就关，现在还剩三个位置。

注意：推送只有一眼的时间，**把最能被复述的那个具体名词放在前十个字里**。

# 活人感文案

## 何时启用

- 写或改通知、公告、故障说明、道歉信、规则提示、门店告示
- 写或改品牌文案、产品卖点、落地页、详情页、服务承诺、招聘帖
- 写或改客服话术、推送、公众号 / 小红书正文
- 用户嫌一段文字"太官方 / 太 AI / 没人味 / 像机器人写的 / 说人话"

## 原理：人感是信息，不是语气

"请提高交通安全意识"和"门口泥头车太多，要小心再小心"说的是同一件事。
后者多的不是修辞，是**现场信息**——门口、泥头车、太多。

抽象词的本质是提纯：把场景、温度、生活痕迹滤掉，只留一个正确但空洞的结论。
把被滤掉的东西装回去，人感自动出现；**只调语气不加信息，得到的是油腻，不是人感**。

由此推出唯一的改写方向：

> 人感 = 具体信息密度 × 对象感 × 真诚。三项任一为零，整段归零。

## 三条判据（每段文案必过）

1. **去名测试** — 删掉品牌 / 主体名，这句话还剩多少信息？剩零即包装语，重写。
2. **证伪测试** — 这句话能被验证或推翻吗？"匠心品质"不能，"每颗过三遍手"能。不可证伪即不可信。
3. **念出声测试** — 能否对着一个具体的人（同事、邻居、你妈）念出来而不尴尬？尴尬即广播腔或假亲昵。

## 工作流

### Step 0 先判断该不该用

法律条款、合规声明、药品剂量、金融风险提示、安全操作强制项、事故定责——这些地方要精确不要温度，"有人味"会削弱效力。
人感放在这些内容的**前后**（解释与安抚），不放进条款本身。边界详见 `references/principles.md`。

### Step 1 抽真话：三个问题

动笔前先答。信息不足就去问用户、查现场、查后台，**不要编**：

1. 对方此刻真正卡在哪？（不是"我想说什么"）
2. 现场真实存在什么？（能被拍下来的：地点、物件、时间、数量、声音）
3. 我到底要他做什么？（一个动作，不是一种态度）

答不出第 2 问就说明素材不够，先补素材再动笔——具象是查出来的，不是想出来的。

### Step 2 落具象

逐词扫描，把每个抽象词换成能被拍下来的东西：

| 抽象 | 具象 |
|---|---|
| 提供休息区域 | 一楼食堂 |
| 提供娱乐设施 | 有电视，有空调 |
| 注意交通安全 | 门口泥头车太多 |
| 严选原料 | 豆子来自云南保山，海拔 1600 米 |
| 匠心品质 | 每一颗都要过三遍手 |

替换问法与完整词表见 `references/ban-list.md`。

### Step 3 装公式：场景细节 + 行动指令 + 情绪锚点

- **场景细节** — 先让对方"看见"，降低认知负荷。必须来自真实观察。
- **行动指令** — 告诉对方"怎么做"，消除真实阻力。必须解决真实阻力。
- **情绪锚点** — 一句人话完成情绪落点。必须对应真实感受。

关键：情绪锚点的正确形态是"我方承担了什么成本 / 允许了什么"，**不是"我方多好"**。

> 欢迎携带宠物入店。（观点陈述）
> → 如果它一路闻了很多树，没关系，我们等它闻完。
> （场景：宠物进店前的犹豫｜行动：消除时间压力｜情绪：被理解的松弛感）

三层的构造细则、情绪锚点的四种合法形态见 `references/principles.md`。

### Step 4 过体检

```bash
python3 ~/.claude/skills/human-voice-copywriting/scripts/check_copy.py draft.md
```

脚本给的是提示不是判决：对每条命中回答"这里真实存在什么"，指标不合格就回 Step 2。

最后做一次真诚自检：

> 这句话，是真的为对方好，还是只想让对方觉得我很真诚？

后者一律删掉。消费者分得清这两者，而且分得越来越快。

## 三个假货（红线）

| 假货 | 长相 | 为什么翻车 |
|---|---|---|
| 故作亲昵 | 宝子 / 家人们 / 亲爱的用户朋友们 | 关系是攒出来的，不是称呼出来的 |
| 强行共情 | "我懂你的不容易" | 你不懂，且对方知道你不懂 |
| 挪用自嘲 | 品牌拿"被生活毒打"卖货 | 自嘲是当事人的特权，品牌用即消费苦难 |

完整拆解（含桃李面包五仁月饼翻车案）见 `references/casebook.md`。

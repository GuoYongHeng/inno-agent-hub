# 课堂教学反思 Skill 维护约定

本目录包含课堂录音转写接入、评价方式选择、课堂反思报告和可选教案重构。流程以 `SKILL.md` 为入口，字段与状态见 `references/input-output-schema.md`。

- 修改工作流时，同步脚本、提示词、模板、字段约定和流程测试。
- 先解析课堂材料，再等待评价方式；自定义量规不得静默回退内置标准。
- 报告交付后主动询问是否生成新教案，用户同意后才进入教案重构。
- 同一案例的转写、评价选择、报告和教案复用一个 `run-state.json`。
- 修改脚本后运行 `python3 -m unittest discover -s agent_cases/classroom-reflection-skill/tests`（从仓库根目录）。流程测试使用本地样例或模拟转写，不发起真实转写服务请求。
- 区分本地流程校验与真实音频端到端验证，交付时只声明实际完成的验证。

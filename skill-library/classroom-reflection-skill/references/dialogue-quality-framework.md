# 师生对话质量

本维度用于用户选择内置标准时的课堂教学反思，与内置学科量规配合。自定义模式以用户上传维度为准，仅在相关维度需要对话证据时参考本框架，不额外追加评价维度。分析口径来自华东师范大学课程与教学研究所团队在 AI Classroom「课堂话语分析」中的做法，崔允漷老师团队的课堂观察传统是这套框架的来源。

逐字稿只能支持可听见的话语。沉默中的个人任务、小组讨论、板书和演示不计入学生时间，也不要据此判断学生没有学习。

## 报告怎么写

「师生对话质量」按三层写，最后再给四行判断。不要把时长和水平占比挤进同一格。

1. 话语要素与课型：一张对照表。行是教师话语、学生话语、师生对话、课型、教师提问、话轮、讲授语速。列是本节课、参考、怎么看。本节课列使用脚本给出的数字，指标名留在指标列。
2. 提问、回答、理答水平占比：三张表。每级一行，写出含义、大约次数和一句原话。没有出现的级别写「这节课几乎没有」。
3. 重要问答链：1–2 条。每条按时间写出提问、回答、理答原话，并说明是否扣住学习目标、理答有没有把回答往上推。

收束判断仍是四行：对话时长与课型、提问水平、回答水平、理答水平。理由指向上面的表和问答链，不把数字再抄一遍。

## 观察点

### 对话时长与课型

脚本统计以下证据。写进对照表时使用这些标签，不要重新加总时间，也不要把这段说明抄进报告：

- 教师话语时长、学生话语时长。
- 师生对话时长：同一轮相邻师生话轮里、间隔不超过 15 秒的可听见话语。连续讲授不算进这段时长。15 秒是本技能用来切分对话段的操作阈值。
- 话轮：教师与学生话语主体发生转换的次数。
- 教师提问个数：带问号的教师问句。没有问号的疑问语气无法从逐字稿确认。
- 教师讲授语速：教师话语中的汉字、字母和数字个数，除以教师话语分钟数。帮助中心同时使用过「字节」和「音节」，这里用字数近似。

课型按「师生互动推进与课型」示意图读取，只比较可听见的时长：

- 学生话语比教师话语多出 6 分钟以上：指导型。
- 学生话语比教师话语少 7 分钟以上：讲授型。
- 绝对差落在这两条分界之间：对话型。

分界是示意图上与对角线平行的分钟刻度，不是得分线。师生话语总时长不超过 7 分钟时，绝对差还越不过分界，课型只说明尚未越界。

帮助中心示例课给出的参考范围，只供解释整课样本，不要当成扣分线，也不要机械套到短片段上：

- 教师提问 20–80 个。多于这个范围时，先看是不是大量封闭问题造成的「满堂问」。
- 话轮 30–70 次。某一时段话轮很多、转换很快，往往说明问答停在很短的来回上。
- 教师讲授语速 150–300 字/分钟。

### 提问、回答、理答水平

课堂问答行为链是：教师提问 I、学生回答 R、教师理答 E/F。研究团队把每个环节分成三个水平。`suggestedLevel` 只是草稿，最终水平由报告作者判断；修正草稿时在判断依据里说明。

| 编码 | 定义 | 例句 |
|---|---|---|
| I1 | 有标准答案的封闭式简短问题 | 同不同意？对不对？大家说，对吗 |
| I2 | 有标准答案的推理性或解释性问题 | 什么是坐标？他们身上具有什么样的人物特征 |
| I3 | 无标准答案的开放式或半开放式问题 | 你有没有不一样的想法？你面临困难的时候，你会怎么办 |
| R1 | 简单回应 | 是 / 对 / 能 / 同意 / 嗯 |
| R2 | 事实性、回忆性、解释性的答复 | 三角形的内角和为 180 度 |
| R3 | 开放性、诠释性的回答 | 我觉得这里还体现了一种时代精神 |
| E1 | 简单回复 | 说得很好 / 没错 / 好的，请坐 |
| E2 | 复述观点、追问，或邀请本人或他人继续回答 | 你说换一下，再解释一下？同学们，还有吗 |
| E3 | 进一步促进反思、元认知 | 你是如何得出这个结论的？你自己觉得这个解释合理吗 |

教师重要问题优先看四件事：与学习目标是否高关联，学生参与是否高，它是不是问题链里的首问或主问题，教师是否投入了更长的讨论时间。报告里点出 1–2 个重要问题，说明它的水平和学生回答是否匹配。

学生没有接上的提问记为未回答。学生回答后教师直接进入下一话题、没有回应，记为未理答。

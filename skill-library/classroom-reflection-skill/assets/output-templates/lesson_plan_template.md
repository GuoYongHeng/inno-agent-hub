# 优化版公开课教案输出模板

```markdown
# 优化版公开课教案

生成时间：YYYY-MM-DD HH:MM:SS

## 一、基本信息

| 项目 | 内容 |
| :--- | :--- |
| 学科 | {subject} |
| 年级 | {grade} |
| 课题 | {topic} |
| 课时 | {durationMin} 分钟 |
| 课型 | {lessonType} |
| 设计类型 | 普通讲授 |

## 二、教材分析

### 教材定位

{textbookPosition}

> 说明课题对应教材的单元、课时位置，以及与前后知识、方法或任务的关联。

### 课标要求

{standardRequirement}

> 结合对应学段课程标准中的内容要求、学业要求或教学提示，不写空泛口号。

## 三、学情分析

| 维度 | 分析 |
| :--- | :--- |
| 先备知识 | {priorKnowledge} |
| 已有经验 | {existingExperience} |
| 可能困难 | {potentialDifficulty} |

> 学情分析是教学设计的起点，应具体说明学生已掌握什么、未掌握什么，以及本节课需要提供哪些支架。

## 四、核心素养目标

说明：先查 `references/core-literacy-map.json`，按学段和学科匹配 `verificationStatus: "standard_declared"` 的核心素养条目，并参考该条目的 `objectiveWritingHints` 组织目标表述；同一学科同时存在义务教育和普通高中条目时，必须先按年级/学段确定 `stage`；若匹配条目含 `developmentalDimensions`，应按小学/初中等阶段选用对应二级维度，并可在“核心素养维度”中写成“一级核心素养（二级维度）”；未命中已核验条目时，可参考 fallback 中的“中国学生发展核心素养总体框架”撰写通用育人目标，但应标注“需按对应学段、对应学科课程标准人工核对后补充”；不要使用三维目标写法。

| 核心素养维度 | 本课具体表现 | 匹配依据 |
| :--- | :--- | :--- |
| {dimension} | {target} | {matchingBasis} |

> 核心素养维度必须来自已匹配的 JSON 条目；不要把 `objectiveWritingHints`、解读材料或通用育人框架当作学科核心素养名称。核心素养维度参照中国新课标。普通教案也应体现素养导向，避免只写知识目标。

## 五、教学目标

| 目标 | 目标层次 | 行为动词 | 对应核心素养 | 评价证据 |
| :--- | :--- | :--- | :--- | :--- |
| {description} | {level: 识记/理解/应用/分析/评价/创造} | {behaviorVerb} | {coreLiteracy} | {assessmentEvidence} |

> 每条教学目标都要同时包含“目标表述”和“对应核心素养”；行为动词必须可观察、可测量，避免使用“了解、掌握、培养、提高”等模糊表述。

### 教学重点

{teachingFocus}

> 教学重点必须对齐主目标，是本节课必须让学生学会的核心知识、方法或能力。

### 教学难点

{teachingDifficulty}

> 教学难点必须在教学流程中有对应支架。难点判断标准是：预计多数学生独立达成有困难。

## 六、教学流程

| 环节 | 时长 | 教师活动 | 学生活动 | 设计意图 |
| :--- | ---: | :--- | :--- | :--- |
| {stage} | {durationMin} | {teacherActions} | {studentActions} | {designRationale} |


> 普通教案的环节通常包括：导入 → 新授 → 练习巩固 → 课堂小结 → 布置作业。各环节时间分配需合理，学生活动时间总和不应少于课时的 50%。


## 七、板书设计

{boardDesign}
> 板书应呈现本节课的知识结构、方法路径或逻辑主线，避免只写标题和条目。可注明主板书与副板书区域。

## 八、评价量规


| 维度 | 优秀 | 合格 | 待改进 | 证据来源 |
| :--- | :--- | :--- | :--- | :--- |
| {dimension} | {excellent} | {qualified} | {needsImprovement} | {evidence} |

> 评价维度应对齐教学目标，确保每个目标都有对应的评价方式和证据来源。

## 九、资源与条件

| 类型 | 名称 | 使用方式 |
| :--- | :--- | :--- |
| {type} | {name} | {usage} |

## 十、教学反思要点

- 教学目标是否达成？每个目标是否有对应的学生行为证据？
- 教学环节的时长分配是否合理？哪个环节超时或时间不足？
- 学生的困难是否被预判并得到了有效支架？难点突破是否成功？
- 评价证据是否足以支撑目标达成判断？
```
